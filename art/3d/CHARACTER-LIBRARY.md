# 角色与动作预览

双击项目根目录「启动3D主角预览.cmd」。左侧选择七个角色，右侧先选动作包页签，再选择动作用途或搜索原名。页签过多时可用左右箭头滚动。

来源页签：武士、战士、制作采集、剑盾、长矛、邪恶法师、女性交互。来源与用途互相独立，因此可以单独查看剑盾的移动动作或女性交互的待机动作。悬停条目可查看来源、分类及时长。同名动作以包编号区分。03 Amplify 包不再列入目录。

支持时间轴、暂停、循环、0.25–2倍速、正背面切换、旋转缩放及水平根位移开关。切换模型保留当前动作与时间点。

仅导入实际AnimSequence，不将蓝图、BlendSpace及Montage重复当作动作。原始空文件和无时长的绑定姿态不列入可播放列表。完整数量和跳过原因见 MOTION-PACKS.json。

源文件位于tempassets，未修改。新增PMX保留UV、原贴图与蒙皮；MMD控制约束与实时物理不在预览中执行。所有角色共享一份动作采样，仅选中的动作载入内存。衣摆、不同身材比例仍可能穿插；武器和交互家具未装配。

更新工具：export_current_packs_ue.py导出当前包，export_current_packs.py采样为Godot动作。预览场景为character_library.tscn，正式跑图动画不依赖03库。

当前可播放数量：武士98、战士96、制作采集45、剑盾124、长矛35、邪恶法师9、女性交互35，总计442。已验证所有采样长度和有限数值，七个包的播放与筛选，以及七个角色共享动作切换；没有逐条人工审查动画美术质量。
