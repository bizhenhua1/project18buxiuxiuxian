# 先知·踏雪来：本地动作适配预览

项目根目录双击 **启动先知动作预览.cmd**，切换九段动作，拖动旋转、滚轮缩放，暂停检查姿态。

模型来源：网易《第五人格》。提取、材质优化、原绑定：kuchikiii。使用用户放入 tempassets 的原文件；转换结果用于当前本地 Demo。

动作来源：用户提供的 Evil Magician Animations。通过本机 Unreal Engine 5.2 导出全部九个动作，再映射到先知原有骨骼，保留网格、UV 和蒙皮。原素材没有受击动画，鸟模型标注未绑定，没有纳入此次动画预览。

已接入：EM_Idle、EM_Walk、EM_Run、EM_Attack01、EM_Attack02、EM_Attack03、EM_RangeAttack、EM_Special、EM_Death。原动作按 30 fps 烘焙，游戏播放插值。

- `seer-animated.blend`：可编辑的模型及九段动作。原始完整 MMD 导入工程保留于 tempassets/work/seer-source.blend。
- `../../../godot/assets/characters3d/seer-treading-snow.glb`：Godot 使用的模型与动作。
- `manifest.json`：材质贴图对应、面数、骨骼数量和动作帧数。
- `EM_*.png`、`rear.png`：Godot 实际预览截图。

当前是动作适配初版，已接入风格 2 远征主角表现。使用原基础贴图重建可导出材质，MMD 专用高光与 Toon 效果未作逐项复刻。运行版已将动作转为骨骼关键帧，不携带原 MMD 控制约束、实时刚体物理或表情动画；头发和衣摆的原骨骼与蒙皮保留，复杂动作中的穿插及二次摆动仍可继续精修。

已在 Godot 中验证九段动画存在并逐段播放、截图检查；没有执行帧率压力测试。


## 项目接入
主角 daotong 在实际远征及无限跑图中使用实时 3D 模型。前进显示背面上半身并播放行走，战斗播放待机、远程/施法、死亡；原有受击位移保留（包内无受击片段）。
开发时运行 `godot.exe --path godot res://scenes/endless_forest.tscn` 可直接体验，原独立预览仍保留。
透明 SubViewport 的 GPU 纹理进入原场景深度排序和雾/灯光着色，不逐帧截图或重建图集。其他队员和怪物仍为原立绘。
验证：游戏行走/战斗截图、主角战斗事件触发动作、暂停同步。未进行帧率基准测试。

## 行走校准
采样重定向模型脚踝最低 35% 的支撑阶段：EM_Walk 约 1.598785 模型米/完整循环，周期 1.366667 秒。透明模型视口垂直跨度 2.55 模型米，场景 sprite 高度 / 2.55 即当前世界单位/模型米。以此计算前进速度（约 1.17 模型米/秒），步相按实际路程推进，AnimationPlayer 使用手动单时钟。
运行时仅为 Walk 创建平滑根平移副本，保留前两阶周期分量，根纵向位移留给场景驱动。实测根高度摆幅从 0.112 米降为 0.031 米，首尾位置差为零。原 GLB 未改动。
不同时间步划分推进相同距离得到相同动画相位；暂停和零路程不推进步相。此为步态/距离验证，不是帧率基准。岔路推进与普通行走采用相同物理速度，所需时间会比旧快速滑行更长。

## 远征相机同步修复
远征 UI 布局不再调用 arena._process(0)；禁用远征内 Arena 自主 _process，由远征在每帧统一调用一次。零 dt 的角色同步不消耗路程。布局、相机发布、角色推进、最终投影同步按固定顺序执行；地面和物件共享最终焦距、地平线与相机高度。
额外引入真实时间临界阻尼跟随位置/镜头混合，转向不再以游戏倍速调整阻尼。主角步相使用呈现相机的实际前进距离。原自然起伏保留。
验证 test_journey_camera：0.5/1/4 倍速的渲染参数一致，暂停冻结，零 dt 不消费路程；此检查不属于帧率基准，也不代表对所有设备上的跳帧情况做了排除。

## 场景光影加强
共享场景着色：降低环境底光，缩小并增强队伍暖色光池与敌方冷光池；高光软压缩保留白色衣物细节。战斗 shot/cast 与 damage/heal/revive 产生按世界位置衰减的短促彩光，最多 4 盏，0.42 秒内衰减，暂停冻结。地面与树木使用同一光源参数，不影响 UI。特效增加柔光晕。
验证 test_combat_lighting：光源参数有效并按期回收，实际战斗静态/闪光截图位于 lighting-rest.png、lighting-flash.png。未进行帧率基准测试。
