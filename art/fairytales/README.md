# 十八个黑暗童话场景

启动项目根目录的 **启动黑暗童话场景.cmd**，按故事筛选。每个场景有「进入场景·探索与战斗」和「查看世界地块与怪物」两个入口。原六套主题仍保留。

## 内容范围

每套包含独立地面、世界地块侧面、一个大型建筑或景物构件、四种小物件和三种战斗怪物，共 180 张运行时图片。场景采用原有分层 2.5D 工艺，镜头、队伍模型与已保存的站位配置继续沿用。新怪物为单姿势手绘切图，调用现有移动、攻击、受击表现，不是新增骨骼模型或逐帧动画。

世界地图主题序列中加入了这些场景；独立目录可直接测试任意一套。世界怪物标记、远处事件展示与战斗敌人使用同一套场景资料。

## 资产与维护

- 原始生成图和逐张提示词：art/fairytales/raw/。
- 运行资产：godot/assets/fairytales/各场景编号/。
- 设计清单：art/fairytales/manifest.json；运行目录：godot/data/fairytale_scenes.json。
- 切图记录和落地锚点：各运行资产文件夹内的 anchors.json。
- 材质、建筑和小物件分离；建筑保持完整轮廓，行走区域不撒布建筑。
- 新增故事剧情、专属首领机制和完整章节叙事不包含在本次场景资产接入中。
