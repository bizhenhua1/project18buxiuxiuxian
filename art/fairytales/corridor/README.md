# 通道主体资产第一批

本批通过内置 image_gen 逐张生成，覆盖全部 18 场景：14 张中空通道外壳、4 张独立侧景（玫瑰庭园、集市、河岸、游乐场）。

- `raw/`：生成原图、手写提示词；剧院保留初稿及修正边缘后的 v2。两张旧主体清底前备份也在此。
- `corridor-overview.jpg`：从实际透明资产拼成的总览，非实机截图。
- `geometry-report.json`：图像边界、接地点、开口宽度与建议显示尺寸。
- `godot/assets/fairytales/<场景>/corridor-shell.png` 或 `corridor-side.png`：透明成品。
- 同目录 `corridor.json`：已由 `fairytale_corridor.gd` 读取的独立参数。

18 张均通过透明边缘、残余品红、完整边界检查。开口尺寸按中下部透明区域测量，保持图像比例；建议值仍须结合游戏机位验证。特别是苹果树冠低垂枝叶使开口偏窄，不能直接套用普通木框宽度。

## 当前状态

完成：原有六套布局的结构/道具层级核算、18 场景补充计划、18 张主体生成/提取/几何检查和首版接入，8 个场景共 72 张小物件提取/尺寸配置和接入，厨房和钟楼旧 structure.png 的品红底清理。

尚未完成：其余 10 个场景的中小件补充、分岔与旋转后路段的完整视觉检查、地面接缝/世界地块拼接、性能分析、与原有六场景的同机位视觉对照。图片生成返回 usage_limit_reached（详见 progress.json）。本批不等于场景精修完成。

当前摆放规则：中空外壳检查左右支撑与所有道路的距离；封闭主体稀疏地放在道路外；有配置的小物件按 anchor/prop/cover/litter 区分尺寸与频率，只有低矮 litter 可进入道路。后续必须检查连续行进下的围合效果，不能只依赖截图和数量断言。

新增验证：`test_fairytale_corridor_frames.gd` 对 18 场景的直路、二岔路、三岔路分支共 144 组布局进行平移/旋转对照，验证资源布局不随全局坐标系变化、保持贴地和图像比例、所有物件位于所属路段。检查发现并修复随机偏移越过路段边界的问题。该测试只证明几何不变量，不替代岔路实机视觉验收。
