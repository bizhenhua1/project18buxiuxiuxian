# 地面重复铺设检查

`overview.jpg` 为六套基准和十八套童话场景原图的 2×2 直接重复预览；各场景另有 768×768 单独预览。未改写任何游戏资产。

基准来源：森林使用 style2/ground.png，另外五套使用 biomes/<主题>/ground.png。它们是局内地面资源，不是世界格子截图。下水道与宫殿当前源图相同，不能把两者当作两个独立的地面美术标准。

## 检查方法与限制

measurements.json 比较原图相对边缘的 RGB 跳变，与图内相邻行/列平均跳变的第 95 百分位。较高比值提示边界异常，不能单独证明肉眼接缝，也不能衡量丰富度；必须和重复预览一并判断。纹样的相位错位即使颜色差异很小也仍需修复。

## 已确认的资产问题与制作顺序

1. 魔镜长廊：菱形格纹在边界断开，需要真正周期一致的石砖纹样，保持当前黑白冷灰配色。
2. 无人木偶剧院：纵向边界亮度/木纹中断明显，纵向跳变比 6.44；重新制作连续舞台板材，红色磨损避免整块渐变边缘。
3. 玩乐之国：拼花在两轴接缝处错位，跳变比分别 3.83/5.02；拼花必须满足完整周期。
4. 空城集市：石铺装的扇形图案在边界突然中断，避免把一个构图完整的广场图片直接反复铺设。
5. 木偶工坊：木板和木屑在横向边缘断开，跳变比 4.79；木屑优先交由已有独立装饰层承载。
6. 山中入口、兔子洞门厅、钟楼：检查石块/镶边纹样在四边的相位，重做连续连接，不能用跨缝模糊遮盖几何错位。
7. 其余十个场景：继续检查完整尺寸的重复预览和实机行进；较低数值不等于验收通过。长屋烘焙地毯尤其需要分离为独立资产，避免重复铺满地面。

## 新贴图约束

- 保持既有手绘刻线与场景配色，俯视、无透视、无方向性大面积明暗渐变。
- 四边真正可平铺，砖格/木板/拼花在两轴都必须闭合。
- 独立地毯、显眼机械圆盘、木屑堆等叙事性装饰不要烘焙为每块地砖固定重复的图案。
- 使用内置图片生成制作或修复，输出后重复铺设检查并在当前游戏机位验证；不要由脚本绘制替代美术资产。
