# 地图样张（仅选型，不进游戏）

上一批评语：`map-ex-*` 五张横条风景 **过于简单、不像地图**（侧视一层山一条天 / 平涂色块）。本批 `map-carto-*` 改成 **俯视或斜俯视的游戏世界地图 / 手绘舆图**：能看出地形、路网、区域，像可探索关卡底图。图上 **没有路点、旗帜、关卡数字、你在这里**。未接入中间地图区，也未改 `js/map.js`。

构图是 **4:3 满幅地形**（刻意不用 16:9 横条风景）。矿物色仍靠 style-e（石青 / 石绿 / 丹砂 / 土黄）。

- **A · `map-carto-a.png`**：斜俯视（约 3/4）手绘关卡图。土路分叉成网，林地/田/山/水塘当地图符号，右上 **一座关隘/城郭剪影**（不密）。
- **B · `map-carto-b.png`**：更俯视的区域图。田、林、山、水色块清楚，像策略地图；路网较细，聚落只作小色块。
- **C · `map-carto-c.png`**：丹砂夜地图，**同样是俯视结构**（不是夜景插画）。深石青底、丹砂山体、石绿林、土黄路。
- **D · `map-carto-d.png`**：以河为骨架的流域图。主河道 + 支流/湿地，桥与岸边小聚落很少。
- **E · `map-carto-e.png`**：偏工笔舆图。折线路、山形符号、绢本感；仍无文字、无比例尺数字、无路点。

旧横条 `map-ex-a`…`map-ex-e` 仍留在本目录作对照，不作为本轮选项。

请回 **A / B / C / D / E**（可多选或组合，例如「白天用 B，夜里用 C」）。选定后再谈生产图，不会自动接到现用地图。
