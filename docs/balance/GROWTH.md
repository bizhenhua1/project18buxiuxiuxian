# 数值成长方案

卡面 `atk / hp / cd` 永远是 **1 级白板**。有效战斗力由关卡系数放大，参数集中在 `js/balance.js` 的 `BALANCE`。调参只改那个对象。

地图：每图 **8 个路点**，`stage` 从 0 计。`nodeIndex = stage % 8`，`regionIndex = floor(stage / 8)`（换图与循环第二圈都算新台阶）。第 8 路点（`nodeIndex === 7`）视为 Boss。

- **玩家倍率**跟 `unlockStage`（已解锁最高路点 / 境界）。
- **怪物倍率**跟当前选中路点 `focusStage`（回打旧点会变弱，不会被最高关碾压式双重放大怪）。
- 正常推图时两者相同，只在 Boss 上怪血额外加码。

## 1. 锚点（第 1 关，stage = 0）

| 项 | 约定 |
| --- | --- |
| 编制 | 我方：道童 + 五件低级法宝（参考 6 人队）。敌方：低级怪预设（火狸等，携带上限 8） |
| 谁占优 | **我方略占优**：同倍率、我方单体质量更高，且集火最左；满编应能稳定打过，空场或只丢 1～2 张会输 |
| 战斗时长 | **设计目标 20–40 秒**（含起步满 CD、弹道、护盾/治疗空转） |
| 现状 | 白板 DPS 相对总血偏高。参考队理论清场 `Σ怪血 / ΣDPS ≈ 5s`，加上起步 CD 与弹道大约 **8–15s**。成长曲线保证 *相对* 时长不崩；要把绝对时长拉进 20–40s，应加白板怪血或降白板攻，而不是改成后期指数血。 |

「略占优」不靠无限加卡：携带上限仍按 `UNLOCK_CAPS` 慢慢涨，强度主要来自倍率。

## 2. 公式

### 公共核

```
core(stage) = stageGrowth ^ stage  ×  regionGrowth ^ regionIndex
regionIndex = floor(stage / 8)
```

默认 `stageGrowth = 1.09`（落在 1.08～1.12），`regionGrowth = 1.35`。  
路点连续变难；换图（0→8、8→16…）再乘 1.35，形成台阶，而不是每关 +1。

### 玩家

```
playerAtkMult = core
playerHpMult  = core × playerHpDrift ^ stage
cdMult        = cdMin + (1 - cdMin) / (1 + stage × cdHaste)
```

```
有效攻击 = round(白板atk × playerAtkMult)
有效生命 = round(白板hp  × playerHpMult)
有效CD   = max(cdHardMinMs, round(白板cd × cdMult))
```

`playerHpDrift = 1.008`：血略快于攻，后期稍肉，对冲怪攻漂移。

### 怪物

```
monsterAtkMult = core × monsterAtkDrift ^ stage × (Boss ? bossAtk : 1)
monsterHpMult  = core × monsterHpDrift ^ stage × (Boss ? bossHp  : 1)
cdMult         = 与玩家同一条软下限
```

`monsterHpDrift = 1.012`，`bossHp = 1.4`，`bossAtk = 1.08`。  
Boss 只在每图第 8 点生效。

### CD 为什么这样

线性 `cd *= 0.95` 会在后期把出手打成机关枪。双曲软下限让 `stage → ∞` 时 `cdMult → 0.78`，再加 `cdHardMinMs = 500` 绝对地板。节奏略加快，但不成为主成长轴。

### 护盾 / 治疗

不另开成长轴，自动跟快照后的有效值：

| 技能 | 现实现 | 成长 |
| --- | --- | --- |
| 护盾（瓦瓷印 / 石头精） | `maxHp × 0.18` | 跟 **有效生命** |
| 治疗（小葫芦） | `atk × 1.4` | 跟 **有效攻击** |
| 溅射 | `atk × 0.5` | 跟有效攻击 |
| 加速（麻索） | 减相邻 `cd × 0.28` | 跟有效 CD |

DPS 统计仍用实际打出的伤害，不必改公式。

## 3. 攻防同步与 T_kill

```
参考队 DPS(stage) = Σ  round(白板atk × playerAtk) / (有效CD秒)
T_kill(火狸)      = 火狸有效HP / 参考队 DPS
```

参考队固定为道童 + 桃木剑 + 瓦瓷印 + 麻索 + 铜镜 + 小葫芦（6 人，忽略溅射/治疗空转）。  
这是 **单体等效击杀时间**，用来盯曲线，不是整场钟表时间。整场 ≈ `全队怪血 / 参考DPS × 开销(起步CD、弹道、盾)`。

意图：

- 普通路点：`T_kill` 大致贴着 0.47～0.50s（相对 stage 0）。
- Boss：拉到约 0.68～0.79s（血 ×1.4）。
- 换图后第一点回到普通路点，不要一直停在 Boss 难度。
- `monsterHpDrift` 让曲线 **缓慢变长**，避免越打越秒杀。

若只放大怪血、不放大玩家攻，后期会打不动；若只放大玩家攻，会秒杀。两边共用 `core`，漂移只开 0.8%～1.2%/关。

## 5. 可调参数（`BALANCE`）

| 键 | 默认 | 作用 |
| --- | --- | --- |
| `stageGrowth` | 1.09 | 每路点；↑ 整条曲线变陡 |
| `regionGrowth` | 1.35 | 换图台阶；↑ 第二张图起跳更大 |
| `playerHpDrift` | 1.008 | 玩家更肉 |
| `monsterAtkDrift` | 1.008 | 怪更疼 |
| `monsterHpDrift` | 1.012 | ↑ 则 T_kill 变长（打不动方向） |
| `bossHp` | 1.4 | 第 8 点血 |
| `bossAtk` | 1.08 | 第 8 点攻 |
| `cdMin` | 0.78 | CD 倍率渐近线 |
| `cdHaste` | 0.035 | 逼近下限的速度 |
| `cdHardMinMs` | 500 | CD 绝对地板 |

代码入口：`playerMult(stage)`、`monsterMult(stage)`、`effectiveStats(unit, stage, side)`、`applyEffectiveStats(unit, stage)`。

## 6. 在游戏里怎么感到变难

1. 硬刷新页面，看卡池数字：第 1 关仍是白板（道童 攻10 血48）。
2. 打赢当前路点后自动推进（**下一关解锁** 按钮只在已打赢当前路点时可用，免战连点不再放大进度；曲线走查请用调试钩子 `__dao.setStage(n)`），卡池与场上有效攻/血上升；左侧解锁栏会写当前攻/血倍率。
3. 推到本图第 8 点：敌军血明显厚一截（Boss ×1.4），输出统计里同一场打得更久。
4. 进入第二张图：倍率跳一档（×1.35），但去掉 Boss 系数，体感是「新图小怪比上一图小怪硬，但比刚打完的 Boss 爽一点」。
5. 地图点回已通路点：敌军按该点缩放，我方仍按最高解锁，旧点会更好打。
6. 悬停场上单位：提示为有效攻/血；悬停卡池：白板 + 当前有效。
