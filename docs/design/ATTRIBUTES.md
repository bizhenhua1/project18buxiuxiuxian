# 战斗属性体系（v1 · dao6）

> 代码：`js/balance.js`（公式/敌方成长）、`js/combat.js`（结算）、`js/talents.js`（mods 聚合）、`js/equipment.js`（词条来源）、`js/unit.js`（卡牌白板）。
> 在法宝双模式（TALENTS.md §3.1）之上引入：伤害二元化、防御二元化、出手三属性（暴击/攻速/技能冷却）。

## 1. 属性总表

| 属性 | 字段 | 作用范围 | 来源 |
| --- | --- | --- | --- |
| 伤害类型 | `dmgType: "phys"\|"spell"` | 每单位固有（普攻与技能同型） | 卡牌白板 |
| 外伤加成 % | `physPct` | 我方全体外伤单位攻击 | 天赋「刚劲」、词条 |
| 法伤加成 % | `spellPct` | 我方全体法伤单位攻击（含法术治疗强度，兼容旧「法术强度」） | 天赋「凝神/咒力/灵台清明/万法周天」、词条、项链主属性 |
| 外伤防御（点） | `physDef` | 受到外伤时递减减伤 | 卡牌白板 + 天赋「铁骨」+ 词条 + 法衣主属性；敌方随关卡成长 |
| 法伤防御（点） | `spellDef` | 受到法伤时递减减伤 | 卡牌白板 + 天赋「玄盾」+ 词条 + 玉佩主属性；敌方随关卡成长 |
| 暴击 % / 暴伤 % | `critChance` / `critDmg` | **全队通用**（每单位掷点，含识海法术）；敌方 stage≥5 的 Boss 带 10% 基础暴击 | 天赋「锐目/淬锋」、词条、戒指主属性 |
| 攻速 % | `atkSpeedPct` | 只作用道童与手持（held）法宝：等效 CD = CD ÷ (1+攻速%) | 天赋「猿臂」、词条 |
| 技能冷却 % | `skillCdrPct` | 只压缩主动技（heal/shield/haste，held 封印时不吃）与识海法术的等效 CD | 天赋「凝息」、词条 |
| 全冷却 % | `cdPct` | 全队所有出手（稀有来源） | 鞋主属性、仙品·踏虚、天赋「静心/玄妙」 |
| 受伤减免 % | `dmgReduce` | 百分比减伤，与防御**相乘叠加** | 天赋「铁布衫/法宝合身」、词条 |

分工：**攻速管出手、技能冷却管技能、全冷却两者都管但稀有**。普通词条池已撤下全队 cdPct，换成攻速/技能冷却两条方向性词条。

## 2. 伤害结算公式（`combat.applyDamage`）

```
防御减伤率 = def / (def + 60 + 4 × 关卡数)   （封顶 75%）
实际伤害   = round( 原始伤害 × (1 − 防御减伤率) × (1 − dmgReduce) )   → 再过护盾 → 扣血
```

- `def` 按来袭 `dmgType` 取 `physDef` 或 `spellDef`；无类型伤害（`dmgType=null`）不吃防御。
- 常数 `60 + 4×关卡` 随关卡抬升（`BALANCE.defBase/defPerStage`），防止后期防御白值碾压。
- 防御减伤与 `dmgReduce` **相乘**而非相加（两条 50% 叠出 75% 而非免疫）。
- **反伤（thorns）定为外伤**；治疗/护盾无类型。
- 跳字分色：外伤暖红（`.float-num.dmg`）、法伤冷紫（`.float-num.dmg.spell`）、暴击更大字带「暴」标（`.crit`）。

## 3. 伤害类型分配

**我方**：道童/桃木剑/青锋剑/玄铁重剑/开山斧/麻索＝外伤；铜镜（镜光）/瓦瓷印（灵光）/小葫芦（灵气）/聚魂幡（魂噬）/全部识海法术＝法伤。
**敌方**：野兽爪牙撞击为外伤（草蛇/金蟾/鼠精/野猪/山羊/黄蜂/石头精）；妖法为法伤（火狸妖火、野乌妖光、小蛟蛟息）。

**双防白板**：多数 0；坦克型给防御——瓦瓷印 6/6、金蟾 8/2、野猪 4/0、山羊 3/3、小蛟 0/4、石头精 12/6、火狸 0/2、道童 2/2。

## 4. 敌方成长（`balance.applyEffectiveStats`）

| 项 | 公式 | 说明 |
| --- | --- | --- |
| 双防 | `白板 + round(关卡 × 0.8)` | 外防法防同加；stage 20 约 +16 点 ≈ 对无穿透攻击减伤 10% |
| 双伤 | `攻 × (1 + min(10%, 关卡 × 0.8%))` | 折入攻击，封顶 +10%，与既有 atkDrift 合计仍在 ±15% 校准带内 |
| 暴击 | `stage≥5 的 Boss：10% 暴击 / 150% 暴伤` | `BALANCE.critBossStage/bossCritChance` |

## 5. 与法宝双模式的交互

- **held 法宝**：继承主角攻速（atkSpeedPct 压 CD）；主动技封印，故 **skillCdrPct 不生效**；暴击自身掷点（全队通用后不再是"继承"特权，但手持仍享重量攻加成）。
- **station 法宝**：主动技生效 → skillCdrPct 压其等效 CD；不吃攻速（保持差异化）。
- 同一件瓦瓷印：station 时是"高双防+护盾"的前排法伤单位；held 时封印护盾退化为法伤普攻。

## 6. 装备来源速查（详见 EQUIPMENT.md）

主属性：衣=外防、玉=法防、戒=暴击、链=法伤（其余：帽生命/鞋全冷却/腕攻击）。
词条池新增：外伤%/法伤%/外防+/法防+/技能冷却%；仙品专属新增衣·**阴阳护体**（双防各+8 基准）。
