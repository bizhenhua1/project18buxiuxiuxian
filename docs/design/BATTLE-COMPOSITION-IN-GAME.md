# 单局卡牌布局落地 · 2026-09-07

依据作者选定的 B 方案布局截图与 samples/card-composition-reference.json。本轮改动已接入正式 expedition_route 使用的 BattleArena/BattleCard，网页小样继续作为调参参考。

## 构图

以 130×280 为卡牌基准，5 为间距。窗口变化时等比缩放，不独立拉伸宽高。敌方上方居中，己方下方单行居中；平时只显示实际阵容，整备时显示容量槽位。中央保留景观与弹道空间。景观延伸到整个阵列背景，保留敌我阵列横向全宽底框，深色半透明底与金色拼接边角，绘制在景观之上、卡牌之下；敌方底框随战斗显隐，己方底框常驻；战斗只通过地平线比例从 0.48 平滑变到 0.43 调整镜头。

直角深蓝卡底；血球直径 75、外环直径 80、环宽 4，中心位于卡宽 50%、卡高 83%。按真实生命液位绘制，外环仍使用真实冷却进度。手持与术法继续使用其规则对应的状态符号，不编造独立血量。等级、模式与护盾信息保留。

卡名默认隐藏，左下角按钮可控制敌我卡名，写入 user://battle-presentation.cfg；隐藏后仍能通过悬浮和点击详情辨识。名字开关不改变卡牌尺寸。

## 立绘与入场

使用现有透明资产的有效边界，人物沿用上半身裁切，人物、完整器物/兽形分别约束构图。遮罩为卡宽 93%、卡高 85%，立绘在遮罩高度 70%～83% 渐隐；只在渐隐带分条绘制，非序列帧，不影响血球与文字。

怪物飞入卡牌的终点与卡牌共用 portrait_rect，避免仍落到旧版短卡的立绘位置。入场节奏、行走、攻击、结算规则不改变。

目前不是完整资产标注系统：尚未逐个标记脸部、主体框和尾巴等附属部分。分类构图是当前回退策略，不能把道童的原始偏移套用给所有资产；后续增加可编辑资产焦点数据与标注入口。

## 验收

实际 GPU 截图：godot/captures/battle-composition，覆盖 1600×960、1000×650、2545×1301，以及显示卡名、整备。检查卡牌比例、阵列边界、中央间隔与整备位置。

连续战斗测试通过：多次遭遇、原场景与己方卡牌常驻、暂停、敌方清场、奖励及检查点恢复。战斗交互测试通过：拖拽、手持生命继承、开始/暂停/重置、单次结算及全部 24 种卡牌行动。

入口：godot/run.ps1 -Adventure，为独立存档的可操作局内验收；正式主岛出征也使用本轮实现。
