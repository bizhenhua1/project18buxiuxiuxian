# 程序化战斗布局小样

入口：项目根目录 battle-layout-lab.html。通过本地网页服务打开，使用真实游戏图像与 HTML/CSS 排版，三种卡牌比例及尺寸滑杆，不承担战斗逻辑验证。

作者明确保留原 Demo 的圆形血球＋外围圆形进度条，不能用直线冷却条替换。当前小样用液面、球面高光、血量数字及外环示意此结构；生命与进度为固定占位，不是实时战斗数据。手持与术法位保留独立状态标记。

“显示卡牌名”开关同时控制敌我卡牌，切换布局后保留选择，并保存在当前浏览器本地。隐藏只改变视觉排版，不删除名称；悬浮提示、点击详情与无障碍名称仍可辨认卡牌。隐藏后纵向卡牌释放名字所占空间给图像，卡片外框尺寸不变，便于公平比较。

2026-09-07：已将作者选定的纵向比例、血球与圆环、名字开关接入正式 Godot 局内，见 [游戏内落地](BATTLE-COMPOSITION-IN-GAME.md)。网页仍独立调参，修改网页参数不会自动修改游戏。
