# 卡牌设计台

2026-09-07：作者选定的卡面比例、血球、外环、渐隐及名称显隐已用于游戏内，见 [落地说明](BATTLE-COMPOSITION-IN-GAME.md)。以下“尚未实现”指完整资产焦点标注功能；网页 JSON 仍不自动热更新游戏。

## 作者选定的构图基准

参数原件保存于 samples/card-composition-reference.json。作者认可的是比例和整体感受，而非跨资产照搬立绘缩放偏移：130×280 直角窄长卡、深蓝底、顶边名称；血球直径 75、外环直径 80，中心在卡高 83%；立绘下方渐隐。名称显隐仍是可选项。血量 74、进度 72 仅为预览样本，不改变数值规则。

需要拆分卡面模板与资产构图数据：模板记录遮罩区域、人物脸部/器物视觉中心的目标位置、主体目标占比、渐隐及血球区域；资产记录透明有效边界、脸部或主体焦点、用于缩放的主体框与必要的人工偏移。道童的 250% 缩放与偏移只适用于该资产，不应直接应用于其他角色、怪物或法宝。

自动化可先从 alpha 获取有效边界，消除透明留白的差异；脸部、主体焦点与主体框需要视觉判断，尾巴、武器、光效不能一律算进主体。后续标注入口应支持原图点选焦点、框选主体并逐资产保存，允许作者修正；未确认的数据应标为候选，不能宣称已完成全资产自动对齐。目前仅归档基准与规则，尚未实现上述标注功能。

本地入口：card-design-lab.html；battle-layout-lab.html 顶栏有入口，设计台可返回布局页。纯程序化 SVG 预览，不生成图片资产替代排版。

44 项可调参数：卡宽高、圆角、边框和配色；名称显示、位置和字号；立绘选择/本地上传、遮罩位置尺寸、矩形/圆角/椭圆/无遮罩、卡面裁切、立绘缩放偏移和透明度；底部渐隐开关、起止位置；血球位置直径、血量液位颜色和数字；圆环位置直径、粗细、进度、起点、配色及与血球的上下层级。

立绘遮罩、底部渐隐只作用于立绘，血球与进度环各自独立，名字可隐藏。放大预览带辅助线，实际像素预览无辅助线。超出卡面的元素纳入导出边界。

本地保存到浏览器，可导入/导出 JSON；导出 SVG 与 PNG 时嵌入立绘，不含辅助线和棋盘背景。本地图片不上传服务器。JSON 是本工具设计参数，目前未直接接入 Godot 场景。浏览器字体与 Godot 字体可能存在字形和度量差异，正式落地仍需核对。
