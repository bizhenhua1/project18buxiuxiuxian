# 战斗特效技术样板

开发入口：`./godot/run.ps1 -VFX`。独立3D试验场，复用角色、武器挂点、动作库；尚未覆盖正式战斗特效，也不是已保存的传统战斗摄像机模板。

剑击：动态 ImmediateMesh 记录实际武器刃部的短期轨迹，排线材质负责边缘、颜色与衰减，目标端独立粒子受击。角色最多前进0.85米后返回。四个剑动作轮换，目前命中点按统一归一化时间演示，正式接入前仍需逐动作标定。

火球：扰动球网格、连续噪声火焰材质、三片交叉火焰尾部网格、世界空间余烬和爆裂粒子；有限范围短暂点光源仅用于火球。弹体抵达后触发 impacted 信号，不在释放时提前命中。

无序列帧、无特效图片生成、无贴图图集播放。现用 Compatibility 渲染器可运行。发射器、火球、爆裂、尾焰对象预建复用，刀光网格复用，采样历史最多18条。

验证：test_combat_vfx_sample.gd 实际渲染两组样板，检查回位、弹道完成与截图；素材测试与美术质量确认分开，运行通过不等于已完成整场战斗适配。
