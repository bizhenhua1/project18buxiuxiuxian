# 无限模式的持续路线

普通推进不能调用 change_scene_to_file，只有「从头开始」允许重建无限场景。append_leg 在一段事件结束、角色已退出战斗后扩展当前场景。

连续性约束：摄像机、角色节点、队伍、行囊、elapsed 和 distance 保留。新路段从旧路当前 pose 接出，ForestRoute 的 origin/origin_s/origin_heading 负责将下一段局部几何接入既有世界坐标。地面材质使用相同路线坐标变换，贴图和地形高度仍在世界坐标采样。

只保留附近旧装饰并补充前方新装饰，重用已加载的纹理图集和渲染节点，更新排序缓存；避免无限累积已走过的几何。世界坐标和总路程不回到零。后续路段第一段使用步行速度，不重新播放初次跑步入场。

回归：test_endless_manual 检查手动选择、死亡等待、续接机位及节点不变、仅显式重开换场景。test_endless_progression 驱动11次岔路和22次事件，检查进度单调、同一场景和角色、超过原始固定路线长度后仍可推进。
