# Epic Toon FX 1.81 资产浏览与传统场景测试

入口：项目根目录「启动VFX特效预览.cmd」。

## 默认模式
沿用游戏的传统 2.5D 场景、保存的战斗机位与队伍站位。
角色仍由各自的模型窗口渲染，特效由透明层投影合成。
**没有将正式游戏改为统一 3D 世界，也没有替换正式战斗的特效。**
独立资产观察用于查看原素材的粒子表现，不是新的局内模式。

## 目录
1,447 个原包预制体条目，包括 1,325 个独立粒子效果与 115 个可解析的演示组合，共 1,440 个可播放条目。
剩余 7 项没有可直接运行的粒子层，会在列表中标记待处理。
按用途、类别、系列、配色筛选，也可搜索名称。配色变种保留为独立条目。
原包自带的粒子贴图动画可以筛选显示；按粒子寿命选格，绝不整张播放图集，也没有新生成序列帧。

## 武器与动作
剑光自动装剑，默认按剑连招 1—4 轮换；飞弹/释放类自动装法杖并使用法师动作。
可手动选择对应攻击动作、更换角色及敌方目标。
预览武器使用现有掌心挂点、握指修正与武器动画轨道；旧的保存装备在该测试实例中隐藏，防止重复持剑。
实际装备存档不写入。

刀光取当前剑柄、剑尖的角色摄像机投影，计算方向、长度与中心。
从原网格 UV/透明度估计亮部中心，再把亮部对齐到剑身附近，避免仅对齐一个不可见的根节点。
角色前移保留在原模型窗口的小范围位移，不调整场景摄像机。
默认连招释放/命中窗口按动作进度安排，尚未逐帧标注全部职业动作。

## 飞行与命中算法
释放点来自当前法杖端部投影。
对起点、终点记录屏幕坐标 P0/P1 及路径深度 D0/D1，
深度随路程比例 t 插值，屏幕位置使用：
P(t) = lerp(P0*D0, P1*D1, t) / lerp(D0, D1, t)。
尺寸由两端角色体型对应的比例做倒数插值。
t 由虚拟路程与可调飞弹速度推进，到终点才调用命中特效；不硬设相同到达秒数。

115 组释放、飞弹、命中特效通过原包脚本字段的 GUID 引用连接。
有对应关系时优先使用原组合，不混配别种颜色的爆炸。
没有可靠关联时不会凭空追加一个通用爆炸。
原包的大范围发射默认根据角色/目标体型限制显示尺寸，可手动放大。

此算法负责当前画面的相对空间感，没有把树木、卡牌变成物理碰撞体。
树木对特效的精确遮挡和完整场景深度碰撞尚未接入。

## 原素材适配边界
原贴图、16 个引用网格、发射数量、寿命/大小/颜色曲线已导入。
支持球体、半球、锥体、盒体、圆、边缘等基础形状，以及时间/距离发射、随机图格/原包粒子图格动画。
保留本地/世界模拟的区分；移动粒子尾迹保留在经过的位置。
资源与实例缓存避免重复读取，并限制空闲实例池中的资产种类。

这是 Godot 适配，不是 Unity 原生播放。曲线采用 33 点采样，噪声为连续近似。
粒子尾带、部分网格表面发射、子发射器、原场景碰撞、粒子灯和自定义脚本并未完整迁移；
对应条目右侧显示限制，不将这些差异隐藏为“完全还原”。
