# 浮空岛厚度与侧面材质

2026-09-06：主岛、冒险岛共用 IslandView3D 的实体岛体实现。保留规整方块轮廓，增加纵向厚度和岩土质感。本轮向下延伸岛体，地表高度、建筑锚点、行走路径与存档高度不变。

## 连续岛体

旧版所有方块厚度均为 `0.88 * HEIGHT`，约 0.20；相邻地表高差超过厚度时会形成透空缝。

新版共享岛底：`bedrock_y = min(cell.h * HEIGHT) - BASE_DEPTH`，`BASE_DEPTH = 1.15`。每个方块厚度为 `cell.h * HEIGHT - bedrock_y`，顶部仍在原高度。高地自然拥有更长的崖壁，所有柱体的底面相接。保留实体顶盖承接地表插画的透明边缘；不通过横向重叠来遮缝，避免共面闪烁。

## 材质与纹理坐标

使用已有 `assets/cave/ground-tile.png` 的岩石纹理，通过亮度调制地块原有的土褐、灰岩和水边色彩。未探索方块禁用岩石纹理，继续使用迷雾颜色、亮度与饱和度规则。

专用 `island_cliff.gdshader` 使用方块局部位置投影，纹理密度固定为每世界单位 1.6 次。局部轴的全局偏移为 `(-r, c) * sqrt(0.5)`，纵坐标为实际高度，因此相邻同向面连续，旋转时纹理不游动，高崖不拉伸。顶部 0.19 单位内收敛为土层，底部逐渐压暗至 68%，结合面朝向明暗表现厚度。顶面继续使用原插画。

当前保留规则柱体及平齐岛底。悬垂岩尖、根须等属于后续独立装饰层，不改变可建设地块与寻路结构。

## 柔和棱线与虚空渐隐

后续同日调整：侧面着色使用圆角盒子的法线近似，`edge_softness = 0.085`。这是倒角光照，几何轮廓仍为完整方块，不会把相邻柱体削开产生新缝。如果继续柔化轮廓，应仅处理岛屿外露边界，并同步裁切顶面或用垂草、根须遮盖；不可直接缩小全部方块。

底部按距共同岛底的世界高度渐隐，`fade_height = 0.85`。使用 smoothstep 和小幅岩石纹理扰动，避免各块因自身高度不同出现参差的渐隐带。实际材质采用 Godot 的 `ALPHA` 与 `depth_prepass_alpha`，背面剔除，上部完全不透明、下部平滑透明，融入当前背景而非写死雾颜色。不使用序列帧，也不依赖体积雾。

在本机 Compatibility 渲染器实际对比后，未采用 Alpha Hash：本次画面出现明显底部条带；平滑透明方案的实际截图更符合目标。深度预通过并不能保证所有透明排序情形都正确，后续若加入透明水体、前景雾片，仍需复查与岛体的交叠。现阶段验证主岛及冒险岛旋转和大小窗口。

官方接口依据：[Godot 4.7 Spatial Shader](https://docs.godotengine.org/en/4.7/tutorials/shaders/shader_reference/spatial_shader.html)。这里使用引擎现成透明机制，加项目自己的高度渐隐公式，不是引入第三方完整效果包。

## 崖沿小样与已撤回方案

作者后续选择 A。B/C 仅保留为历史对照，不作为推荐正式方向；当前工作转为 [A 岛体地表与立面贴图选型](ISLAND-MATERIAL-STUDIES.md)。

整圈顶图延伸、草根状包边方案已被作者否定并撤回。原因：顶图纵向取样产生流苏/包边感，石地变成薄贴皮，装饰密度过高。正式主岛、冒险岛恢复干净的侧面与已认可的底部渐隐，不自动采用实验小样。

`rim_study.tscn` 提供同镜头、同材质、同一布局的三列对照，上排草地与石地近景，下排整岛，Q / E 同步旋转。入口：主岛“表现样本”→“崖沿 A / B / C”。小样不读取或写入用户存档。

- A：恢复后的基线。
- B：真实窄倒角，石地宽 0.025 世界单位，草地 0.014。仅低邻接或无邻接边缘处理，同高内边保留。顶面与崖壁使用同一组边界点，避免独立缩小地块造成透空。
- C：局部不规则缺口，石地最大宽 0.077，草地 0.034；少量程序化草簇。用于比较更明显的轮廓变化，不作为正式成品。

本轮视觉判断：B 更适合日常地块，但提升克制；C 的凹缺在全岛重复时偏波浪状，草簇仍是几何占位，不能直接推广。后续更强的破损应限定于少数特殊地块，并使用有结构方向的断面设计。

实验实现独立在 `rim_study_view.gd`，尚未覆盖正式探索中的动态地表替换与破损边缘拾取；确定方向后再整合这些行为。它复用已认可的侧面与渐隐着色器；透明自定义网格的叠加表现仍需在整合时进一步对齐基线。原始素材未修改。

## 地块头部选中反馈

选中/悬停仍使用原 `can_visit` 状态颜色：可进入为 `c5e9a5`，不可进入为 `d59075`，地表本身的亮度与迷雾颜色规则不变。保留顶面轮廓，侧面只从地表向下延伸 0.24 世界单位，用 smoothstep 渐隐；垂直角线更清楚，面填充很淡。超过该范围的像素直接丢弃，不再高亮整根柱体，也不再绘制建筑或树木的透视剪影。

`island_selection_head.gdshader` 按真实柱体高度计算距顶面距离，因而不同高度地块的高亮长度一致。反馈仍可在遮挡时提示地块位置。`capture_selection_head.gd` 验证颜色沿用原状态，并检查地块与植被位置、旋转后的实际截图；`test_world.gd` 保留探索与拾取回归。

可见性调整：作者明确否定粗描边和黑色衬边，已撤回。保持原细轮廓，通过状态色饱和度与亮度增强、顶面 34% 半透明染色、侧面顶部约 48% 覆盖来提升识别；侧面颜色在原有 0.24 单位内平滑衰减至零。不得再用增加边框粗细代替表面颜色调整。状态判定与色相归属不变。新增亮色迷雾上的可进入/不可进入两种颜色截图检查。

## 地块与物件合并反馈（当前）

作者要求对齐原版 `world-demo.html` 的 `paintCellMask` / `drawHoverXray`：原版合并地块与可见物件 alpha 遮罩，再对合并结果取外轮廓；遮挡区域显示淡色透视。本次恢复物件透视，取代上文曾移除物件剪影的处理。

Godot 使用屏幕空间的顶面菱形与物件 alpha 的并集生成约 1.2 像素细外轮廓；相交位置不再各自描边。物件有淡状态色，深度被遮挡处叠加透视剪影。地块侧面继续使用当前 0.24 单位渐隐，不恢复整柱高亮。未知地块不显示隐藏物件。`capture_selection_head.gd` 覆盖草地、石地、树丛、古树和迷雾状态。

原版网页仍需要本地 HTTP 服务加载模块；新增根目录 `run-web.ps1`（默认完整游戏，`-World` 打开浮岛原型），只监听 127.0.0.1:8000。2026-09-06 排查时该预览服务未运行；启动后原版浮岛已实测正常绘制，未修改原版 HTML。

合并染色修正：顶面与物件不仅共享轮廓，还对并集遮罩只染色一次（34% 覆盖、相同状态色增强）。有物件时关闭单独的顶面染色与物件深度剪影叠层，避免建筑表面出现地块菱形分色；短侧面渐隐也扣除物件 alpha，防止建筑基脚重复着色。合并遮罩仍覆盖遮挡区域，保留淡色透视提示。无物件地块沿用独立头部效果。截图验证增加小屋案例。

`test_world.gd` 覆盖全部样本岛的顶面高度、共同岛底、最小厚度与纹理坐标，保留八方向的 2D/3D 地表投影对照和原生点击行走测试。`capture_home.gd` 与 `capture_modules.gd` 输出主岛、冒险岛、旋转视角和大小窗口的实际渲染画面。
