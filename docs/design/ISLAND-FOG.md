# 岛屿未探索封雾与开格表现

本轮实现：2026-09-06。用于共享的 IslandView3D；美术效果待作者实际验收。

后续反馈：作者认可萦绕感、散雾过渡和内容浮现，认为雾纹偏丑。尝试低频拉伸云纹后，作者明确认为更差：该版本已撤回，恢复前一版纹理，动态效果保留。前一版纹理也未获美术认可，不能视为最终方案。后续应针对云雾的形态、立体层次与边缘设计做可对照小样，避免仅降低噪声频率造成平滑色块。

## 表现结构

未探索地块不再显示原来的高反差黑白云纹图片。底层使用不透明的青灰流雾遮住真实地表，叠加一层朝向摄像机的软边薄雾，浮在格面上方，稍微越过边缘。两个不同尺度、不同方向的噪声缓慢流动；噪声以地块的世界网格坐标为种子，同高度相邻格面的底层纹理连续。

底层必须保持完全遮蔽，不能用稀疏粒子代替，否则会提前泄露地形内容。未知物件的原画颜色与细节隐藏，按作者最新要求将其外形表现成云雾。薄雾是视觉层，不影响点击、视野、寻路和地块颜色语义；已认可的选中轮廓与染色保持原有规则。

## 物件合入封雾小样

**当前修正，覆盖下文旧的分材质试验：**作者指出物件在立面内部有明显轮廓，真正要求的是并集轮廓统一贴雾。现在由 island_fog_union 在同一张朝向摄像机的平面上，先对地块顶面投影、四个侧面投影、物件透明遮罩取最大值，再统一计算雾纹、透明尾缘和消散。未知状态隐藏原立面与原物件，避免重复绘制形成内部边界。平面包围范围包含超出地块的完整物件；旋转、缩放时重新投影更新。

每个地块及其附属物件组成一个并集，保留不同地块之间的空间遮挡；不是把整座岛压成一张覆盖所有角色的画面。通过真实渲染确认前方草丛在立面内部不再有单独的轮廓。开格、预览、选中和点击定位检查通过。

选中反馈同步采用格子顶面与物件外形的并集：未知云雾和散雾过程中也显示统一外轮廓与一次染色，隐藏穿过物件的独立菱形边线。沿用可行走浅绿、不可行走暖橙的状态色，不显示物件原画。capture_selection_head.gd 已覆盖两种状态的未知物件并集轮廓；此规则取代首次试验中“未知物件不参与选中轮廓”的限制。

### 合并平面深度修复

作者截图暴露了合并平面使用单一深度，导致已探索格附近发生错误切割。现保留一次合并着色，但按像素重建顶面、侧面及物件的实际视图深度：各面的投影坐标插值深度，重叠处取最近表面，物件按原画平面的深度参加。通过相机投影矩阵写回深度，不再以承载遮罩的整张平面深度参与遮挡。

test_fog_depth.gd 在八个旋转方向，将已探索顶面的可见像素与原生实体几何渲染作对照，允许边缘抗锯齿误差，已通过。capture_island_fog.gd 的开格与粒子回收检查也通过。检查范围是当前正交相机；未将此方案声明为支持透视相机。

### 已被替代的首次试验

树木、建筑、岩石、草丛统一通过物件材质接入，与格面和立面使用同一组云雾颜色和流动函数。仅取原画透明轮廓，经多点采样软化及轻微扰动形成云雾外形，不读取原画颜色作为雾色。物件脚下与格面薄雾叠合；这是视觉合并，并非合并几何或真正的体积云。

开格使用同一个 0.28 秒进度从雾形过渡到原画。主角不参与封雾，已知物件保持原材质。未知物件不会触发原画轮廓的选中透视；完成开格后恢复原有合并选中效果。

此方案会提前透露大致物件外形，是此次小样有意展示的体验变化，尚待作者确认。大物件可能遮住后方角色或地块，暂保留现有空间遮挡规则，未声称已经完成所有密集布局的美术验收。

## 云雾立面补充

作者进一步指出立面也需要设计。未知地块原有深色实心侧面改为云雾侧面：顶面与侧面共用 island_fog_field 的坐标、时间和颜色，补偿方体的局部旋转，使顶边纹理衔接。向下逐渐加入云气弯曲、轻微暗部和不齐的透明尾缘，消除“云纹盖在黑柱上”的割裂。

保留网格几何与拾取边界；此版不是体积云，也没有修改已探索地块的岩土材质。开格沿同一个 0.28 秒进度交叉过渡到真实立面，结束后完全回到原材质。此轮已实际渲染检查，待作者确认外观。

## 开格时序

仅在模型从未知变成已知时开始，保持原来的抵达后探索规则。总时长 0.28 秒：底雾按噪声差异消退，上层薄雾抬升并扩散，物件在前约 0.21 秒内淡入，立面由未知颜色过渡到真实材质颜色。完成后隐藏两层雾。

开始时发射一次 10 个 CPUParticles3D 软粒子，寿命 0.28 秒，向外散开并淡出，结束释放。粒子形状由径向透明度 Shader 生成，无序列帧、无新增图片、无逐格常驻粒子发射器。全貌预览直接显示内容，不触发散雾。

动画属于显示层，不新增输入锁定或行走等待。参数入口为 IslandView3D.CLEAR_SECONDS、fog_burst 和 island_fog.gdshader。若以后同时批量揭开大量地块，应先测量透明叠加开销，再考虑共享粒子池；当前不宣称已完成大地图性能验收。

## 验证

capture_island_fog.gd 已验证抵达前隐藏真实地表且物件为完全云雾模式、抵达后才启动、0.28 秒完成、输入不被锁定、一次性粒子正常释放、预览直接显示；实际渲染截图位于 godot/captures/island-fog。capture_selection_head.gd 通过已知物件合并选中与未知格状态色检查。

test_world.gd 通过原版 192 组视野/探索样本及 224 组投影位置检查，包括行走、存档和真实 3D 点击定位。
