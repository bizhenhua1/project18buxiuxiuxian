# 岛屿水位、岸线与流动

## 当前接入范围

最新规则修正：作者要求所有外露水体立面都有落水。已替代下文旧的单出口试验：对每个水格生成 waterfall_edges，所有无邻格的外边均生成全宽水幕，同水位相邻水格与高岸接面不生成。距离场改为从所有外沿共同向内计算。水纹按岛屿空间位置和真实高度采样，转角纹理连续，速度不随面宽或相机角度改变。上段写入深度，避免旋转后前后水幕重复透明叠加，末端仍淡出。

新增八个朝向的实际渲染，并验证 32 岛全部外露边均有对应面、内部接面没有水幕。正常的透视缩短保留；瀑布未改成始终朝向摄像机的图片。

接缝柔化：保留全宽水幕几何与深度遮挡，上沿向下 0.22 世界单位内由深青水色渐变为亮流水；左右各约 16% 面宽作为亮度过渡带，中间保持宽幅落水。不裁窄水幕，也不以额外透明叠层制造过渡，避免重新引入旋转叠影。已重新渲染八个朝向。

视野明暗修复：瀑布材质使用所属格子的 brightness 与 saturation，与水面同时响应离开视野、悬浮和全貌预览；此前水幕遗漏这两个参数，造成地图变暗而瀑布仍亮。新增视野外参数一致性检查与实际截图 out-of-sight.png，已通过。

冒险岛初始化区域时调用 IslandWater.solve，对原有候选水格进行水位求解，再重建显示。原版网页与 world_samples 原始资源未改；主岛当前没有新增水体。此阶段修正现有水格布局，并非完整的河道开挖或动态水模拟。

## 高度约束

按四邻接收集连通水格，每片水体共用 water_level。水位取原候选水格最低高度与最低邻岸减 0.35 两者较低值，保证平水面且低于邻岸。水底 bed_h 单独记录为水位减 0.65；当前水面不透明，水底尚未单独绘制为可见的水下网格。h 保持现有投影、选格和角色脚点所需的表面高度。

保留 source_h 避免重复求解导致水位不断下降。不同连通水体分别求解。此阶段不会改造附近陆地，通路逻辑沿用现有规则，不自动新增深水阻挡或桥梁。

## 岸线与流动

四向邻接数据标记水陆边缘，水面 Shader 只在这些边缘增加浅水色带和波纹，相邻水格内部不套岸框。流动采用世界网格坐标的两层噪声位移叠加现有水面美术纹理。封闭池塘保持缓慢波动；接触岛缘的水体选取一个出口，用从出口向内的距离场给出各格的流向。

出口增加一张沿边缘垂下的窄水幕，纹理向下移动、末端淡出，无序列帧。只在选定出口显示水幕，不把所有水体侧面做成流水。其余立面仍为暗色岩床材质。未探索时隐藏水面和水幕，随现有揭雾进度出现。

## 限制与后续

目前所有同一连通水格采用一个平水位，未生成多级河道之间的跌水。出口按稳定的遍历顺序选择，尚未按流量和完整岸堤几何计算溢流；要扩展为河流生成器，需要先定义源头、河槽和分段水位，再处理坡降连接。陆地立面水位处的湿痕与水下床体细化也尚未实现。

## 验证

test_island_water 检查 32 岛共 158 水格：连通高度一致、水底低于水面、岸地高于水面、水陆岸线标记及重复求解稳定性；另验证封闭九格池塘不生成瀑布。已实际渲染池塘和岛缘落水小样，截图在 godot/captures/island-water。test_journey 的三个遭遇、奖励、32 岛与恢复保存回归通过。
