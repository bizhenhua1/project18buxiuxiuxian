# 原生3D森林独立样板

入口：项目根目录「启动原生3D森林.cmd」。场景 native3d_forest.tscn。

完全独立的 Node3D 场景；不替换旧模式，不读写旧冒险存档。
角色模型、地形网格、植被面片与雾共享 World3D，由一台 Camera3D 拍摄。复用现有美术、重定向动作、版画材质与 BattleModel。

## 空间约定
Godot 米制单位，Y 向上，路线初始沿 -Z。行进主角位于路线左侧，镜头保持默认路线偏移。战场中心在遇敌点前方7米；弧形我方阵列位于中心后侧，敌方在前方。主角卡位可在行进时切换。
入阵使用具有前向控制点的三次贝塞尔路径；外侧卡位较前、内侧卡位较后。离阵终点在战场前方，角色先向前跑再汇合。镜头独立追踪预先计算的战场机位与注视点。
选择事件时先对准战场；确认战斗后入阵。战败/复活期间冻结镜头、保持队员位置。原地恢复使用已有死亡与待机动作衔接。

## 验证入口
顶部按钮可触发战斗、交谈、战败、复活、两/三岔路与分支选择；重置按钮只重开本样板。默认约3秒抵达首个事件，后续行进约4秒。林地范围有限，走过65米自动重开样板。
自动测试 test_native3d.gd 检查共享世界、入阵/离阵的正向纵深、原地复活和路线分支。

## 样板边界
这是空间与镜头迁移验证，并非原游戏全量迁移。四个我方单位、三个敌方单位；暂无完整整备与世界存档、布料、完整特效、物理角色碰撞和动态地形导航。路线运动由曲线约束；植被面片使用批量绘制、透明裁切。二维植被转角时仍有纸片限制，暂不启用自由环绕镜头。性能需阶段性对比验证，未承诺60帧。
