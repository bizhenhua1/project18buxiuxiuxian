# 场景站位式战斗 · 第一版

保留 BattleModel 的单位、阵容、攻击冷却、伤害、奖励与成长。BattleCard 作为可交互单位视图复用，在场景模式下绘制完整立绘、脚底阴影、圆形血球及冷却环，隐藏卡牌框与阵列底板。切回卡牌模式恢复原框；整备时使用原卡牌操作。

资产新增 agent-rear、medium-rear、watch-front、watch-reverse。两名角色为背侧战斗站姿，怀表作为正反面道具样例，其他封印物暂沿用现有立绘。原始生成稿保存在 assets/generated/scene-battle/rear-pack.png，脚本仅分割、抠图、清理品红和裁边。抠图后强品红残留计数为 0。

默认风格 2 使用场景模式，底部“表现 · 切换”可与卡牌版对比；“道具 · 正反”切换怀表。设置不改变阵容数据。名字开关仍可用。角色和道具尺寸分别控制，前景两侧放背面角色，敌人集中前方，道具在前景错位浮动。

开战沿已有 battle_mix 平滑把镜头倍率从 1 降至 .78，地平线保持基准位置，战后恢复；乘在用户保存镜头参数外，不写回用户镜头存档。场景模式取消飞成卡牌表现，保留接敌与渐入。攻击位移、受击抖动和现有粒子系统复用，不使用序列帧。

当前单位立绘已接入 ForestBatch，使用与树草一致的世界坐标、地形高度、透视和深度排序；血球与交互仍为投影位置的界面控件。行进只显示左下放大半身主角，步行轻微起伏；遇敌约半秒展开近景队友与道具，敌人位于远处。没有做场景物体自动碎开、智能遮挡消隐或实体地形碰撞。按用户要求这些等待实测反馈再决定。后续可用角色/道具锚点元数据深化脚底、武器出口与受击点。

验证：完整两场战斗、奖励、返岛通过；场景/卡牌切换不改变单位数据，切回恢复原底框。2545×1301 正常流程 P95 9.83ms，入场偶发峰值21.71ms，不能宣称所有帧都锁60。

## 登场连续性修正

近景我方允许下半身出画，血球钳制在视口下沿；主角行进和战斗均使用 ForestBatch，反投影保证半身构图连续。敌人交接时保留原位置、尺寸、贴图，再按原左右顺序展开，避免交叉换位。路上实体同帧隐藏，取消场景模式旧卡牌飞入层。镜头先更新，再计算投影；队友在镜头展开过程中渐入，血球稍后显现，0.72秒就位后开始战斗。胜利先消散敌人，再收起我方并恢复行进。

## 越肩镜头与遭遇演出

行进速度145世界单位/秒（原420），约1Hz步行上下起伏。行进采用近处背肩构图，取消屏幕矩形插值；角色始终保持世界尺寸。进入战斗镜头沿路线后移16单位，同时从肩后高度恢复战斗高度，队友从侧方跑入；主怪先独立出现并后跳，其余怪物延迟从侧面跃入。入场0.95秒后开始结算攻击，结束反向恢复镜头。保存的森林镜头参数保持不变，演出偏移仅运行时叠加。敌人使用同一批次着色器的红色流动边缘，依立绘局部高度在下半部渐隐，不使用序列帧。

主角透明度随镜头展开量 smoothstep(0.15,0.80,battle_mix) 变化：推近行进时完全淡出，拉远进入战斗时淡入。仅改变显示透明度，不改变镜头轨迹、世界尺寸或站位。

敌人轮廓仅在全部单位登场完成、进入战斗后用0.4秒渐入。探索及跳跃入场期间无红色边缘。独立的轮廓批次复用同一图集与世界投影，在场景本体之后绘制，允许透过树草看到轮廓；本体继续参与原深度排序。下半部渐隐和流动保留。

战斗取景：仅相机叠加高度10世界单位与向下取景偏移0.19视口高度，使敌人脚底上移至画面约四成高度。沿用2.5D直立立绘投影，以镜头高度和偏移实现构图，未旋转立绘或修改怪物世界坐标。行进肩后高度偏移仍为15，战斗随battle_mix平滑过渡；地面、树草、角色、轮廓共用相机参数。

攻击/受击方向采用双方世界站位连线，不再把屏幕上下方向直接作为世界前后方向。攻击短促蓄力、前冲、回位；受击沿攻击来源反向击退并小幅回弹。伤害事件携带来源（包括反伤），只增加演出元数据，不改变伤害结算。连续打断保留当前偏移平滑接续，按透视深度约束幅度，保持原朝向与静止站位。

## 灯笼与雾

风格2森林启用冷暗环境色，随主角路线及站位移动的暖色灯笼衰减光，带轻微晃动与亮度波动。地面、草木和角色共用世界空间光照函数，不依赖全屏亮斑。低处流雾用世界坐标与连续时间计算，近处较清楚、远处积雾，灯光范围内雾色略暖。使用现有批次着色器，不增加粒子节点或重新撒布；这是风格化光照与雾，不含遮挡投影阴影。

近景补充局部程序流雾层，覆盖道路中下部两处雾带，低频噪声缓慢漂移，避免全森林均匀覆盖。随两处世界灯源投影的雾中光晕独立于角色受光，增加光域可读性而不恢复过黄过亮的人物。风格2共用面板和按钮切换为深灰蓝、旧金属细框、菱形符号，事件窗和整备底板同步，风格1保留原皮肤。

## 世界空间雾修正

已移除屏幕ColorRect雾层及其着色器，解决左半屏直边蒙层。局部雾现在以固定路线坐标的双层雾团表示，同一森林批次按深度绘制；镜头移动不改变雾团锚点，仅雾自身慢速漂移。雾与草木、单位存在前后遮挡，近裁面前柔和淡出，雾色读取世界灯光。实现为2.5D空间雾片，不是全屏滤镜或体积光线追踪。

站位语义修正：左侧人物更远，右侧人物更近。根据视口、眼高与焦距约束最远人物距离，使脚部留在画面下方；不以主角身份打破左右纵深。连续道具在相邻人物之间或队列两端的剩余区间均分，保留卡牌左右顺序。

人物高度根据敌方落脚基准线限制，头顶只高出约4.5%视口高度，缩小立绘同时保留脚部出画、左远右近。道具世界高度由10提高到14，在保留顺序与可用横向区间的前提下采用椭圆前弧纵深，呈环绕错位。

取消主角行进占位及从中间/侧方归位的移动。所有人物直接使用阵容站位淡入淡出，取消步行与跑入起伏；镜头演出与攻击受击位移保留。头顶进一步下降到敌方基准线下约1.5%视口高度。

入退场改为相对追赶：人物以完成态相机计算固定尺寸，入场从镜头后方沿各自槽位追上，在接近站位时渐显；退场队伍前进8单位、相机额外前进36单位，形成接近放大并被超过的淡出效果。相机额外位移在恢复行进时并入路线距离，避免回跳。

### 资产空间标记：头顶与道具离地高度
- `asset_spatial_marks.gd` 记录 Style2 三张怪物 PNG 的原始尺寸、透明裁切范围和头顶像素点；StyleLibrary 中十个怪物 ID 自动对应其皮肤标记。猎犬含耳尖、钟骸含钟顶，飞蛾使用头部触须范围，不按翅尖定位。血球保留原样式，随身体投影、攻击位移和裁切一起移动。
- 道具按资产区分 floating / grounded。怀表离地 22、书 17、面具 19 世界单位并轻微浮动，提灯离地 0 且无浮动。高度相对当前位置地形计算；视角缩放、进退场与遮挡继续共用场景投影及深度顺序，不提升到 UI 层。
- 验证：窗口模式卡牌顺序检查通过；两次完整遭遇战通过并检查截图。无窗口模式顺序检查的头高断言失败，正常窗口模式复验通过；未进行帧率测试。
