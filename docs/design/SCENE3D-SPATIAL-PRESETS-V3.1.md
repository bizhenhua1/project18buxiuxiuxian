# 场景组合分类与低成本室内执行补充 v3.1

本补充负责空间分类、低矮物件室内、吊挂物与最短执行路径，优先于v3中相同范围的泛化表述。属于规范设计，尚未实现运行时功能。新增数值均为 `design_initial`，不是标杆实测。

## 1. 七家族够用吗

七家族足以给当前18景分配工作，但不构成完整、互斥的空间分类。例如“剧场”是用途，“洞穴”是结构，“花园”是环境，不能把它们当成同一维度的枚举来推导全部算法。

保留七家族作为生产文件夹与既有profile兼容字段；生成器的行为改由以下独立维度决定。美术主题只决定图与组合，不决定顶面是否存在。

| 维度 | 允许值 | 由它决定什么 |
|---|---|---|
| topology | corridor / chamber_chain / court / platform_chain / shaft_transition | 路线走廊、连室、开放庭院、架空平台、多层转换 |
| enclosure | open / local_canopy / low_ceiling / vaulted / irregular_tube / partial_ruin | 连续顶壁、局部棚、拱顶、洞壳、明确破口 |
| floor | dry / wet_edge / shallow_water / elevated / stepped | 地面、水边、浅水、桥面、台阶及相应接触 |
| supports | masonry / timber / rock / organic / mechanical / vegetation | 柱梁、挂点和材料能怎样连接 |
| furnishing_height | low / mixed / tall_edge | 低家具与上方构图、普通混合、高柜沿边 |
| identity | 主题主体组ID列表 | 茶桌/锅架/钟摆/书架等；不自动改变上述几何 |

每景必须同时填这六项；不得只写“室内”让执行者现场推导。多层转换只定义连接和镜头过渡接口，不能在本次场景任务中重写已有攀爬系统。

## 2. 推荐预设及扩展边界

下列预设给新场景直接选用；“扩展储备”表示规则可复用，不意味着现在追加制作这些新地图。

| preset_id | 组合 | 现有适用景/用途 | 必有结构 | 禁用捷径 |
|---|---|---|---|---|
| domestic_low | chamber_chain + low_ceiling + dry + timber + low | 外婆小屋、七人旧居 | 连续顶、墙顶收口、门间过渡 | 靠高柜/树填满上部 |
| workshop_low | corridor + low_ceiling + dry + timber + low | 猎人工坊、木偶工坊、厨房 | 顶梁、靠墙台、上挂socket | 放大工具/桶替代工作台 |
| ceremonial_vault | corridor + vaulted + dry + masonry + mixed | 镜宫、错序门厅 | 连续拱顶、柱龛、墙段 | 透明拱图代表屋顶 |
| cave_tube | corridor + irregular_tube + dry + rock + mixed | 山门岩窟 | 环向连续壁顶、岩腔岔路 | 植被填深洞、无顶岩环 |
| cultivated_garden | court + open/local_canopy + dry + vegetation + mixed | 三花园与茶庭 | 花坛/树组、园路、局部藤架 | 统一森林草墙 |
| settlement_street | corridor + local_canopy + dry + masonry/timber + mixed | 红帽村、集市、游园 | 两侧立面与转角、局部门廊 | 全街封低顶 |
| elevated_bridge | platform_chain + open + elevated + masonry + low | 旧桥 | 桥面、外缘栏杆、平台连接 | 用岸草当护栏 |
| backstage | chamber_chain + low_ceiling + dry + timber + mixed | 剧院 | 连续顶、幕框、吊杆与侧台 | 一排完整舞台无限重复 |
| machinery_hall | platform_chain + low_ceiling + dry + mechanical + mixed | 钟楼 | 支座、轴、梁、局部栏边 | 链/齿轮无支撑悬空 |
| sewer_channel | corridor + vaulted + wet_edge + masonry + low | 扩展储备：排水道/水牢 | 干路与水渠独立、拱壁连续、桥接段 | 全路水面覆盖角色脚 |
| organic_tube | corridor + irregular_tube + wet_edge + organic + mixed | 扩展储备：鲸腹/活体建筑 | 连续有机壁、肋架、附着挂点 | 石洞换红色即完成 |
| roofless_ruin | chamber_chain + partial_ruin + dry + masonry + mixed | 扩展储备：废教堂/坍塌屋 | 显式断墙、顶破口、暴露断面 | 把意外漏顶解释成废墟 |
| cliff_platform | platform_chain + open + stepped + rock + low | 扩展储备：悬崖/矿道栈桥 | 高差、踏步/栈道、外缘提示 | 图片遮住断路假装可行走 |
| flooded_chamber | chamber_chain + low_ceiling/vaulted + shallow_water + masonry + mixed | 扩展储备：积水地下室 | 分离水位/地面、干台、墙面水线 | 复用地面碰撞高度作水面 |

雪地、灰烬、沙漠、霉菌、冰封属于材料/覆盖层变化，通常不新增生成算法。图书馆、监牢、墓室、礼拜堂分别是柜架/牢栅/墓龛/祭台主题组合，优先放到已有空间预设。只有真实拓扑、顶壁连接或地面接触规则变化才增加结构预设。

组合限制：`elevated`必须有平台外边界；`partial_ruin`必须提供破口区域；`shallow_water`必须有水位和干地分区；`shaft_transition`必须有目标区域与进出动画钩子。缺少这些字段即 `unsupported_combination`，给出最接近的现有预设，不默默退回森林。

## 3. “低资产室内”同时处理两种含义

**低矮物件**：床、桌、矮柜集中在下部，确实容易让上半幅空。用墙面分区、梁、顶面和吊挂层补全垂直构图，不能把低家具放大。

**较少源图、低制作成本**：用连续简模承担地板/墙/顶，一套材料重复使用；2D贴图承担梁、墙饰、家具与吊挂物的风格。稀疏室内可以是设计结果，只要空间边界、主物和尺度可信，不必强行达到森林的遮挡率。

### 3.1 最小可审查包（覆盖v3完整版数量的前置要求）

这是第一份6–10 m闭合空间候选所需，不是完整冒险资产包：

| 层 | 最低来源数 | 实例初值 | 允许复用 |
|---|---:|---|---|
| 地面、墙、顶 | 2–3张材质 | 各一连续面/分带 | 语义合适的墙顶可共用一张，不允许把有路标的地面当顶 |
| 梁/门框 | 1套 | 每4.5 m一跨 | 同一套先复用；缺变体不阻塞第一次审查 |
| 墙顶收口 | 0–1张 | 沿墙连续 | 可复用梁/材质裁片，或简单几何同材质 |
| 低矮主体 | 2种 | 每2跨一主组，左右错开 | 床+柜/桌+炉；现有完整组合算一来源 |
| 上挂主体 | 1种 | 每2跨最多1个，初始向侧边偏 | 吊灯/锅架/布卷任选一种；不是必须新增图 |
| 小配物 | 2种 | 每跨1–2件 | 使用本景已有箱篮等 |
| 地表细节 | 2种 | 每10 m 3–5小组 | 可来自已有dressing |

合计通常10–12个源素材槽位；共享和已有图可抵扣，不能转译成“必须先生成12张”。拿现有壳图做框、dressing做配物、现有材质做连续面，就可以先提交结构与尺度候选。完整数量仍按v3资产手册逐步补齐。

### 3.2 垂直构图与净空

三层独立：0–1.2 m为低家具；1.2 m到梁底为墙饰/门窗；梁底以上为连续顶与挂点。高度带仅用于设计定位，实际服从角色和相机包络，不能让柜子一律卡1.2 m。

主路上吊灯最低点至少高于该段角色动画最高点0.35 m，同时避开摄像机近裁剪包络0.20 m。侧边可更低，但必须在全分支通路并集之外。不能把“角色会从画面上挡住它”作为不存在碰撞/穿插的理由。

固定战斗镜头中，吊物默认离角色头部/技能中线投影至少画幅短边3%；它可以制造侧边剪影，不能遮选中单位、敌方主要攻击方向。冲突先换socket，再缩小同类允许尺寸，最后取消本实例；不改变镜头/角色比例。

## 4. 吊灯、悬吊人形与其他挂饰

悬吊人形在黑暗童话中可作为稀疏环境叙事主体。本项目默认远中景剪影或衣物包覆的非血腥人形，属于场景道具；不实例化战斗角色控制器，也不参与索敌、血条、阻挡或复活。

| subtype | 默认支撑与形态 | 位置/频度初值 | 动态默认值 | 特别检测 |
|---|---|---|---|---|
| chandelier | 梁/顶锚点→链→灯体 | 每2跨1个以内 | 静态；允许≤2°轻摆 | 灯体最低点、链两端、无每灯真实点光 |
| hanging_figure | 梁锚点→绳索→人形上挂点 | 一个叙事区最多1组、每组1–3体；连续两跨不重复 | 默认静态；需要时1–3°、周期6–10秒 | 挂点连接、摆动包络、身份不是敌人 |
| cloth_banner | 横杆/两点绳→布 | 每1–2跨一片侧挂 | 根固定的低幅shader摆动 | 不遮出口，不把硬架一起扭曲 |
| chain_hook | 顶socket→链/钩 | 每跨0–2，侧边 | 静态为主 | 起止有归属，末端不穿家具 |
| roots_stalactite | 岩顶/墙顶附着 | 每跨1–3轮廓组 | 静态 | 顶根嵌合，不贴在透明空处 |
| cocoon_cage | 枝/梁→绳链→茧或笼 | 每2–3跨一组 | ≤2°可选 | 载体支撑成立，内部不额外启动角色AI |

没有悬吊人形资产时，标注该叙事槽缺图，不拿普通站立角色旋转180°假装完成。现有可用角色模型只有在明确为该道具制作合适固定pose后才可做静态网格候选；优先独立2D剪影/少量侧片。当前18景默认不自动添加悬吊人形：此处建立可选模块，具体故事配方选用后才布置，避免每个室内都变成同一种惊悚房间。

### 4.1 连接与摆动算法

`owner_socket_world → rope top → rope bottom/prop attachment`必须连贯。构件局部原点放在支点，`R(t)=rest_rotation × swing_rotation(t)`；摆角用固定seed相位的低频正弦即可，默认不启用刚体、布料或绳索求解器。不能围绕人形自身中心摆动导致上端脱绳。

绳与主体可合为静态assembly；需要摆动时用同一支点变换，或以实际端点更新一条2–4段线片。主体不弯折时一片/有限厚度就足够；视角超出asset支持范围时加侧片或静态低面体，不对相机实时翻转。

离线/加载时计算全周期扫掠包围，与墙、梁、玩家/相机净空检查。粗检采用包围球，精检只对被选中的少量挂物做离散极值姿态检测；静态边界取角度正负极值，必要时加中间样本。不能每帧遍历所有场景物件进行碰撞。

若碰撞：换侧边socket→缩短悬挂长度（同时更新绳图/几何）→减少摆幅→移除此实例并记录原因。禁止让动画每帧按碰撞结果跳到新位置。

### 4.2 成本约定

普通吊物合入静态批次；初始同屏动态吊物上限8个，悬吊人形上限3个；超出按距离和叙事优先级静态化，保留画面物件。远处不更新摆动或使用共享shader时间。灯光默认emission与已有环境色，新增实时灯数默认0；重点灯仅在已有光预算内替换一个名额。

这些是初始内容约束，不宣称实测上限。不能因为低成本方案可行就为每个吊物创建骨骼、粒子和点光。

## 6. 直接执行、可检测的最小工单

每张工单固定包含：输入路径、选用preset、写入文件、默认参数、操作步骤、最多3项检查、失败出口。没有这七项就不能派给执行模型。已有规范给默认值时直接采用，除非有明确失败证据，不重新调研或广泛询问。

### R01：低顶室内首个可见成果

- 输入：red_cottage现有ground/corridor-shell/structure/dressing与锁定镜头；采用domestic_low。
- 写入：单景candidate profile、连续顶壁实例与必要AssetSpec；不改六基准。
- 默认：6–10 m试段，框架4.5 m，低家具2种，上挂1种（有图才放），连续顶高由已规定净空计算。
- 步骤：确定可走区→铺顶壁→框架接缝→两组低家具→侧挂物→少量碎物。
- 检查：平灰图无非声明漏口；正式图家具比例/头部不遮挡；直行回放无静态跳变。
- 失败出口：缺材质先完成灰模结构图并列具体裁片候选；缺挂物只暂停该槽；**不能因此停止整个房间**。

### R02：挂物装配

- 输入：一个runtime候选挂物、一根绳/链和承重socket；无图不创造假路径。
- 写入：assembly及支点、局部最低点、摆幅/周期/扫掠包围。
- 默认：静态，先连接正确；需要摆动才启用2°、8秒、固定随机相位。
- 检查：绳首尾连续；摆动极值无穿墙/角色通路；正式镜头不遮主体头部与出口。
- 失败出口：按4.1顺序换位/缩短/减幅/移除；最多两轮。

### R03：扩成完整代表景

- 输入：R01已能审查的结构、同景profile；无需先等待全部资产标注或精确深度统计。
- 写入：30 m行进、战斗区、共用两/三岔厅及分支恢复。
- 检查：所有出口可走且顶面单owner；战斗构图保持；左右分支录像无重撒/闪烁。
- 失败出口：局部问题记录到该岔路，不重新收集全部基准。

## 7. 防止“规范越详细，前置检查越多”

检测分级：**必须先查**只有当前工单可能破坏的单位/路径/文件、主通路和可见缺面；**随成果查**是接地、摆动、透视、正式效果；**后置专项**是精确role/depth覆盖率、全种子回归、性能压测。

T02精确深度工具不阻塞R01。T01若两次仍无法可靠冻结，停止修采集平台，采用可复现固定机位的手工/开发开关截图与平灰结构视图，注明无法像素精确比较；不声称中性工具已修复，但继续可见结构工作。若连最低结构视图也不可获得，仅该项验收blocked，继续资产和几何断言，立即报告取景障碍。

先提交R01的小成果，再完成R03；完整版资产配额和全部岔路不是第一张可见成果的前置条件。每轮报告必须说出“场景里哪一处改变了”，否则只能记工具工作，不能记场景进展。
