# 风格 2 · 雾林调查局

## 方向与工艺判断

采用暗黑漫画式二次元：大块墨色阴影、有限明暗分面、成熟人物比例、清晰的道具与怪物轮廓。固定炭黑、灰蓝绿、象牙白、旧黄铜与少量朱红。此前偏写实的五张概念稿归档，不作为生产目标。

参考来源为 [Darkest Dungeon 官方图库](https://www.darkestdungeon.com/darkest-dungeon/media/)、[Limbus Company 官网](https://limbuscompany.com/)、[Chaos Zero Nightmare 官网](https://chaoszeronightmare.onstove.com/en)。以下是本项目的工艺判断，不是对这些游戏内部制作方式的陈述。

| 方向 | 对当前工艺的适配判断 |
|---|---|
| 厚重写实绘画 | 单图表现强，但模块拼接后的光照、材质和尺度难保持一致 |
| 精细商业二次元 | 人物识别清楚，但碎配饰、发丝和高光增加批量抠图与一致性成本 |
| 严格像素风 | 需要统一像素网格与缩放方式，现有自由缩放立绘和透视场景需额外改造 |
| 墨色暗黑漫画＋成熟二次元 | 选定方案；重轮廓和有限明暗适合静态透明立绘、卡牌裁切和模块复用 |

## 实际产物

生成并接入 3 个角色、4 件神奇道具、3 种怪物；环境包含两棵树、钟塔、蕨草、岩石、芦草、灌木、薄雾，以及地表和立面两张材质。共 18 张透明图、2 张材质。卡牌保留圆形血球、圆形进度条、名称隐藏选项与双方阵容底框。角色采用独立近景裁切，世界使用完整立绘。

环境由上述部件和现有透视、揭雾、浮空地块算法组成，不把概念图当作运行背景。此样例外部地块与局内均为森林主题。

## 抠图修正与验收

原处理只去掉高饱和背景，半透明轮廓仍混入品红，部分素材有孤立碎屑。修正包含背景剔除、轮廓去染色、透明像素清色和小碎屑清理；蕨草使用独立碎屑阈值。灵媒原稿背景不适合直接提取，重新生成了纯底版本。

`scripts/build_style2_assets.py` 完成导出后自动执行 `scripts/style2_alpha_qc.py`。该脚本生成深浅双底检查图与检测报告。当前 18 张透明资源的不透明品红像素检测均为 0；这只代表该检测阈值通过，不替代人工检查细发丝和浅色装饰。

原始生成图与精确提示词留在 `assets/generated/style2-production/manifest.json`，原始品红底文件不参与运行。最终资源位于 `godot/assets/style2/`；检查图为 `assets/generated/style2-production/alpha-contact.png`。

## 特效与接入

动态曲线光带、仪式圆弧、几何刻印与原生 GPU 粒子组合；没有序列帧。攻击方向由实际起终点确定。原生粒子沿用有界池，避免每次攻击持续创建节点。

运行 `godot/run.ps1 -Style2` 进入可玩样例，使用独立存档，不覆盖风格 1 存档。样例通过实际地块揭雾、事件阻挡、森林连续两场战斗、结算、返回世界流程。结果及实机图位于 `godot/captures/style2/`。风格 1 战斗交互回归通过。

## 当前边界

这是完整可运行的主题样例，尚非全部游戏剧情与规则重做。底层仍复用原卡牌 ID 和战斗规则，三种怪物立绘供多个数值变体复用，部分通用 UI 装饰仍沿用原资产。后续应增加每个资产的脸部/视觉中心标注，而非对全部角色强套同一裁切参数。
