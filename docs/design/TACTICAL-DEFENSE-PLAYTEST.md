# 战术防守模式 · 首版体验说明

入口：仓库根目录「启动战术防守.cmd」。场景为 tactical_presentation.tscn；复用原 3D 场景、保存的镜头/站位、模型池及投射物表现，战术模拟和界面位于 scripts/tactical。原 3D 迁移入口与模拟规则不被替换。只读取现有阵容，不写回存档或装备。此模式暂隐藏道具卡的场景表现，仅操作现有阵容中的 3D 队员。

点击「开始战术防守」。悬浮角色描边，点击打开菜单；菜单和目标选择期间战斗为 20% 速度，UI 正常响应。关闭、右键或 Esc 恢复正常速度。点击另一名角色切换选择。

- 技能选择器提供攻击回能的贯穿斩、受击回能的守夜领域、自动回能的幽焰爆破与无尽射线。切换技能清空能量，属于首版测试配置入口。满 30 能量可施放。
- 「查看范围」切换实际战斗坐标的投影轮廓。预览与命中使用同一份形状定义。普通直线有射程上限，无尽射线对前向距离不设上限；屏幕轮廓绘制到远处场景。圈型以自身为中心，爆破以自身前方固定距离为中心。
- 换位可点击队友、地面站位圈，或底部八位站位栏。位置分配立即交换，角色实际移动到新站位；死亡中的位置保留，不能交换。
- 职业来自现有武器动作类型：剑士前出迎敌、先锋更深入前出、术士短距离前移、守卫临时增加阻挡。撤退返回当前分配站位。指令打断该单位尚未出手的近战动作，释放阻挡。
- 近身敌人占用阻挡名额，已有关系优先保留，满额后其他敌人继续前进；远程敌人可以在射程内攻击。死亡、撤退或离开接触距离都会释放关系。
- 队长与队员均使用正常血量。只有敌人越线扣防线血量。
- 死亡先完成倒地动作；随后使用现有转化设置的颜色和转化表现，光芒返回当前站位；尸体留在该处，12 秒后重生。重生恢复生命，起身动画结束后继续行动。

首版数值位于 data/tactical_mode.json：回能、能量上限、技能尺寸和伤害、慢速比例、返回与重生时间。波次暂为 60 名来敌，同时存活上限 30，沿用 50 个预热模型实例。此处为可玩验证数值，尚未做最终平衡和各职业完整技能设计。技能释放当前使用范围闪光反馈；未制作专属技能美术。角色拾取使用屏幕投影包围区域，不是逐三角形拾取。

## 验证

- test_tactical_rules.gd：阻挡容量和稳定归属、释放、换位、队长/防线血量隔离、死亡返回与复活、三种回能、有限/无限直线及爆破几何。
- test_tactical_presentation.gd：实际 GPU 窗口、SubViewport 鼠标点击打开菜单、20% 时间缩放及恢复，截图保存至 tempassets/work/tactical-preview.png。
- test_tactical_death.gd：真实角色前出、原地倒地、光芒返回、站位尸体及重生状态，防线血量始终不变。

模拟沿用 20 Hz 固定步长；索敌/邻近避让使用空间索引，阻挡按小规模我方队伍维护；技能只在施放时查询。未开展全地图或长期性能压测。

## 整体选择描边

选择高亮已由逐材质法线膨胀改为角色遮罩合并后取外轮廓。半分辨率独立遮罩视口仅绘制被悬浮/选中的角色及其附件，使用原网格、Skin 与同一骨骼层级，保留现有角色投影参数；画面合成阶段对遮罩膨胀后减去遮罩自身，因此不会在材质与身体接缝处产生高亮。原美术黑色轮廓不受影响。无目标时关闭遮罩更新。当前遮罩不包含其他场景物件的遮挡深度。

GPU 验证 test_tactical_outline.gd 通过：遮罩透明背景、角色覆盖区域有效、主镜头排除遮罩层、复用网格及 Skin、无选择时关闭更新。test_tactical_presentation.gd 仍通过，截图已检查。
