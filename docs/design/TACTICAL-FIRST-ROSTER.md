# 战术防守：第一组角色与战斗规则

2026-09-16。八张角色卡现已接入独立战术防守模式，使用独立的八人测试阵容与装备，不写入原存档。具体映射与测试入口见 TACTICAL-ROSTER-IMPLEMENTATION.md。下方为设计基准，数字是首轮平衡起点；攻击间隔还受对应原动作实际时长约束。

## 已接入的规则

### 嘲讽与阻挡

- 守卫（当前重武器 warrior 动作职业）默认具有嘲讽；菜单“特性 · 嘲讽相邻列”可临时开启或关闭其他队员的能力。
- 列由本场八个站位的横向坐标排序定义；相同横向位置合并。不是根据角色在屏幕上的像素坐标判定。
- 接触阻挡优先；已经被别的队员阻挡的敌人不被抢走。尚未阻挡的敌人，只有处于相邻一列、距离不超过 3.2 米、尚未越过角色身后时，才参与吸引。
- 先保留正在前来接敌的目标，再从新的候选中挑最近者。多个嘲讽者竞争时按双方距离排序，同距离按稳定 ID 排序，不反复横跳。
- 已阻挡人数 + 引敌预占人数不超过阻挡值。例如阻挡 3、已挡 2 时，最多再吸引 1 人。接近后预占转成实际阻挡。正在接触的新敌人优先占位，因此可能取消远处的一次邀请。
- 被吸引者以原有速度走向嘲讽者；近战接近后攻击，远程到自身射程后即可攻击，仍占用一个引敌名额。没有瞬移和额外加速。
- 死亡、换位、撤退、关闭能力释放引敌。技能降低阻挡上限时释放超额预占。为避免边界抖动，已引敌目标有 20% 距离容差。
- 菜单显示实际阻挡、引敌数和剩余名额。开关仅供本场测试，重开恢复职业默认。

这是一条本作的“跨列引敌”规则，不是宣称《明日方舟》的嘲讽机制本来就会改变敌人的路线。

### 朝向

站立且没有有效目标时，从当前位置朝向摄像机前方的远处中央参考点，换位后重新计算。此参考点约在摄像机前方 60 米，视觉上趋向屏幕中线与远方地平线的位置。行走时保留实际移动方向；普攻时面向目标，目标死亡或脱离范围后恢复默认朝向。固定朝前的技能按技能方向面向前方，不继承上一发普攻的侧向目标。死亡与起身过程不强行旋转。

### 两种飞行道具

| 类型 | 发射后的规则 | 命中与丢失目标 |
|---|---|---|
| 指向追踪 | 锁定一个单位 ID，以固定速度追踪其当前身体中心 | 只命中指定单位，不被途中另一只怪截走；目标死亡、漏过防线等失效后消散，不自动重新索敌 |
| 固定弹道 | 记录发射方向后不再拐弯 | 通过真实扫掠碰撞命中第一名敌人，允许被其他敌人挡住，也允许打空 |

远程队员菜单可切换两类普攻；目前队员默认追踪、敌方默认固定弹道，具体弹体表现继续复用当前特效。切换只影响新发射的弹体。固定弹道和穿透次数是独立配置，不能把“非指向”理解成“无限贯通”。下面设计中的定点爆炸、贯穿技能还需要分别接入，不等于本次已经完成。

## 首发八张角色卡设计

所有在场角色使用正常生命值；防线生命归属于场外主角。角色死亡沿用倒地、转化返回原位、重生倒计时机制。职业身份与角色外观分离，装备驱动动作：盾与单手武器、双手锤、剑、矛、法杖沿用已有动作组；不重新加入弓箭。

## 技能空间与提示器约定

- 剑士与长矛：固定向前的长条印记；预览内敌人脚底出现光圈，施放后按同一空间判定结算一次。
- 重装：自身状态技能；提示器显示引敌覆盖距离，突出相邻列候选，已经引敌者与已阻挡者分别显示数量，不能拿通用圆形伤害范围误导玩家。
- 火球：地面落点圆形＋飞行路径；锁点后即使敌人移动也不追踪。圈内显示的是当前覆盖人数，不承诺飞行抵达时仍会命中这些人。
- 飞针：显示索敌范围和最多三个候选目标；单枚发射时锁定，目标消失则该针消散，后续尚未发射的针可重新索敌。
- 医师：友方范围、治疗色，不给敌人显示受击光圈；治疗目标不是伤害目标。
- 纺女：固定区域，只结算区域内敌人；多片同名区域伤害取最高档、减速取最强档，避免重叠导致异常倍增。
- 清道夫：矩形与后退方向箭头；位移以敌人重量限制，不能用强制位移反复穿过防线扣血，也不能推到不可达的树林深处。
- 朝向是表现，范围是权威逻辑。普攻可以朝目标转身，不意味着已锁定的固定方向技能会偷偷旋转。未来若支持手动旋转技能，必须同时旋转指示器、命中体和角色出手方向。

## 一组可以形成决策的搭配

**聚怪焚烧**：门卫吸引邻列 → 纺女延缓余下怪群 → 卖火人锁定门卫前方爆破。代价是单体远程威胁与门卫生命压力，需要守灯人支持。

**机动截流**：十二前出截住一组 → 女仆换位打穿长条 → 裁缝优先清漏怪。代价是换位时释放阻挡和嘲讽，不能无成本地持续搬动前排。

**推回火场**：灰把接近防线的怪推回已有余烬或迟滞区域。重型与首领有明确位移抵抗，避免形成无限推退。

首轮体验建议先用门卫、女仆、卖火人、守灯人四张牌做出完整闭环，再增加余下四张。冒险中的抽牌可以是“加入一位角色 / 强化一个技能 / 获得一个藏品”，不用一开始就把八种职责全塞入同一队伍。

## 长线与局内 Build

长线解锁角色、故事档案、外观和横向技能分支。局内抽牌改变组合与打法，优先做横向改变：嘲讽距离与容量二选一；火球爆炸扩大但飞行变慢；银针变固定贯通而失去追踪；剑士第四击由加伤改为击退。这些应是明确的取舍，避免全是数值加成。

首轮不加入数十种异常状态。先统一实现：减伤、护盾、治疗、减速、有限击退、持续区域、有限多弹道。每种状态必须写明刷新、叠加、死亡清理和复活恢复规则。

## 成本边界

本次嘲讽在战斗固定逻辑步内复用已有空间索引找邻近敌人；请求排序以局内人数为界，没有增加导航网格寻路或模型渲染。弹道继续共用原扫掠碰撞与可复用特效，追踪仅多一次朝目标重算速度方向。

后续卡牌技能必须把逻辑与表现分离：范围伤害按固定间隔查询，视觉粒子可以降级但不能漏掉伤害；七枚银针是一枚一枚调度，不生成七个独立角色控制器。火球爆炸继续使用受预算控制的亮度脉冲，不给每个碎片新建动态灯。
