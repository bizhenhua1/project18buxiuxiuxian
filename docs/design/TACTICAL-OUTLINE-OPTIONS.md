# 角色选择描边：调研与四种实机方案

## 结论

继续使用整名角色的独立遮罩，只在整体外轮廓绘制高亮。旧实现的半分辨率遮罩和 3×3 方形膨胀会放大阶梯边缘。现在改为与游戏内容视口相同分辨率的遮罩、4× MSAA 和 16 方向圆形采样；光晕采用两圈加权采样。原材质与内部美术黑线保留，不再给每个子网格加选择颜色。

## 技术路线比较与依据

| 路线 | 特点 | 本项目判断 |
|---|---|---|
| 法线膨胀外壳 | 直接扩大模型轮廓 | 分离的服装/饰品会出现不需要的内部边界，不采用作为选择高亮 |
| 场景深度/法线检测 | 可以发现场景中的几何边缘 | 会包含内部结构，选择单一角色还要单独筛选，不是这次问题的直接答案 |
| 单独角色遮罩 + 屏幕轮廓 | 多网格先合成为一个覆盖区域，再减去内部 | 适合当前角色选择，继续使用并改善采样质量 |

上述遮罩路线参考 [Ronja：Object Outlines](https://www.ronja-tutorials.com/post/052-object-outline/)，其关键是先将选中对象绘制到单独纹理，再从邻域覆盖中减去对象自身。路线比较还参考作者的 [Postprocessing Outlines](https://www.ronja-tutorials.com/post/019-postprocessing-outlines/)。代码为本项目的 Godot 实现。

[Godot 官方抗锯齿说明](https://docs.godotengine.org/en/stable/tutorials/3d/3d_antialiasing.html)说明了几何边缘抗锯齿与不同方法的适用范围；[Viewport API](https://docs.godotengine.org/en/stable/classes/class_viewport.html)提供独立视口的 MSAA 配置。MSAA 改善几何边缘，不能把低分辨率贴图本身变成高清；因此这里同时取消半分辨率遮罩。以上项目适用性是结合本项目实机测试作出的判断。

## 已提供的选择

1. **月白细线**：1.5 像素左右的柔和白灰细边。最克制，轮廓辨识清楚，采样成本最低。
2. **旧金流光**：旧金色细边、很轻的暖色外晕、缓慢移动的明暗。推荐默认，呼应童话书装饰和现有金色界面。
3. **幽灵柔辉**：青绿色细边加更柔软的外晕，并有轻微呼吸。适合灵异、回魂与调查氛围。
4. **绯红余烬**：暗红轮廓，橙色亮带沿画面缓慢游动。适合危险、诅咒或爆发状态；当前可直接作为选择风格试用，不自动绑定战斗状态。

这四套是实时 shader 效果，没有生成序列帧或额外点光源。流动基于屏幕坐标，不宣称沿轮廓弧长精确运动。

入口：「启动战术防守.cmd」→ 点击角色 → 菜单底部「描边」下拉框。选择立即生效，保存至 user://tactical-outline.cfg，重启记住。仅修改战术模式选择表现。

对照截图：tempassets/work/tactical-outline-choices.png；四张原始截图为 tactical-outline-0.png 至 tactical-outline-3.png。截图使用同一静止姿态和效果时刻；流光与呼吸请以游戏内动画为准。

## 验证与开销边界

- GPU 实测四套输出各不相同；遮罩尺寸等于游戏视口尺寸，测试图有 1642 个部分覆盖边缘像素，验证 MSAA 不是空配置。
- 原整体遮罩测试仍通过。网格与 Skin 继续复用，无目标时停止遮罩更新。
- 月白细线使用 17 次纹理读取，其余风格使用 49 次（含中心），遮罩增加至全分辨率与 4× MSAA，因此成本高于旧版。没有为此启动全地图或长时间压测，也不据此承诺固定帧率。
- 当前遮罩仍未纳入其他场景物件的遮挡深度，沿用上一版行为。
