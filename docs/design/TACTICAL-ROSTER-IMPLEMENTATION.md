# 八角色战术阵容 · 实装说明

2026-09-16

入口：启动战术防守.cmd → 开始战术防守。底部八个队员按钮可以直接选人，点“查看范围”或释放技能。左上“技能测试 · 回满能量”给存活队员回满能量，便于反复体验；正常战斗仍按各自回能规则进行。选人期间维持 20% 战斗速度，关闭恢复。

## 逻辑与表现

- 角色技能固定绑定，各自显示职业、技能说明、独立能量上限、护盾数值。保留临时嘲讽开关及远程伤害普攻的弹道切换；医师不显示伤害弹道选项。
- 普攻与技能在所用动作时长的 42% 位置触发效果；这是当前统一打击点，未宣称每段动作都已逐帧手工标注。使用原片段时长，不把所有攻击压成 0.65 秒。近战包含小幅向前出手及返回，位移不超过 0.7 逻辑单位（0.28 米）。
- 指向技能弹体锁定目标；固定火球锁定地面，按抵达时间爆炸；普通固定弹道能打空或被途中敌人截挡。已经发出的弹体独立运行，换位取消尚未出手的攻击与未发射的连射。
- 治疗预览标记队友；七针预览最多标记前三个候选；其他范围按实际形状显示。新技能反馈使用贴地 3D 印记与渐隐边界。复用已有粒子发射器，火球暖橙、飞针银白、迟滞淡紫，未制作新的序列帧图片。
- 火焰/迟滞区域使用固定的一秒节拍，相同类型重叠伤害取最高值，减速取最强并刷新。普通怪完整击退，体型较大的怪减半，首领不击退。
- 死亡取消未出手技能；减伤、护盾和额外阻挡清除，仍沿用原本的尸体与重生流程。重开清除技能队列、区域和视觉池绑定。
- 视觉反馈池上限 32，超过只省略额外反馈，不省略伤害、治疗或其他逻辑。未新增每角色独立粒子控制器或逐粒子点光源。

## 验证

- test_tactical_roster_skills.gd：八种主动技能、反伤、第四击、低血治疗选择、邻列回能、火球抵达、持续伤害、击退免疫及死亡中断。
- test_tactical_roster_live.gd：真实 GPU 场景，八种不同模型、装备槽与武器实例数、动作库、八人同时施法、友方范围提示。
- 既有战术规则、嘲讽/弹道测试及原 3D 弹道回归通过。
- 一次本机短测：8 队员、50 敌人、八技能触发，180 次更新逐帧渲染约 3.94 秒，约 46 帧/秒；场景 CPU 更新 P95 约 17.10 ms。这是高密度短测，包含特效启动，不代表全程性能，也未声称已达到稳定 60 帧。保留该结果供后续有针对性地优化，不开启无限压测。

本轮已是可操作原型；角色强度与技能视觉精修仍以用户体验反馈为准。

## 前移边界
队员前移终点固定在本场逻辑深度 z=-0.5，当前战斗镜头下地面投影约在画面高度 50% 附近，对应用户红线。所有前移职业共用，不随重复指令累加。普攻与技能的前踏同样受限；技能射程不受此移动边界截断。到达后停下迎敌，菜单显示已达前移边界，仍可换位或撤退。test_tactical_advance_limit.gd 已验证。

## 敌方尸体消散
无重生资格的敌人死亡后保留 5 秒，再使用大世界迷雾粒子材质消散 1.35 秒；倒地动画超过 5 秒则等其播完。消散完成才释放模型绑定，已消散的尸体不再参与显示分配。有剩余重生次数（revives_remaining，默认读取敌人配置 revives）或正在等待复活（revival_pending）的单位保留尸体；该判断不新增自动复活能力。我方死亡/重生流程不变。失败时由现有全场消散接管，避免两套透明度控制冲突。GPU 测试 test_tactical_corpse_smoke.gd 通过保留时间、烟雾、重生例外、模型复用与重开清理。
