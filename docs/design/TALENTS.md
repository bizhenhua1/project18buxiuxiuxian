# 道途天赋系统（v1 · dao1）

> 代码：`js/talents.js`（数据+逻辑）、`js/talent-ui.js`（SVG 放射树面板）。
> 存档键：`dao-talents-v1`（已点节点）、`dao-progress-v1`（关卡进度/胜场）。

## 1. 设计立意

结合修仙文化与《流放之路》天赋树的核心思路：**天赋不只是加数值，而是改变"能带什么上场、它如何运作"**。

- 卡牌是修士的"身外之物"：法宝、武器、法术、御兽。
- 天赋树的四条主干对应四条道途，各自解锁一类**格位（slotType）**与专属机制。
- 敌我上阵位置上限均为 10；我方的实际容量 = 道童 1 + 各类格位之和，**敌方出战数与我方格位容量对称**——开格子既是成长也是提高对局规模的代价。

## 2. 悟性点经济

| 项 | 规则 |
| --- | --- |
| 获得 | 每通过 1 个路点 +1 悟性；每通过 1 个 Boss（第 8 路点）额外 +1 |
| 公式 | `points = unlockStage + floor(unlockStage / 8)` |
| 洗髓 | 免费、随时（面板内按钮），点数全额退回 |
| 单点退点 | 允许，但不可切断其余已点节点与「道基」的连通 |
| 回档保护 | 若已花点数 > 当前总点数（清档等），自动洗髓 |

## 3. 卡牌类型与格位

| cardType | 格位 | 承伤 | 说明 |
| --- | --- | --- | --- |
| `char` 道童 | 本体（固定 1） | ✔ | 唯一主角，手持武器与识海法术都系于他 |
| `fabao` 法宝 | 法宝格（基础 4） | ✔ | 有独立血量、自走；幡/剑等子类有专属机制 |
| `weapon` 武器 | 手持格（体修开启） | ✘ | 捏在道童手里：**不占承伤位**，受"力量预算"重量约束 |
| `spell` 法术 | 识海格（法修开启） | ✘ | 无血量、不可被攻击，按 CD 自动施放 |
| `beast` 御兽 | 兽栏格（御兽开启） | ✔ | 战斗收服的妖兽，可上阵 |

**目标规则变更**：敌方集火"最左**可承伤**的存活单位"（`leftmostTargetable`），法术与手持武器被跳过；溅射同样只命中可承伤单位。

**连锁消散**：道童阵亡时，其手持武器与识海法术立即消散（记尸体、触发死亡事件——会喂给聚魂幡）。上阵武器/法术但不上道童时禁止开战。

## 4. 四条道途

### 体修 · 三头六臂（左上）

| 节点 | 类型 | 效果 |
| --- | --- | --- |
| 蛮力 | 小 | 力量预算 +3 |
| 两手蛮力 | 大 | **手持格 ×2**，力量 +2 |
| 筋骨 / 体魄 | 小 | 全队生命 +6% / +8% |
| 罡体 | 小 | 反伤 +10%（近战命中我方时反弹） |
| 四臂罗汉 | 大 | 手持格再 +2，力量 +3 |
| 铁布衫 | 小 | 全队受伤 -5% |
| 三头六臂 | 道果 | 手持格再 +2（共 6），力量 +4 |
| 法宝合身 | 道果 | 手持武器血量 60% 并入道童，且道童受伤 -30%（金刚护体） |

> 数值备注：合身把全队集火压到一根血条上，v1 验证发现纯并入必被融化，故道果附带 30% 减伤补偿；后续可再加"手持武器反伤联动"。

### 法修 · 万法周天（右上）

识海格解锁法术卡。v1 法术（`spellKind`）：

- `fireball` 离火术：轰击敌方全体可承伤单位
- `bind` 冰缚诀：敌最左延迟行动 1.4s + 40% 伤害
- `bolt` 天雷引：敌最左 220% 伤害
- `mend` 回春术：我方全体伤员回 80% 攻击的血；全满则转为普通一击

节点：凝神/咒力（法强 +8/+10%）、识海开窍（**识海格×2**）、静心/玄妙（CD -3/-4%）、神识（识海 +1）、灵台清明（识海 +2、法强 +8%）、道果**万法周天**（识海 +3 共 8、法强 +20%、全队生命 -10%）。

### 器道 · 万宝归宗（左下）

法宝格扩容 + 法宝子类专属机制：

- **幡**（`tags:["fan"]`，聚魂幡）：敌我任意单位死亡叠 1 层魂力，每层攻 +8%；「幡道」提到每层 +12%。**克制送死复活流**。
- **剑**（`tags:["sword"]`，桃木剑/青锋剑/玄铁重剑）：「剑心」解锁剑阵——任一剑出手时，其余存活剑各追击 30%（「剑意」+12%）。
- 预留子类接口：鼎（炼化）、镜（反射）、绳（缚敌）、葫芦（收摄）。

节点：御器/器灵（法宝攻 +6/+8%）、多宝（**法宝格 +2**）、炼器（法宝血 +8%）、剑心/剑意、幡道、道果**万宝归宗**（法宝格 +3 共 9、法宝攻血 +10%）。

### 御兽 · 万兽山河（右下）

- **收服**：胜利结算时，本场每击杀 1 只敌方妖兽独立掷收服（基础 10% + 驭心/灵契/玉佩气运，上限 75%）。收服入库（`dao-beasts-v1`），卡池出现「御兽」分区，可上阵份数 = 收服只数。
- 节点：驭心/灵契（捕获 +10/+12%）、兽栏/扩栏（**兽栏格各 +2**）、兽性/血食（御兽攻 +8%/血 +10%）、共鸣（场上每种不同御兽全队攻 +2%）、道果**万兽山河**（兽栏 +2 共 6、御兽攻血 +12%、兽王血契：御兽死亡道童回其最大生命 20% 的血）。

### 交叉小路

`筋骨↔静心`（顶）、`铁布衫↔炼器`（左）、`幡道↔兽性`（底）、`咒力↔灵契`（右）——支持体器双修（反伤+炼器）、幡御双修等杂交 build。

## 5. 修正聚合管线

```
talentMods() ┐
             ├─ mergeMods() → mods ─→ applyPlayerMods(unit, mods)   （逐单位）
equipMods()  ┘                    └─→ applyQueueEffects(queue, mods)（共鸣/合身等整队效果）
```

- 数值型词条求和、布尔型（共鸣/血契/合身）取或。
- `applyPlayerMods` 在 `applyEffectiveStats`（关卡成长）之后执行，写入 `unit.thorns / dmgReduce / swordEcho / fanPerStack / healBoost / shieldBoost / splashN / splashMult` 等字段，战斗层只读这些字段，不感知天赋系统。
- 敌方单位不走此管线（天赋只属于玩家）。

## 6. 树 UI

- SVG 放射布局（`viewBox -360 -352 720 704`），中心道基，四主干对角展开。
- 节点三档：小点（r10 纯数值）、大节点（r14 机制/格位）、道果（r19 + 虚线环，build 定义级）。
- 交互：点击加点（需相邻+有点数）、再点退点（需保持连通）、悬停底栏显示说明、洗髓一键重置。
- 入口按钮常显剩余悟性，有余点时金光提示。

## 7. v1 范围外（预留）

- 五行生克：降级为卡牌标签体系，未参与结算。
- 法宝子类鼎/镜/绳/葫芦：数据结构支持 `tags`，机制未实现。
- 多主角/分身：`char` 上限写死 1。
