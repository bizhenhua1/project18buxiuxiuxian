# 道途天赋系统（v3 · dao6）

> 代码：`js/talents.js`（数据+逻辑）、`js/talent-ui.js`（SVG 放射树面板）。
> 存档键：`dao-talents-v1`（已点节点）、`dao-progress-v1`（关卡进度/胜场/已打赢路点 clearedStage；加载时钳制 unlockStage ≤ clearedStage+1，清洗免战推关灌大的旧档）。

## 1. 设计立意

结合修仙文化与《流放之路》天赋树的核心思路：**天赋不只是加数值，而是改变"能带什么上场、它如何运作"**。

- 卡牌是修士的"身外之物"：法宝、武器、法术、御兽。
- 天赋树的四条主干对应四条道途，各自**加成**一类格位（slotType）与专属机制。白板已有手持/识海/兽栏各 1 格与法宝格 4，天赋只做 +N，不锁卡种。
- 敌我上阵位置上限均为 10；我方的实际容量 = 道童 1 + 各类格位之和。**敌方出战数只随关卡增长**（`min(capAt(关卡), 5 + ⌊关卡/2⌋)`，第 0 关 5 只、每 2 关 +1、封顶 10），与玩家天赋无关——开格子是纯粹的成长收益。

## 2. 悟性点经济

| 项 | 规则 |
| --- | --- |
| 获得 | 每通过 1 个路点 +1 悟性；每通过 1 个 Boss（第 8 路点）额外 +1 |
| 公式 | `points = unlockStage + floor(unlockStage / 8)` |
| 洗髓 | 免费、随时（面板内按钮），点数全额退回 |
| 单点退点 | 允许，但不可切断其余已点节点与「道基」的连通 |
| 回档保护 | 若已花点数 > 当前总点数（清档等），自动洗髓 |

## 3. 卡牌类型与格位

| cardType | 格位 | 承伤 | 说明 |
| --- | --- | --- | --- |
| `char` 道童 | 本体（固定 1） | ✔ | 唯一主角，手持法宝与识海法术都系于他 |
| `fabao` 法宝 | 法宝格（station）或手持格（held） | 视模式 | **唯一实体**：同一件法宝按所在格位以两种模式上场（见 §3.1） |
| `spell` 法术 | 识海格（白板 1，法修加成） | ✘ | 无血量、不可被攻击，按 CD 自动施放 |
| `beast` 御兽 | 兽栏格（白板 1，御兽加成） | ✔ | 战斗收服的妖兽，可上阵 |

**目标规则变更**：敌方集火"最左**可承伤**的存活单位"（`leftmostTargetable`），法术与手持（held）法宝被跳过；溅射同样只命中可承伤单位。

**连锁消散**：道童阵亡时，其手持法宝与识海法术立即消散（记尸体、触发死亡事件——会喂给聚魂幡）；操控（station）法宝不受影响，继续自走并可自行重聚。上阵手持法宝/法术但不上道童时禁止开战。

### 3.1 法宝双模式（dao5 · 用户确认的设计）

**法宝归一化**：取消独立的 `weapon` 卡类型，原武器卡（青锋剑/玄铁重剑/开山斧）并入 `fabao`。每件法宝统一具有：重量 `weight`、血量、攻击、主动技/被动技、**重聚时间 `reviveMs`（每件法宝自己的属性）**。

**重量映射数值**（`js/unit.js fabao()`，基准值按"映射后 ≈ 原手感数值"回推，避免平衡大崩）：

```
血量 = 基准血 × (1 + weight × 0.25)
攻击 = 基准攻 × (1 + weight × 0.18)
CD   = 基准CD × (1 + weight × 0.12)
```

全法宝定重与重聚时间（轻小的快、厚重的慢）：

| 法宝 | 重量 | 重聚 | 主/被动技 |
| --- | --- | --- | --- |
| 桃木剑 | 1 | 4.5s | 被动：剑阵 |
| 麻索 | 1 | 4.0s | 主动：加速 |
| 青锋剑 | 2 | 5.0s | 被动：剑阵 |
| 铜镜 | 2 | 5.5s | 溅射（攻击形态，两模式都生效） |
| 小葫芦 | 2 | 5.5s | 主动：治疗 |
| 聚魂幡 | 2 | 6.0s | 被动：魂力叠层 |
| 玄铁重剑 | 3 | 7.5s | 被动：剑阵 |
| 瓦瓷印 | 3 | 7.0s | 主动：护盾 |
| 开山斧 | 4 | 9.0s | 无 |

**主动/被动技分类**：heal（小葫芦）、shield（瓦瓷印）、haste（麻索）为主动技；幡叠层（fan tags）、剑阵连携（sword tags）为被动技。普通攻击不算技能，两种模式都正常出手。

**同一件法宝，两种上场模式**（`unit.mode: "held" | "station"`，由所在格位决定）：

| | 手持 held（手持格，白板 1） | 法术操控 station（法宝格） |
| --- | --- | --- |
| 承伤 | 不占承伤位（isTargetable false） | 独立血条可被集火 |
| 出手 | 自身 CD ÷ (1+攻速%)（继承主角攻速）；继承主角暴击 | 自身 CD 独立行动 |
| 重量 | 额外攻击加成 ×(1 + weight × 0.06)（举得动=打得狠） | 无额外 |
| 主动技 | **封印**（heal/shield/haste 不触发，退化为普攻） | 生效 |
| 被动技 | 生效（手持剑可入剑阵、手持幡照样叠层） | 生效 |
| 血量 | **30% 并入道童**（基础值恒定生效；「法宝合身」+30%→共 60%） | 独立生效 |
| 击毁后 | 随道童存亡（道童死则消散，collapseOrphans） | **自行复活**：经过自身 reviveMs 原位重聚，**血量 100%**；死亡次数不影响重聚时长（不写死递增），仅天赋/装备词条「重聚缩减%」可修改；战斗结束清除未完成的重聚 |

**胜负判定**：**道童阵亡即战败**——主角一倒直接判负，不等其余存活单位或重聚中的法宝（敌方同刻恰好全灭则算平局）；无道童的阵容仍走"全灭才判负"，此时重聚中的法宝可撑住不判负（战斗继续直到重聚回归或真正无人）。敌方无复活机制不受影响。已知重聚可能造成拖磨，后续会另加硬性时限（雷劈清场判负）——**当前版本未实现时限**。

**交互**：拖放入阵默认 station；法宝格满且手持格有空（含重量预算）则自动入手持。布阵期**右键**（或双击）场上法宝在 held↔station 间切换（校验空手位与重量预算，失败时状态栏提示原因）；卡池法宝右键可直接手持上场。held 法宝卡面带"持"角标，格位底纹按模式对应手持格/法宝格。一键布阵：法宝格填满后从重到轻持法宝。洗髓/格位收缩的超编退回：held 超编优先转 station（法宝格有空），转不了才退回卡池，不丢卡。

**出手三属性（dao6 更新，详见 ATTRIBUTES.md）**：
- 攻速 `atkSpeedPct`：只作用于道童与手持法宝（等效 CD = CD ÷ (1+攻速%)），与全队 `cdPct` 区分开。
- 暴击 `critPct` / 暴伤 `critDmgPct`（默认暴伤 150%）：dao6 起**全队通用**（每单位掷点，含识海法术）；敌方 stage≥5 的 Boss 带 10% 基础暴击。跳字更大字号并带"暴"标。
- 技能冷却 `skillCdrPct`：只压缩主动技（heal/shield/haste，held 封印时不吃）与识海法术的等效 CD——攻速管出手、冷却管技能。

来源：体修「猿臂」（攻速+6%）「锐目」（暴击+5%）、器道「淬锋」（暴伤+20%）、法修「凝息」（技能冷却-8%）；装备词条池攻速/暴击（腕戒亲和）、技能冷却（鞋链亲和）、重聚缩减（链亲和）、戒指主属性暴击。

### 格位美术与悬浮说明（dao2）

战场格子按状态与类型渲染专属边框（`assets/slots/slot-*.png`，style-e 敦煌矿彩，品红底 2×4 总表 → `scripts/make_slot_frames.py` 切片，1:2 竖版与卡牌同比例）：

| 状态/类型 | 视觉 | 悬浮说明 |
| --- | --- | --- |
| 本体格 | 金边莲纹 + 打坐人影 | 道童之位、连锁消散规则 |
| 法宝格 | 铜边八卦 | 余量 x/y、幡/剑子类机制、扩容天赋 |
| 手持格 | 铁边刀结 + 拳印 | 余量、重量 w/W、不占承伤位说明 |
| 识海格 | 石青云纹 + 天目 | 余量、无血量不可被攻击说明 |
| 兽栏格 | 石绿藤蔓 + 兽爪 | 余量、收服来源说明 |
| 妖兽格（敌） | 暗朱獠牙边 | 敌方规模成长规则（5 只起，每 2 关 +1） |
| 封印之位 | 铁链 + 黄符 | 各道途开格路径 + 位置上限进度 |

规则：空格按「剩余容量」顺序排型（本体→法宝→手持→识海→兽栏→封印）；已占用格按占用者类型作衬底压暗；空格悬浮点亮并弹出说明（复用卡牌 tip 气泡）；提示内容含实时计数，签名含关卡/重量防止陈旧。

## 4. 四条道途

### 体修 · 三头六臂（左上）

| 节点 | 类型 | 效果 |
| --- | --- | --- |
| 蛮力 | 小 | 力量预算 +3 |
| 两手蛮力 | 大 | **手持格 +2**，力量 +2 |
| 筋骨 / 体魄 | 小 | 全队生命 +6% / +8% |
| 罡体 | 小 | 反伤 +10%（近战命中我方时反弹，反伤为外伤） |
| 猿臂 | 小 | 攻速 +6%（道童与手持法宝等效 CD） |
| 锐目 | 小 | 暴击 +5%（全队通用，基础暴伤 150%） |
| 刚劲 | 小 | 外伤 +8%（全队外伤类攻击，中段小点） |
| 铁骨 | 小 | 外防 +6（全队外伤防御点数，体魄之后） |
| 四臂罗汉 | 大 | 手持格再 +2，力量 +3 |
| 铁布衫 | 小 | 全队受伤 -5% |
| 三头六臂 | 道果 | 手持格再 +2（共 7），力量 +4 |
| 法宝合身 | 道果 | 手持法宝血量继承比例 +30%（基础 30%→60%），且道童受伤 -30%（金刚护体） |

> 数值备注：held 血量继承基础 30% 恒定生效（`applyQueueEffects`），道果只提高比例。合身把全队集火压到一根血条上，v1 验证发现纯并入必被融化，故道果附带 30% 减伤补偿；后续可再加"手持法宝反伤联动"。

### 法修 · 万法周天（右上）

识海格（白板 1）可挂法术卡；法修天赋加格。v1 法术（`spellKind`）：

- `fireball` 离火术：轰击敌方全体可承伤单位
- `bind` 冰缚诀：敌最左延迟行动 1.4s + 40% 伤害
- `bolt` 天雷引：敌最左 220% 伤害
- `mend` 回春术：我方全体伤员回 80% 攻击的血；全满则转为普通一击

节点：凝神/咒力（**法伤** +8/+10%，dao6 起旧「法术强度」统一为法伤——增益全队法伤类攻击并保留法术治疗强度）、识海开窍（**识海格 +2**）、静心/玄妙（全冷却 -3/-4%）、神识（识海 +1）、灵台清明（识海 +2、法伤 +8%）、**凝息**（技能冷却 -8%，神识之后中段）、**玄盾**（法防 +6，凝息之后）、道果**万法周天**（识海 +3 共 9、法伤 +20%、全队生命 -10%）。

### 器道 · 万宝归宗（左下）

法宝格扩容 + 法宝子类专属机制：

- **幡**（`tags:["fan"]`，聚魂幡）：敌我任意单位死亡叠 1 层魂力，每层攻 +8%；「幡道」提到每层 +12%。**克制送死复活流**。
- **剑**（`tags:["sword"]`，桃木剑/青锋剑/玄铁重剑）：「剑心」解锁剑阵——任一剑出手时，其余存活剑各追击 30%（「剑意」+12%）。
- 预留子类接口：鼎（炼化）、镜（反射）、绳（缚敌）、葫芦（收摄）。

节点：御器/器灵（法宝攻 +6/+8%）、多宝（**法宝格 +2**）、炼器（法宝血 +8%）、剑心/剑意、**淬锋**（暴伤 +20%，剑意之后）、幡道、道果**万宝归宗**（法宝格 +3 共 9、法宝攻血 +10%）。

> 点数经济备注（dao6）：新增五个小点（刚劲/铁骨/凝息/玄盾/淬锋）会稀释悟性点，均安排在支线中段/末端，不要求全部点满。

### 御兽 · 万兽山河（右下）

- **收服**：胜利结算时，本场每击杀 1 只敌方妖兽独立掷收服（基础 10% + 驭心/灵契/玉佩气运，上限 75%）。收服入库（`dao-beasts-v1`），卡池出现「御兽」分区，可上阵份数 = 收服只数。
- 节点：驭心/灵契（捕获 +10/+12%）、兽栏/扩栏（**兽栏格各 +2**）、兽性/血食（御兽攻 +8%/血 +10%）、共鸣（场上每种不同御兽全队攻 +2%）、道果**万兽山河**（兽栏 +2 共 7、御兽攻血 +12%、兽王血契：御兽死亡道童回其最大生命 20% 的血）。

### 交叉小路

`筋骨↔静心`（顶）、`铁布衫↔炼器`（左）、`幡道↔兽性`（底）、`咒力↔灵契`（右）——支持体器双修（反伤+炼器）、幡御双修等杂交 build。

## 5. 修正聚合管线

```
talentMods() ┐
             ├─ mergeMods() → mods ─→ applyPlayerMods(unit, mods)   （逐单位）
equipMods()  ┘                    └─→ applyQueueEffects(queue, mods)（共鸣/合身等整队效果）
```

- 数值型词条求和、布尔型（共鸣/血契/合身）取或。
- `applyPlayerMods` 在 `applyEffectiveStats`（关卡成长）之后执行，写入 `unit.thorns / dmgReduce / physDef / spellDef / critChance / critDmg / swordEcho / fanPerStack / healBoost / shieldBoost / splashN / splashMult` 等字段，战斗层只读这些字段，不感知天赋系统。外伤%/法伤% 按单位 `dmgType` 折入攻击；攻速/技能冷却/全冷却按各自作用范围折入 CD（见 ATTRIBUTES.md §1）。
- 敌方单位不走此管线（天赋只属于玩家）。

## 6. 树 UI

- SVG 放射布局（`viewBox -360 -352 720 704`），中心道基，四主干对角展开。
- 节点三档：小点（r10 纯数值）、大节点（r14 机制/格位）、道果（r19 + 虚线环，build 定义级）。
- 交互：点击加点（需相邻+有点数）、再点退点（需保持连通）、悬停底栏显示说明、洗髓一键重置。
- 入口按钮常显剩余悟性，有余点时金光提示。

## 7. v1 范围外（预留）

- 五行生克：降级为卡牌标签体系，未参与结算。
- 法宝子类鼎/镜/绳/葫芦：数据结构支持 `tags`，机制未实现。
- 多主角/分身：`char` 上限写死 1。
