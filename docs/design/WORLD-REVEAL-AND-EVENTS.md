# 世界行走、揭雾范围与事件阻挡

## 当前规则

冒险岛底栏提供“揭雾范围”，默认 0，保存于世界存档。0 只揭开落脚格；1 为中心加四邻格的十字；2 为九宫；后续按菱形和方形交替扩展：3 十三格菱形、4 五乘五。只处理岛上实际存在的格子。调大范围立即揭开脚下周围；调小不重新盖住已探索格。

揭雾与原有视线明暗分开：揭雾决定内容是否已知，视线继续影响已知格明暗。行走抵达时应用范围，不在出发时提前揭开目标。

## 事件格

未清除事件由 JourneyState 根据区域生成阻挡表。已揭开的事件格显示代表怪物，状态色使用原有不可通行暖红色。取消询问不清除事件，普通寻路不穿越事件。点击已知事件会寻找可到达的相邻安全格，抵达后询问；已经相邻则直接询问。没有安全路径时不允许隔空进入。

未探索事件可以作为本次试探落脚点，但不能作为寻路中间节点。踏入发现事件后，揭开相应范围，角色从事件格用 0.24 秒缓动退回刚才的安全格；模型的稳定位置立即保留在安全格，渲染姿态单独插值，避免保存到阻挡格。退回期间禁止确认进入，动画结束才出现中央询问框。沿用短小的行走起伏动画，不使用瞬移。

提示居中覆盖窗口，提供“进入局内冒险”和“暂不进入”。事件成功完成后移除阻挡和怪物显示，恢复该格通行。既有局内入口、结算奖励及主岛返回流程保留。范围揭开的远处事件先显示在地图上，不自动连续弹出多个询问框。

弹窗显示修复：询问框使用独立 CanvasLayer，尺寸跟随实际视口，不受地图容器最小尺寸或布局扩展影响；使用不透明青绿底板、细边框和阴影，背景压暗与内容底板分离，避免地图穿入内容区。已检查 1000×650、1200×800、1920×1080 的居中、窗口边界及底板不透明性，并实际渲染小窗口。

## 实现边界

- IslandModel：reveal_range、reveal_near、blocked、event_requested、rebounding；阻挡是会话重建数据，不直接存入世界存档。
- JourneyState：根据未清除区域同步阻挡表，处理询问、取消与完成。
- IslandView3D：已发现事件的代表怪物显示，与揭雾同时淡入；清除后隐藏。
- JourneyView：范围设置与中央询问框，等待退回动画结束。

旧存档没有范围字段时按 0 处理，未清除事件阻挡表在恢复时重建；若旧存档停在事件格且有安全返回位置，则恢复到该安全位置。
