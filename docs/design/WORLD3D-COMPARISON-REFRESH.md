## 行进身体朝向修正

进一步隔离证明，上述行进残差主要不是骨骼重定向：传统 `scene_formation.gd` 使用 PI−0.12 的行进身体朝向，而独立 3D 根节点跟随实际道路，直路朝向为 PI。实测两者分别 3.021551 与 3.141594 弧度。

复原方式：仅在传统构图模式的行进／接近事件阶段，给主角 body 平滑施加 −0.12 弧度视觉偏转；真实根节点、位置、路径及相机不变，进入战斗平滑归零，死亡不继续改动该偏转。修正后头部归一化误差约 0.00000161，腰 0.000000562，脚部最大约 0.00000533，已对齐采样帧四个骨点加入 0.0001 阈值回归。七检查点 GPU 流程通过，已查看更新后的行进画面。

该结果只证明同模型、同动画时刻的关键点朝向匹配，仍不代表整幅场景/全部动作的像素一致。
