## 左右转弯的后续遗漏

用户再次报告移动，尤其左右转弯时仍频繁跳变。检查发现：实际资产 short-grass 未列入低矮草分类，旧分类中的 grass 并不能代替它；同时树根附件仍以偏心锚点绕父树随相机旋转，并受父树屏幕下沿隐藏规则控制。

已加入 short-grass，并在生成阶段把低矮树根附件换算为独立世界根位置、居中落脚锚点和固定道路朝向。它们仍使用既有源图和批次，不再沿用父树出画即隐藏的规则。原始撒布字典不改写。

GPU 实例读取检查覆盖 7650 个独立低矮草对象与 23970 个根部草附件，附件固定模式、锚点和裁剪包围盒检查通过；完整低草集合的排序反转测试仍为 0 变化像素。二岔左转、三岔右转均运行并截图检查。头less后端不支持此实例读取验证，因此测试明确要求实际渲染后端。这些检查不等同于已经证明所有连续移动画面无闪烁，需保留用户下一次实机反馈。
