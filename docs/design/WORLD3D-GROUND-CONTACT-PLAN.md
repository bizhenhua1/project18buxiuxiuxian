## 已落地：固定世界地面网格

发现原 PlaneMesh 的 160/260 subdivisions 实际对应 161/261 个单元，且地面片连续跟随摄像机平移：同一世界位置的三角形插值会随镜头改变。新增 ground_grid.gd，改为真正的一米网格（159/259 subdivisions），地面片按整米坐标回收。顶点 42444 → 42021，三角形 84042 → 83200；不增加逐物件查询，不改变镜头设置。

验证：实际生成网格全部顶点位于整数米格点，六组正负/远距离镜头坐标保持同一格网。GPU 固定视口对照五次回收位置，共 768000 像素最大通道差 1/255。最初低俯角把有限地面片的远边界也纳入比较而失败，改为俯视共同覆盖区域后通过，没有放宽差异阈值；远端回收边界视觉仍需在正式运动镜头中检查。生产地面树根六组角度/振幅回归通过，最大脚线偏差 .522 像素、地面遮去绿色面积比例 .0684%。完整 presentation flow 六状态采集通过，胜利为测试注入。

这解决网格随镜头漂移的基础问题，不等于连续高度与三角插值已完全统一，也不代表所有资产穿插修复。

## 统一规则

1. 地面渲染、静态撒布、角色足底共用地表坐标与高度定义。贴近地面的支撑高度应匹配实际地面网格三角形插值；仅共享连续高度函数仍可能与低密度网格有误差。局部平台/地基的高度修正必须同步进入高度查询与渲染。
2. 为每种资产缓存接触描述：类别、根部锚点、有效接触区间、刚性占地范围、可变形底带、允许坡度与少量埋入容差。透明轮廓只能生成候选数据，不能把垂下的叶片自动认作根。支持人工修正并保存。
3. 草与花以根部支撑，主体保持形状；树木只调整有限根部底带；地表碎叶使用贴地小网格；建筑/巨石保持刚性，在生成阶段择平缓落点或生成小地基。大坡差不通过拉伸整座建筑解决。
4. 树干、建筑等硬实体使用二维空间哈希检查占地冲突；叶冠和灌木允许适度重叠。保留已有构图与撒布优先级，局部微调或地基优先，不重随机整个场景。道路和战斗站位属于受保护区域。
5. 深度测试保持开启。共面装饰使用受控毫米级间隙；透明排序另行诊断。雾、阴影和根部覆盖只能用于自然过渡，不能作为隐藏穿插的验收依据。

## 执行成本

- 接触描述和共享网格按资产缓存，预处理一次，避免重复图像读回。
- 静态落点、占地冲突和坡度检测在地图生成/分块加载时执行，分帧预算化；限制每物件候选次数，无可用位置时记录诊断并采用明确回退，禁止无限重试。
- 按纹理/接触网格/空间块继续 MultiMesh 批绘制；参数尽量存实例数据，不为每棵树创建独立材质。
- 底部变形仅用于有需要的资产；远景用低顶点表示。Shader 每顶点计算仍有成本，不能称为免费。
- 不增加每帧逐物件射线或全场两两碰撞。动态角色只查询附近地表；统计生成峰值、绘制次数、三角形、显存和帧时间。

## 验收顺序

先建立诊断视图：显示接触点、占地范围、资产名和接地模式，输出最严重穿插清单。依次覆盖六个基础主题的近景、最大尺寸、坡顶/坡底、左右转向与镜头过渡；先修共性再修资产元数据。检查地面接缝及路线拼接处。

保持相同随机种子、机位、物件数量做前后截图与性能对照。地面遮挡掉的真实根部、悬空间隙、植被非自然折弯、透明排序、角色脚底分别判定。原有测试的 1% 遮挡比例只能作为局部诊断门槛，不能替代整幅画面的人工验收。

近期实施优先级：统一实际三角地表采样 → 资产接触元数据和诊断 → 普通宽面片与刚性物件 → 撒布占地冲突 → 六主题动态回归与性能对照。保持正式版镜头构图基准不变。
