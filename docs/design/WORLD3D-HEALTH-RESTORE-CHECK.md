# 战斗结算转化恢复验证

2026-09-14：修复独立 3D 版本我方模型的转化状态在胜利、重新整备后仍逐帧恢复的问题。此前真实血量已恢复，表现层仍沿用战斗回血插值，短时间残留上一场的骷髅/幽灵状态。

现在两处状态边界直接同步血量表现，身体转化、骷髅及环境覆盖参数同次更新；正常战斗回血保留平滑逆转。没有改动角色锚点、镜头或用户保存的编辑参数。

实际森林场景 GPU 测试 `godot/tests/test_world3d_health_view.gd` 通过：零血量全转化、普通回血渐变、调用重新整备后无需等待下一帧清零、通过胜利处理分支立即清零、骷髅及环境参数同步、两种投影切换、恢复原材质和镜头/角色锚点保持。测试使用临时内存配置，不写用户文件。

范围限制：胜利结果由测试注入，覆盖实际结算分支，不代表自然战斗全流程验收；这次没有扩大性能压测，也没有完成敌方转化接入或全部死亡复活动画验收。

后续补齐血条模式：我方模型在受伤、存活且转化未实际启用时显示血条；转化有效时隐藏，非法方案回退保留血量信息。道具卡使用其真实世界锚点投影下方的血条，受伤时显示，满血或离开战斗隐藏，不受模型转化开关影响。复用同一个 Canvas 绘制节点，不给每件道具新增独立血条场景。实际 GPU 用例覆盖道具受伤比例、投影位置、转化模式下仍显示，以及离场和满血隐藏；已查看截图。
