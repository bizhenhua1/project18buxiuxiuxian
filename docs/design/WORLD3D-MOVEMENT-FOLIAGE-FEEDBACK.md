# 试玩反馈：滑步与草丛跳变

2026-09-14。

动作步频原来使用单脚全周期前后摆幅估算速度。改为加载时采样支撑期：脚处于低位且向后移动时，取速度中位数；结果按模型缓存，运行时仍以实际移动速度及模型缩放驱动动作。没有通过加速角色来追赶动画。

mary-kuromi 跑步样本：原摆幅估算约 2.096，新支撑速度约 2.887。支撑阶段绝对速度残差从 0.637 降至 0.468（约 26%）；不是脚锁定，也不代表屏幕空间完全没有滑动。检查脚速、现有队伍两档速度和两档缩放均通过。死亡播放仍保持真实时间。

森林独立低矮装饰（fern、clover、litter、grass）此前使用相机朝向的竖直广告牌；转弯时几何面随相机转动，造成交叠关系变化。现在在生成时绑定所在道路的朝向，位置与源字典不变，不新增网格或实例。森林检查覆盖 3738 个低矮装饰。树根附件仍沿用其父体规则，未宣称所有跳变都由这个问题引起，透明排序和地形局部穿插仍可能有其他案例。
