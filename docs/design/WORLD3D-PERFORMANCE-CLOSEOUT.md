# 3D 性能阶段收口报告

日期：2026-09-14。根据用户要求，本轮专项优化收口，停止重复压测与全地图巡检。本文汇总已有记录，本次没有重新运行性能测试。

## 结论

尚未证明已到引擎或硬件极限，但继续小步优化的收益不足以优先于镜头、空间与玩法迁移。保留现有优化，记录风险，继续产品工作；不以稳定 60 FPS 作为继续开发其他功能的前置条件，也不宣称当前已达标。

## 已有测量

固定森林、1440×900、RTX 3060、480 帧；均为普通特效预算档。以下是不同负载的既有样本，不是修改前后 A/B，也不是全部最新功能的综合验收。

| 负载 | 平均帧时间 | P95 | P99 |
| --- | --- | --- | --- |
| 普通战斗样本 | 13.736 ms | 18.242 ms | 19.892 ms |
| 密集技能样本 | 21.700 ms | 29.778 ms | 38.710 ms |

密集样本有 39 个模型中位、95 个活跃弹体峰值、32 个区域峰值；绘制调用中位 885，粒子脚本约 5.529 ms。特效池零丢失，模拟指纹一致。普通负载仍有超过 16.67 ms 的帧，密集负载没有稳定 60 FPS，后续技能运算余量有限。

## 保留的技术约束

- 特效复用与活跃实例查询；装饰减量不改变真实索敌、弹道、命中和伤害。
- 普通弹、受击、出手初始上限分别为 24、32、12 个活跃粒子。全局预留软预算 2000；核心可读层允许超过软上限，因此不是硬性能保证。
- 密集时减少新实例的烟雾与外围光晕，已有实例自然结束，保留弹芯和命中主体。
- 模拟补光最多输出四份贡献，总能量封顶；没有每颗子弹独立带阴影点光源。爆炸记录普通档最多 32 条，可合并近距离短时命中补光。
- 完整原包档仍保留且目前仍为默认；普通预算档需选择，不能将其测量结果当作默认档表现。

## 剩余风险与取舍

密集特效的粒子更新、透明覆盖和绘制数量仍值得后续处理，但没有证据将全部慢帧归因于某一个环节。既有关闭补光对照仍远超目标帧时间，不能靠取消灯光解决全部压力。白色特效叠亮、补光交接的动态连续性、跨技能重要性调度尚未全部验收。

后续技能先规定频率、同时存在数量、屏幕覆盖、持续时间和装饰层预算。危险预警、真实范围及命中信息优先；不能通过丢失伤害或缩减真实攻击范围来满足表现预算。重要技能 32–64、关键大招 100–200 粒子仅为初始试验额度，不是质量或帧率承诺。

## 后续工作顺序及重启条件

1. 固定森林作为标准切片，先完成正式版本战斗占比、行进与事件镜头及转换过程的复刻。
2. 完成行进、事件、岔路、战斗、死亡与恢复的空间连续性；修复资产根部、遮挡、地面穿插规则。
3. 标准稳定后通过配置迁移其他主题，只检查具体差异，不反复逐图寻找通用规则。

仅在正常玩法出现可复现的明显卡顿、新功能造成可测回退，或准备阶段验收时重启专项性能工作。每次明确一个问题、一项假设和一次同负载验证；无可靠收益则收口记录，不开启无限压测循环。普通功能正确性检查继续，但不自动扩展为全地图或性能专项。

详细实现和历次数据见 [特效运行标准](WORLD3D-VFX-RUNTIME-STANDARD.md)。本次收口不代表整个 3D 迁移目标完成。
