# 3D 正式玩法特效预算

本标准用于森林基准和后续技能接入。保留完整原包作为效果参考及极端压力测试，不把无限叠加完整 StormMissile 当作正式玩法必须承担的负载。以下未实现部分是接入约束，不能据此声称性能已经达标。

## 已实现

- 特效回收改用本帧活跃弹体建立的对象查询表，替代每个结束实例重新生成 `bindings.values()` 并线性搜索。活跃弹体仍保留绑定，消失后拖尾自然结束再归池。实际预算选择器的双向重建测试同时验证补光策略、JSON 参数和清场，已通过。

本轮接入回归明确使用 `--theme=forest`，1440×900、固定 480 帧技能压力：39 模型中位、95 活跃弹体峰值、32 区域峰值，零特效池丢失，逻辑指纹 `408ccb8c329edb01679d89e1c795dbc3a93f36a819ee49cbc1f24fb2c0538a72`。mean 21.700ms / P95 29.778ms / P99 38.710ms，粒子脚本 5.529ms、绘制中位 885。没有稳定 60 FPS，不把这次结构优化说成已证明的帧率提升。此前本轮第一次漏传主题参数，报告是 `connected`，不能当作森林对照；已另跑明确森林报告，不混用两份结果。

- 普通档爆炸补光记录现在也有硬上限：最多 32 条；0.75m 内、已有记录年龄不超过 0.05s 的命中共享补光。合并不重置年龄、不移动原位置、不增加能量；超过容量只省略新补光记录，伤害和受击粒子不受影响。参数位于 `lighting`，完整原包对照档保留独立记录。每次命中最多检查 32 条，结束后恢复容量；最终输出仍最多四份。`test_world3d_burst_light_budget.gd` 已验证千次密集/分散输入、固定锚点及年龄、到期回收、禁用与完整档隔离。这是有界处理验证，尚未测量帧率收益或完成动态视觉验收。

- 普通档密集门槛：真实活跃弹体达到 24 枚时，新实例采用 missile `[3,0,1,0,0,0]`、impact `[2,1,0,0,0]`、muzzle `[1,1,0,0]` 的逐层上限；保留弹芯和命中主体，关闭烟尘及外围光晕。额度在发射时固定，存量实例自然结束；低于门槛后新实例恢复普通预算。配置在 `world3d_vfx_budgets.json` 的 dense 中，完整原包档不受影响。这是明确的有损表现约束，不是无损加速；尚无跨技能重要性调度。

密集门槛接入证据：阈值、弹芯保留、恢复和配置不被修改的测试通过。固定森林技能压力 480 帧，1085 个实例采用密集预算；粒子脚本 5.303ms（前次同参非细分测量 7.728ms），绘制中位 875（前次 1079），mean 20.821ms / P95 28.066ms / P99 33.321ms。零池丢失、伤害与模拟指纹不变；粒子峰值 missile 287、impact 108、muzzle 12。已查看新的 `forest-budget-ordinary.png`：外围烟光减少，白色弹芯叠亮仍存在。没有稳定 60 FPS，没有宣称密集画面美术合格。普通战斗回归 dense_instances=0，粒子数和绘制次数不变，逻辑指纹不变，mean 13.735 / P95 18.872ms。截图文件当前为密集预算版本，不能再作为修改前的截图使用。

- 普通攻击试验档：单枚飞行特效最多 24 活跃粒子、单次受击 32、出手 12；减少装饰发射和外围加法光晕，保留弹芯。通过验证面板选择，当前默认仍是原包完整档。
- 子弹补光使用 shader 模拟，最多输出 4 个光照贡献，爆炸优先，合计能量有上限。没有为每颗子弹创建带阴影真实点光源。
- 特效减量与实际索敌、轨迹、命中、伤害计算独立。

## 后续接入约束

| 类型 | 初始美术预算（同时存活粒子） | 必须保留 |
| --- | --- | --- |
| 高频普通弹 | 每枚不超过 24 | 弹芯、飞行方向、命中提示 |
| 普通受击 | 每次不超过 32 | 接触位置、受击时刻 |
| 重要技能 | 每实例先按 32–64 试验 | 轨迹、范围、危险提示 |
| Boss 或关键大招 | 每实例先按 100–200 试验 | 预警边界、阶段和命中时刻 |

这些不是跨材质通用的性能保证。普通档现以 2000 为全局预留软预算：为新实例连同拖尾预留最大粒子数，额度紧张时降低新实例逐层上限，直到自然回收才释放额度。最低可见层允许超过软上限，不隐藏真实弹道；复用池项重新分配额度，飞行中不突变。3000 仍仅是压力检查点。技能分级、屏幕面积调度尚未实现，该阈值也未证明能维持目标帧率。

还必须记录绘制调用、材质层数、透明屏幕覆盖、持续时间和每秒生成数。一个覆盖半屏的透明烟团可能比许多小粒子更贵，不能只按粒子数量验收。

调度优先级：危险预警和关键命中 > 弹芯与轨迹 > 装饰火花 > 烟雾与外围光晕。拥挤时优先降低新实例的装饰发射率和寿命；同一目标短时间内的普通受击可以合并表现。不得合并或遗漏真实伤害、穿透、多目标命中。预警范围必须继续对应真实技能范围。

## 补光方案

普通子弹继续采用发光材质、少量共享模拟补光，必要时用贴合地面的淡光斑。光斑同样受透明覆盖预算限制，不保证零开销。普通弹不分配独立实时阴影。

普通档已接入最多四个持久飞行补光组：在真实世界中合并距离 0.75m 内的弹体，以组内质心提供一份补光，不叠加组内粒子亮度。已有组优先保留；离开的组在原处用 0.12s 淡出，空位释放后才允许远处新组进入，新组同样淡入。每颗弹最多比较四个中心，为 O(4N)，不进行弹体两两比较。关闭飞行补光或重开会清理组状态。原包完整档保留原来的选取方式供对照。

该实现仍有限制：新组首次选择受输入顺序影响，没有屏幕重要性排序；质心跟随实际弹体，跨组合并/拆分并非完整连续性求解；爆炸仍直接优先占用输出槽，尚无爆炸抢占时的淡出交接。不能据此称所有补光闪烁已消除。后续如有视觉证据，再处理这些情况。爆炸保留短暂峰值再衰减，合计亮度继续封顶，不因子弹数量增加而线性增加光源数量。

共享补光验证：100 枚邻近弹合为一组、输入倒序后中心保持、消失原地淡出、最多四份输出、爆炸优先、总能量上限、清空与禁用均通过；原完整档回归也通过。接入后的固定森林普通负载 480 帧（1440×900，RTX3060）mean 13.736ms、P95 18.242ms、P99 19.892ms，粒子脚本 0.782ms，39 模型中位、684 绘制中位、零池丢失，逻辑指纹仍为 64c8aeff82f4e5cf10375d771767312104514827cef9d745f19619acec8114e2。本次为功能接入回归，不是隔离补光的 A/B，不能归因帧率收益；尚未稳定 60 FPS，也没有完成共享补光的密集画面验收。

## 验证范围

### 白斑来源隔离

已针对普通档 StormExplosion 实体层调整：gain 系数从 1 降至 0.65，起始尺寸乘数从 1 降至 0.8。没有修改发射数、粒子寿命、命中时刻、实际伤害或原包资产。先试过 0.45，受击主体过淡，最终回调为 0.65。同模拟帧隔离截图确认，原先不透明纯白团变成更小的半透明亮团；完整截图仍有飞行弹体亮带，不能称所有叠亮已解决。修改前隔离图另存 `forest-vfx-impact-before.png`，修改后为 `forest-vfx-isolate-impact.png`。

最终回归 480 帧：mean 20.717 / P95 27.497ms、粒子 5.372ms、875 绘制中位、零池丢失，逻辑指纹与粒子峰值不变。本次是美术参数修正，不宣称性能收益。全流程及普通单发受击的动态可读性仍需后续检查。

新增 `--capture-effect-kinds`，在压测结束的同一模拟帧分别仅显示 missile / impact / muzzle / none，保存 `forest-vfx-isolate-*.png`，保持镜头、模型、环境补光和区域提示不变。已查看 missile、impact、none 三张图：画面中部一串边缘较硬的纯白团块来自受击组，不应全部称为“弹芯叠亮”；左侧连续柔边亮带仍来自飞行组。实际资产 StormExplosion 为无贴图的 solid_AB 网格层，普通档目前 gain 未减，需优先针对这一层验证亮度/透明度，而不是继续削弱飞行弹芯。

本轮曾试验飞行组第 0/2 层改普通透明混合并限制峰值，整图改善很小，已撤回该材质试验，不保留未经证明的改动。隔离截图是来源证据，不是美术问题已经修好。对应高压逻辑指纹仍一致，零池丢失。
