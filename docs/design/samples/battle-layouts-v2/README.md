# 单局战斗布局参考 · 第二轮

三张均由内置 image_gen 根据当前 ui-review/06-fighting.png 参考图生成，完整提示词见 [prompts.json](prompts.json)。仅供布局选型，不是运行截图，也不是直接投入游戏的大幅 UI 资产。卡名、数值、状态文本存在生成偏差，不能据此改变玩法或数值。

- [A · 林境全景](A-panorama.png)：景观铺满背景，敌阵紧凑、己方单排常驻，减少上下大底板。建议作为连续行进体验的优先基础；整备入口落在下方，若采用应移至中上部，展开区遵循既有平级要求。
- [B · 行旅画卷](B-scroll.png)：纸色与墨边明确区分信息，卡牌名字最醒目，但卷轴装饰较重、景观空间相对少。
- [C · 云台列阵](C-formation.png)：敌方错落、己方浅弧排列，整备入口移至中部，空间感更强。落地时需让地台随场景主题变化，避免每种场景都固定一张石台。

三版保留中间景观、上方敌方与下方八张己方卡牌。下一阶段选定后才拆分角花、边条、按钮、卡牌底板等小型资产；字与数值继续引擎绘制，不能整张图直接贴入。需补充非战斗、整备展开、奖励和窄窗口状态的真实交互验证。
