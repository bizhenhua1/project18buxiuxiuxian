# 森林通道渲染器（伪 3D 走廊）

单张 `<canvas>` 上的画家算法伪 3D：2D 纸片素材沿深度排布，针孔投影 + 远→近排序 + 连续压暗，模拟"在森林通道中向前推进"。嵌在主流程中景带（`index.html`），独立演示页 `corridor-demo.html`（WASD/自动前进）。实现集中在 `js/corridor.js`，素材与生成约定见 `assets/corridor/SCENE-SPEC.md`。

实测单帧绘制 **约 2ms**（`window.__corridorDrawMs`），静止时按需重绘、按位移阈值节流。

---

## 1. 渲染管线（每帧绘制顺序）

| # | 层 | 要点 |
| --- | --- | --- |
| 1 | 天空渐变 | 程序渐变，无图片素材；预设/随时间混合（§4） |
| 2 | 日月 | 圆弧 6 步，推进对齐缓动（§5）；会被后续所有层遮挡 |
| 3 | 远山 ×2 | 完全静止（真实远山前进中几乎不动）；按预设动态压暗 + 雾霾染色 |
| 4 | 祥云 | 世界精灵：纵向视差逼近 + 独立横向风（§6） |
| 5 | Mode-7 地面 | 地平线以下逐扫描带反算深度取纹理行，v 随 camZ 滚动，ping-pong 寻址免接缝 |
| 6 | 雾带 | 地平线上下渐变：上半用雾霾色且向地平线趋暗，下半恒黑（尽头黑暗只属于通道内部） |
| 7 | 精灵 | 树/密草条带/散草/路面低草，严格全局画家排序（远→近，等深按 id 稳定） |
| 8 | 环境光 | 全屏 `multiply` 着色（预设 `amb`），树/草/地面全局受氛围影响；乘法下黑仍是黑 |

## 2. 核心机制

- **投影**：`sx = cx + (x + pathOffset(z) - camEff) * focal/z`，`scale = focal/z`；相机跟随脚下道路中心（`camEff = camX + sway + pathOffset(camZ + curveLook)`）。
- **无跳变**：远端进入视野时 alpha=0 从黑暗中淡入（`FADE_START→CULL_Z` 斜坡）；压暗 = 正常图 + 黑剪影按连续 alpha 叠加，绝无分档硬切。
- **回收**：精灵滑出 `Z_EXIT` 即重掷参数扔回远端（云反向：从远端绕回）。
- **落地锚定**：所有素材用统一 alpha bbox 求底边，根部做侵蚀处理（见 SCENE-SPEC 生成流程）。
- **弯道**：`pathOffset(z)` 双正弦叠加（伪 3D 赛车手法），所有物件按各自世界 z 偏移，远处的路左右摆弯。

## 3. 昼夜时钟（推关驱动）

时钟挂在 `camZ` 上：**一次推关（`STAGE_STEP`）= +2 小时，12 关一个昼夜**。

```
hour = (dayStart + camZ / STAGE_STEP × 2) mod 24
```

- 战斗期间相机不动 → 时钟停 → 天空/日月全部驻留；只有推进途中演变。
- `dayStart` 默认 9（编辑器可调"起始时刻"）。

## 4. 天空系统

`SKY_PRESETS` 五预设：夜空 / 晴天 / 阴天 / 黄昏 / 恐怖。每个预设含：

| 字段 | 作用 |
| --- | --- |
| `stops` | 垂直渐变色标（0=画幅顶，1=地平线） |
| `haze` | 大气雾霾色：远山/远云/地平线以上雾带都往此色融（晴天=亮天光青，夜空≈黑） |
| `amb` | 环境光 `[颜色, 强度]`，帧末全屏 multiply |
| `cloudCap` / `mtnCap` / `fogUp` | 云压暗上限 / 山压暗上限 / 雾带高度收缩，随 `skyBright` 联动 |

**随时间模式（默认，`skyType = -1`）**：按昼夜表 `DAY_SCHEDULE`（夜→黎明→晴→黄昏→夜）在相邻预设间全量插值（色标位置+颜色、haze、amb、联动系数）。时刻量化到 0.05h，剪影染色缓存只在换色时重烘。编辑器也可手选固定天气。

## 5. 日月运行

- 素材 `sun.png` / `moon.png`（style-e 同画风：朱砂金焰纹日 / 月白玉兔云纹月），6:00–18:00 太阳、18:00–次日 6:00 月亮。
- **轨迹**：上拱圆弧，收在中央天空楔内（约 0.32~0.68 画幅宽——画幅两角被树冠盖死）；两端在天空楔两侧半高处（约 0.55×地平线高），中间拱到画幅顶部（预留半张脸余量不裁切）。
- **节奏**：半日 12h ÷ 每关 2h = **6 步走完圆弧**；缓动与推进对齐——步进开始起步、smoothstep 铺满整个推进、结束时就位（峰值速度仅 1.5×均速），战斗时驻留。
- 6/18 点交接各留 0.3h 淡入淡出；画在天空渐变之上、远山之下，被山/云/树自然遮挡。

## 6. 云

- **纵向**：世界精灵以 `cloudParallax`（默认 0.12）的视差因子缓慢迎面漂来，靠近时放大、掠顶前柔和消散。
- **横向风（独立逻辑）**：真实时间驱动（默认 5 世界单位/秒，可负值反向），驻足时也缓缓横漂，前进时与纵向逼近叠加；漂出 ±900 卷绕边界前 180 单位柔和消散、绕回另一侧淡入。静止画面攒够 ~0.6 世界单位才重绘一帧，空转开销可忽略。
- **方向一致**：渲染器不做随机镜像；条带素材 4 簇统一"云头朝右、云尾朝左"（`make_cloud_strip.py` 里对原始包 TR/BR 两簇做镜像），与向右的风向匹配。

## 7. 镜头起伏

行走模型：垂直颠簸（画幅高 1.6%，每步一次）+ 半频左右摇摆（±8 世界单位，步伐交替、近景摆得多）；步频约 1.3 步/秒且随速度加快。幅度挂在速度包络 `bobEnv` 上——起步渐入、到站余摆缓出，不弹跳。编辑器"镜头起伏"滑杆 0~3（默认 1，0=关闭）。

## 8. 参数编辑器

场景带右下角齿轮打开。所有可调参数集中在 `CORRIDOR_DEFAULTS`，运行值在 `P`，存 `localStorage`（键 `corridor-params-v2`）。

- 分组：弯道 / 道路 / 森林 / 草地 / 纵深 / 相机 / 天空（含天气预设按钮行，首项"随时间"）。
- 参数模式：无标记=改后直接重绘；`measure`=重算投影；`structural`=重建场景；`strips`=重烘草带+重建。
- 调试钩子：`window.__corridorSet(k, v)` 改参数、`window.__corridorSetHour(h)` 直接指定当前时刻（截图脚本用）。

## 9. 验证与工具

- `scripts/cdp_shot.py`：Headless Chrome CDP 按 JSON 计划（wait/eval/shot）自动截图，`scripts/plan_*.json` 为既有计划（昼夜时序、日月档位、云风、镜头起伏等）。
- 素材处理：`keyout_parallax.py`（品红抠底+裁剪）、`fray_grass_roots.py`（草根侵蚀）、`make_cloud_strip.py`（云簇包→条带，含方向统一）。
- 版本破缓存：`CORRIDOR_VERSION`（现 `canvas25`）拼在 js/css/素材 URL 的 `?v=` 上，改代码或素材后**必须同步升版本号**（`index.html` / `corridor-demo.html` / `js/main.js` / `js/corridor.js` 四处）。

## 10. 与主流程的接口

`createCorridor(host, opts)` 返回：

- `travelForward(distance = STAGE_STEP)`：推关前进一段（返回 Promise，到站 resolve）——驱动时钟 +2h。
- `setMoving(on)`：开始/停止行进（敌方刷出后停）。
- `destroy()`：销毁实例。

战斗中场景静止（云仍横漂、时钟不走），战斗胜利后调 `travelForward` 进入下一关。
