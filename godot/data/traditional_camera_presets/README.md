# 传统模式镜头模板

双击项目根目录的「启动传统镜头编辑器.cmd」。分别设置移动、事件停留、战斗三个情境，点击保存。每个 JSON 包含全部三个机位，可以重新读取继续编辑。

这是传统 2.5D 投影编辑器：左右 / 前后使用旧场景的路线单位，以事件停靠点为原点；高度是投影眼高；地平线是画面纵向比例；倍率控制焦距；左右朝向以度表示。地平线调整不是原生 3D 俯仰。

预览使用独立测试队伍、当前主角选择和传统森林设置。单位位置先确定，改变镜头不会重新编排。静止关键帧用于确定构图；进入、离开和复活的动作过渡需要在确认模板后接入游戏。此目录与 native3d_camera_presets 独立，保存会同时发布到 traditional_camera_active.json，传统游戏每半秒读取一次更新。

## 战斗我方占位

战斗情境下可从列表选择每个我方角色或道具，设置左右位置、前后距离、显示高度（等比缩放）和离地高度。黄色框指示当前单位。正的前后数值越大，单位离事件停靠点越远。地面站立物件的离地高度设为 0，悬浮道具可适当抬高。

版本 2 的模板增加 battle_units，使用 card_id 与 occurrence（同卡序号）标识单位，避免使用临时战斗 UID。旧版镜头模板读取后使用初始占位补全，点击保存才会升级文件。编辑器启动时自动读取最近修改且有效的模板。保存模板会同步到传统游戏，镜头和占位平滑更新。新版代码首次使用需要重启游戏一次，之后保存无需重启。阵容一致时使用精确占位；阵容数量或顺序变化时按角色范围和道具排列分配。原生3D模式不受影响。


## 版本3：8个槽位，每个槽位两套标定

战斗情境选择「位置1」至「位置8」，再选择「角色 · 3D模型」或「道具 · 图片」。每个位置分别保存两套左右、前后、显示高度、离地高度；切换只改变该槽位的预览类型，不覆盖另一套。角色用当前主角模型预览，道具用怀表图片预览。预览类型不改变游戏实际卡牌类型。

保存字段 battle_slots 固定8项，每项有 character、prop、preview_kind。游戏按实际卡牌顺序及类型取值：8张卡一一对应；其他数量按槽位序列插值；单张使用中间位置。旧模板保留原算法，编辑器读入时补齐双模式，用户保存才升级发布。运行时不会拿道具的高度作为3D模型高度。
