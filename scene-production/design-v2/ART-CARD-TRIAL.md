# 2D 主导洞穴：真实图片最小拼组实验

2026-09-23。**研究进行中；不是已验收洞穴，不允许 Luna 据此批量生产。**
本页把实际做过的事情和下一道门槛分开。原正式场景、森林和用户入口未替换。

后续岔路研究见 [2D 岔路可见性分区](2D-FORK-VISIBILITY.md)。直道数据不能代替其中的洞口、分区接缝和退休检查；该研究也尚未成为正式游戏标杆。

## 已改变的实现

1. 停止整条立体拱体的美术扩充。真实游戏试验使用普通 2D 岩片，结构模型数量为 0；角色与地面继续沿用现有 3D 管线。
2. 左肩、右肩、冠部、外侧填充分别生成源图，而非矩形裁切一张整拱。裁切试验的直边已经在运动中暴露，不能重用为成功方案。
3. 左右肩、内冠、外侧填充和外冠有独立的纵深序列。冠部下缘中央高于两肩，维持圆拱趋势。外侧填充负责近镜头层间的空缺，不让小肩拱同时承担所有任务。
4. 实例只等比缩放，固定在世界位置；没有跟随镜头转动、淡出补洞或逐帧挪动。变化分为缓慢的洞腔宽窄/偏心/顶高与局部间距扰动，不把所有角色锁进同一整齐截面。
5. 地面角色读取源图最低接触带，按实际固定三角地面安放，并记录埋入量；冠部单独使用上方连接语义。没有把冠部最低点当树根。
6. 结构图片使用不透明 alpha 截断，不沿用树叶的半透明排序和近距淡出。此改动只在独立试验进程中替换材质。

## 多样性不是随便给一个资产数量

当前每个角色只有一张图，重复仍然明显。工具已统计真正可见片段，而非全部实例总数：在 1.2m 候选、以单实例占画幅 1% 的**研究观察线**计，某些机位同时见到 5 个左肩、5 个右肩、7 个内冠。0.1% / 0.3% 观察线也保存在结果里，方便判断敏感性。

这些数字不是必须生成 5/5/7 张的生产命令。下一步先区分高辨识轮廓与安静填充：减少相同强轮廓的高频出现，再在真实关键帧验证替代造型。镜像、外冠复用和换色不能当新造型；不能通过拉大间距重新制造缺口。按可见冲突和最小拼组结果申请变体，禁止一次盲目生成全场景库。

## 冠部间距的约束补充

针对上述顶部留出失败，未在失败坐标塞临时岩片，而是补了 `--coverage-cadence`：从源图中央 30%–70% 范围测最短连续不透明竖带，计算外冠的最大纵向间隔。

`最大间隔 ≤（不透明带厚度 − 两端摆放/缩放余量）÷（屏幕顶部最大射线斜率 + 洞顶高度沿路最大变化率）`。

当前候选的计算值：有效不透明厚度约 0.702m，两端余量合计 0.375m，顶部射线斜率 0.558，顶高变化率上界 0.175，外冠最大间隔约 0.446m。**这是这张图和这组变化量算出的研究结果，不是所有顶部都应该隔 0.446m 铺图。** 安静覆盖层与前面可辨识的主冠分开控制；不能把所有肩部、饰物也一起加密。

厚度不足以容纳变化时直接拒绝；试验另设 1,200 张卡片的有界编译上限，防止错误源图导致无限加密。此上限是研究保护值，不是实测性能预算。

`authored-card-cadence-01`：同一 141 留出机位不再有采样缺失，整段 556 张卡片、1,112 个结构三角面，仍为四张源图、零洞道结构模型。此推导只覆盖冠部中央带的节拍约束，侧向接口、源图 alpha 的细部、地形及全画幅仍必须经完整射线和原生过程复核。不能从局部推导声称整个场景数学闭合。

**重复问题并未因此解决。** 按同一 1% 观察线，内冠仍最多同时出现 7 个；后续必须继续解决强辨识造型的使用方式和变体，不得将留出零缺失写成艺术完成。

原生复核 `native-authored-cadence-01` 已完成并以 0 退出：记录终止阶段为 `encounter`，确实是约 3.975m 后遇事件，不是遇岔路。9 帧的近侧/顶部没有与画幅边界相连的背景区，中心远端仍有最多 352 个背景像素。末帧真实镜头已升至约 1.783m，倍率约 0.9545、地平线比例约 0.37194；以后不能把所有行进末段都按固定 1.3m / 1.0 / 0.48 测试。新清单已保存实际倍率和地平线，旧固定镜头粗筛只证明它自己声明的范围。

下一轮具体顺序：

1. 以现有四图拼组为结构对照，保持正式森林不变。先分离安静覆盖图与高辨识前景图的出现频率，制作确实不同的主轮廓/岩层变体，不能把额外的覆盖层算作丰富度。
2. 补地脚过渡并检查真实地形、事件前镜头升高时的接地/遮挡，不修改角色动画或战斗规则。
3. 直道艺术可接受后再将真实图片接入紧凑岔路。原数学混合方案的长中隔模型仍不符合局部辅助定位，禁止直接恢复；需以局部连接厚度和 2D 回折组作对照。
4. 完整两岔/三岔、事件/战斗、资源导出和性能仍是洞穴交付前置条件。室内必须在洞穴通过后开始，不能用当前局部结果提前标记目标完成。

## 2D 拼组调整：安静底层与局部岩层分开

新增两个原始生图文件，均使用内置生图，旁边保留 `.prompt.txt`，未修改像素：

- `crown-b.png`（2048×768）：减少亮斜面和小块石头，用连续岩面承担低辨识覆盖。只是一个不同源图，不能把缩放、位置扰动算成美术变体。
- `scree-a.png`（2172×724）：地脚碎岩过渡，附着于对应岩层组的底部，保持图片原比例。

试验顺序和结论：

| 对照 | 结果 | 判定 |
|---|---|---|
| `authored-quiet-crown-01` / `native-quiet-crown-01` | 换 B 冠后 141 留出机位无采样缺口，9 帧边界背景连通区为 0 | **单纯降低图案对比度不足以解决套圈**，不可据此批量生成替代图 |
| `authored-formations-01` / `native-formations-01` | 新增 `--formation-groups`：向内突出的左右肩和冠按固定世界岩层分组，独立于连续外覆盖；实例从 480 减至 354，留出机位无新增缺口 | 同画幅 1% 观察线下内冠峰值由 6 减至 4；外覆盖的可见次数反而增加，不能只报内冠减少就称重复问题解决 |
| `authored-ground-transitions-01` / `native-ground-transitions-01` | 对岩层地脚增加碎石子组；141 留出机位无采样缺口；真实角色/地形/镜头 9 帧，边界背景连通区为 0，远端背景最多 433 像素 | 地脚直切改善；远端收束、不同岩层的丰富度和全过程仍未验收 |

组合规则写在 `authored_cards()` 和 `add_ground_transitions()`，包括世界坐标低频分组、独立放置序列、等比缩放、地脚子组。参数仍属研究配置，不能抄成所有场景的强制数量或密度。

**接地修正**：取源图不透明主体边界的最低 10% 作为接触候选带，不再取整张画布最后 10%。新碎石图的透明下边距较大，旧方法会没有接触点；原生试验现在读取测量合同。顶部没有地脚候选，继续使用上方连接语义。地脚子组也计入总实例保护上限，不允许绕过 1,200 张研究保护值。
