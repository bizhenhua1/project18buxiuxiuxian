## 2. 先生产哪些能力，再决定数量

自然紧凑洞穴应有连续的岩体趋势，但不能每一横截面都是相同门框。结构与装饰分开；常规结构使用低识别度大块面，尖齿、发光、晶体、根须和吊物按条件少量出现。

| 功能 | 单图/组应提供的能力 | 不能混用的内容 |
|---|---|---|
| 近侧岩体填充 | 与道路肩部同材质；相近的窄高包围轮廓；大面、缓折、破口等区别；能在相机许可域里维持体积阅读；必要时以固定错角的面组成一组 | 不用完整拱门拉大填角；不能把薄片画了顶面就当作能任意绕看的立体岩体 |
| 道旁肩部 | 左/右来源或方向变体，分别具有内凹、斜抬、局部外凸的轮廓；沿岩层趋势组合；接口落在可遮叠的岩缝 | 不将所有肩部都画成同高度、同坡度的半门框；镜像不计新品种 |
| 普通顶体 | 主要表现从下方所见的底面；厚薄/破口变化；低显著性；与肩部的交接边可遮叠；不能有每次重复都能识别的大尖齿 | 禁止把一张俯视岩台当作所有屋顶；不靠一个整体平顶覆盖全部问题 |
| 局部顶体强调 | 单簇钟乳、短岩舌、局部垂落体、根须等；有明确悬挂接口和最低点 | 与常规顶体拆开，不把发光和尖齿烘焙进高频底层 |
| 岔路鼻端与侧回折 | 前端可见面、进入后会显露的回折面；是有纵深的固定组；支持小洞口、门后变宽 | 不把外侧矩形填充缩小后直接当中间独立石柱；不得侵入另一条路径 |
| 根部过渡 | 大碎块—小砾石—沉积接地的尺度递进；依附结构脚点；单组内统一岩层方向 | 不把全部地面均匀铺成碎石地毯 |
| 环境/叙事调剂 | 渗水、矿物薄层、菌类、稀疏结晶、遗留物等与水分/裂隙/通行侧有条件关系 | 不为凑数添加无功能小物；发光件独立、稀疏且有照明预算 |

这些是需求角色，不是已确定生成张数。新图的材质参考可以继承旧图的灰蓝手绘质感，但不能原封不动继承全部尖碎、亮顶面的造型。

## 3. 单资产检查，必须在整段铺排之前

1. **美术判读**：实际物件是什么，观察方向是什么，哪一面朝内/朝下，根/挂点/可遮叠边在哪里，有哪些强识别标志。先保存可见源图和标注；不能只测 alpha 包围盒。
2. **元数据**：源图哈希、像素、alpha 轮廓、实体/开口/连接区、锚点、允许等比尺寸、可镜像条件、画内光方向、允许照明、角色白名单、变形模式、验证状态。
3. **观察角预检**：在真实投影和距离范围里测试正视、斜视、最坏近侧视；角度上限来自本图的验看，未知写 null，不能统一拍一个 45°/60° 充当全部图的能力。几何退化与画内透视矛盾要分别判定。
4. **尺寸预检**：以预定最近距离算投影像素需求；等比放大不等于清晰度足够。根部可局部接地，主体/悬顶保持刚性；不能把地下部分翻折算法无条件套给悬挂物。
5. **最小拼组**：先检查“近侧填充＋肩部＋普通顶体”及“岔路鼻端＋入口回折”两个必要组合。验证开口、M 形轮廓、交叉穿插、接口、光向、侧视和显著重样；不先铺满整段。
6. **连续性**：通过后才在真实进出镜头轨迹上验证许可域边缘。固定资产组不随镜头摆动；禁止忽隐忽现的动态补洞。

新生成图先进入候选目录，不直接覆盖旧源图。未通过上述检查的源图不得写 `approved`。

## 4. 资产量和撒布如何联合推导

- 先编译通行区域、镜头轨迹与需要结构遮挡的边界，列出每一段真正需要哪些角色及接口；不是用固定截面间距推出整套美术。
- 以原尺寸及许可朝向求覆盖候选；需要不合理的缩放或侧视才覆盖到，说明角色能力不够，返回资产需求，而不是增加重复实例。
- 组合按“连贯趋势段”组织：一段主岩层方向、块面尺度和顶高变化保持一致；段间出现破口、挤压、局部侧洞或沉积变化。肩部、顶体、根部不共享一个等间距节拍。
- 对实际可见、可辨识的实例建立冲突图：同时看到的显著相似件、沿途短时间再次出现的显著组合不能分配同一变体。镜像、换色、小幅缩放属于同一相似族。
- 先尝试在通行/遮挡约束内改变组与趋势段；仍无法分配才生成该角色缺少的变体。这个分配冲突给出数量下界，不能用整个路段实例数或透明包围盒重叠数冒充可见重复数。
- 高频基底、局部轮廓强调、稀疏光源分别计量；增加光源/小道具不能抵消结构库缺少变体。
- 编译期做角度、支撑、重样、覆盖检查；运行期消费固定组与既有空间分批/裁剪，不每帧搜索摆放或分析图片。
