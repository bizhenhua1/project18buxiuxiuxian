# C1 岩体接地：规则、修正与验收边界

2026-09-22。数值接地修正已接入 C1 试验；整体洞穴和根部美术边缘尚未验收。森林不在本次改动范围内。

## 1. 已定位的问题

1. `cave_c1.gd` 将侧填充、落地肩拱和分隔岩体统一使用 `anchor.y=.96`。实际旧侧填充的可见脚沿约在画布高度 .8912～.9480，新侧岩约 .9072～.9548。透明画布底、图像最下方像素、整段真实接地轮廓是三个不同概念。
2. `scenery.gd` 之前按 crystal 类型判断接地方式；有固定朝向的侧岩和悬顶都会进入底部翻折模式。若岩脚已经在锚点以上，翻折不会让它接地；主体还会随各顶点地形采样发生形变。
3. 最小组合检查原来使用平面地板，却让相机使用正式地形高度，检查空间不一致。这已改成正式世界坐标的一米三角网格。

这不是简单把所有资产的 root 改到图片底部即可解决的问题。图中碎石、主体根脚、悬挂接口必须先区分语义。

## 2. 当前实现

- 落地侧岩、落地肩拱、分隔体：`contact_policy=rigid`，离线检查后的脚沿元数据决定一次性刚性高度；不转动、不拉伸、不翻折主体。
- 顶岩：同样刚性，但属于悬挂件，不执行地面脚沿求解。其组内挂点和肩部连接仍需后续组合验收。
- 散落地表件与已认可森林保持原接地策略，不因本次试验全局切换。
- 在源图修改后，接触数据必须重新审查、编译。测试核对 SHA256，不能让旧元数据套新图片。

源图已经人工查看，仅以下三个明确落地角色进入当前接触数据：`modular/side-fill-v1.png`、`modular/shoulder-rising-v3.png`、`c1-candidates/side-mass-v1.png`。这只确认其脚带可以检查，不代表这些源图的风格或重复使用已获准。

### 计算方式

元数据记录每个脚沿区间 `[u0,u1,vmin,vmax]`。镜像、横向偏置和固定朝向先转换到世界坐标，再查询 `ground_grid.gd` 的实际三角形高度；不能使用路线距离当世界坐标，也不能只用解析高度代替实际三角网格。

对于每个区间，取地面高度的保守下界，减去该区间最高可见脚点相对锚点的高度，求得允许的最大根节点高度。整张图使用所有区间约束中的最小值。区间宽度的地形误差使用坡度界约束，同时留出 MultiMesh 锚点半精度存储的误差量。

同时计算最深埋入量。当前候选试验上限为画布世界高度的 10%，**这是显式试验预算，不是所有资产的正式标准**。超出则记录 `root_band_exceeded`，不无限下沉、不拉伸修补；应缩小单体覆盖跨度、调整摆放，或重新制作可用根脚。后续生产编译必须将其作为失败项，不能把运行时警告当成验收通过。

图片扫描只在 `scripts/compile_c1_support.py` 离线发生，运行时每个实例生成时消费最多约几十个区间。每帧不读图片、不重选锚点、不随相机求解接地。渲染仍使用已有 MultiMesh，刚性结构走四顶点平面，不新增灯光、粒子或独立物理碰撞。

## 3. 验证结果

- `test_c1_rigid_support.gd`：3 张源图，镜像/非镜像、3 种固定方向、3 处含负坐标的位置、3 种地形幅度。独立扫描原图脚沿逐像素核对，共 **139,860** 个样本，未出现脚沿高于地面的样本；最深埋入约 **0.431 米**，发生于测试组合，未超过本次候选预算。
- `jobs/cave-c1-benchmark/root-contact-verified-v2/rigid-ground-contact.json`：当前试验布局 **280 个落地结构实例**，接地求解拒绝 0 个，最深埋入约 **0.405 米**。
- 同目录 `projection-audit.json`：当前镜头中的 **460 个上传结构候选全部为 mode 2（固定刚性平面）**。这是上传数据检查，不等于 460 个实际可见物件或性能结论。
- 同目录正式/诊断截图检查了实际岔路左行过程。仍可见旧源图重复、侧面薄片与屋顶缺口；这些没有因接地修正被关闭。

## 4. 未通过的美术部分与下一步

刚性岩体与地面的深度交界现在仍偏直、偏硬；最小组中的肩部/顶体与落地岩体还未形成统一的组级挂点关系。不能将数值无悬空描述成根部视觉已自然。

下一步限定为一个近侧岩组：保留刚性主体，按组定义根脚可埋入带、肩部挂点及独立的小碎石/沉积过渡。过渡件也必须有自己的真实接地数据，不能用漂浮草或雾掩盖错误。若主体必须损失过多轮廓才接地，重新制作根部更适配的资产，而不是继续增加遮挡数量。

最低验收包括：相机前进及横移时脚点世界坐标不漂移、相同地面三角形支撑、镜像正确、无主体拉伸、埋入不损伤关键轮廓、根部过渡自然、组内肩顶接口仍连贯。完成这一组后才可恢复整段新资产铺排。
