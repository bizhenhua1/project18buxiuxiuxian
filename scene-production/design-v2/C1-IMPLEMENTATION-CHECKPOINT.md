2. 事件能力编译器区分无战斗、可能战斗、必定战斗及未知；遍历同地点剧情链，识别循环和缺失声明。现有事件已明确声明能力，C1 开战入口按路线、事件索引和实际距离校验。真实战斗流程已跑通。**事件区间尚未完整驱动新结构撒布和队伍净空，不能称物理战场已全部准备好。**

4. 最小组合与离线透明轮廓覆盖检查工具已实现。32 个有限组合中最佳候选的最差检查区覆盖约 92.3%，未达到试验目标。此数字只适用于三个静态机位的作者设定检查区，不能充当正式灯光下的视觉评分或连续无漏空证明。接地修正改变了组合位置，旧覆盖数字也不能沿用为新组合结果。
5. 侧岩接地已加入语义数据、实际地面支撑、刚性摆放和埋入预算，详见 [接地规则和证据](C1-GROUND-CONTACT.md)。数值测试和当前左行场景接入检查通过，根部美术衔接尚未通过。
