# 当前 C1 山洞如何测试

当前是局部修正体验版，不是完成版。整段仍使用此前被否定的重复结构铺排；三张新候选只在最小组合中预检，没有作为新山洞整段交付。

1. 在工程根目录双击 `启动C1山洞接地测试.cmd`。这会明确打开 C1 试验开关，探索存档使用独立的 `c1-review-only.json`。
2. 在目录底部选“只看三岔”、事件选“选路后遇事”，种子保持 1842。
3. 在“水晶矿洞”下点击“进入 3D · 无限探索”。普通的“启动游戏”入口不会自动启用 C1。
4. 行进时看左右近处岩脚；到岔路先选左路。观察静止和移动时是否浮起、滑动或变形。空格或“暂歇”可暂停，再按恢复。
5. 点击右上“从头开始”，依次选右路和中路。返回“场景目录”，改为“只看两岔”再测两边。

首轮重点是接地和转接过程，不要为了检查改动已有镜头参数。遇到问题可提供“第几路段、两岔/三岔、左/中/右、静止还是移动时出现”与截图，便于复现。

已验证：岩脚数值支撑检查、当前第一路段左行的正式/诊断渲染、事件能力编译及开战位置校验。

仍未交付：自然根部边缘、新岩组完整撒布、顶部和侧角连接、低重复结构、岔路预览接管回收、连续后续路段的完整接地/构图验收。尤其缓存路段转换到新的世界位置时，现有固定支撑高度的重算仍须审查，第一段的通过不能推广到后续路段。

已知问题由开发侧继续处理，不要求用户重复证明。此次体验用于查看局部修正和补充未知问题，不代表请求整体验收。
