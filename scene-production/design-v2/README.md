## 三个必须说清的结论

- **不能承诺任意图片、任意镜头、任意路线都能自动不漏空。** 能交付的是：声明适用域、共同求解、在生产前拒绝无解组合，并对域内路线和机位做持续检查的系统。
- **资产总量由所需视觉能力决定。** 先算覆盖、同屏重样、沿途重样和主题叙事的缺口，再得到制作清单；不能从已有张数倒推合格，也不能把新增文件数当丰富度。
- **需要开发的核心是场景编译器及其检查器。** 它统一路线、镜头、结构、地面和光照约束，输出可直接运行的布置。运行时不做昂贵的全局艺术布局优化。
