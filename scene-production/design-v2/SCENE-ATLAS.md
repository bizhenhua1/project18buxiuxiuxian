# 类型与场景手册：不是换皮清单

与 [系统设计](SYSTEM-DESIGN.md)、[开发需求](DEVELOPMENT-REQUIREMENTS.md) 一起使用。以下是拟采用的空间设计，不是对现有成品的认可。

## 1. 分类方法与边界

共 **6 大类、18 个结构子类型**。分类依据是围合来源、承重/附着关系、可走面与可见空域、纵向尺度、观察角，以及路线拓扑。故事和颜色另作主题层。

| 大类 | 子类型 | 主要围合来源 | 核心差异 |
|---|---|---|---|
| O 室外 | O1 林地；O2 湿地；O3 人工庭园；O4 街巷；O5 露天装置场 | 植物、建筑/装置侧向体量，天空合法 | 有机生长、人工秩序、水岸与开放空间不同 |
| C 洞穴 | C1 紧凑岩洞；C2 高大洞穴；C3 根穴/侵蚀洞 | 岩体、顶岩或根系体积 | 紧凑尺度、巨大空腔、有机侵蚀不能同一截面 |
| I 低中顶室内 | I1 居所；I2 工坊；I3 厨房/服务空间 | 家具/设备、梁/顶面、挂物 | 日常用途与活动中心决定组合 |
| A 拱道与高廊 | A1 工程拱道；A2 礼仪高廊 | 有规律的柱拱/砌体、远顶 | 水利逻辑与仪式轴线不同 |
| V 垂直/台口空间 | V1 剧院；V2 竖井塔楼 | 台框/帷幕或平台/竖向装置 | 轴向终点、竖向连续与普通走廊不同 |
| X 诡异结构 | X1 活体腔室；X2 镜像廊；X3 错尺门厅 | 肋膜、镜框、异常门组 | 柔性组织、反射一致性、显式空间重映射 |

诡异是可叠加表现，但当它改变结构和观察逻辑时才单列 X。普通房间放一只诡异娃娃，仍是 I1 加叙事模块，不另造一个算法类型。

每个子类型下面均给出：组织方式、资产组合、路线、镜头与顶部、光雾地面、必须拒绝的问题。数值不是从截图随意换算；尺寸依照角色/机位/结构契约求得，数量依照需求矩阵求得。

## 2. O：室外的五种组织

### O1 林地：已有视觉参照，保持保护

- **趋势与层次**：大树决定林隙与路径，中层灌木形成团簇，低草响应根、湿度、踩踏。近侧干冠团提供量感，远端树隙保留目标。不能把所有植物沿路等距排队。
- **资产组**：树的支撑根与冠分开标注；根草、腐木菌簇成组；冠可以悬到路上但根不能占路。独立轮廓重点在显眼主树，中远低显著叶团可复用。
- **路线**：优先 R1/R3，自然绕树，分流后的支路恢复稳定方向；战斗袋由林隙形成。节点无需对称三门。
- **镜头/顶部**：继承已满意镜头，天空属于合法空域；冠层负责节奏和侧上角框景，不能铺屋顶。侧路转向不应突然看到全部树卡片侧面。
- **地面/光雾**：保留当前视觉认可的生态特征；起伏、树根支撑、曲雾独立预算。认可画面不等于任意新坡度和负载都已认证。
- **拒绝**：以“统一框景”为由修改现有森林；把森林当前参数自动作为其他四个室外子型的合格线。

### O2 湿地：空与密来自水陆边界

- **趋势**：密集岸草/菌簇与安静水面交替。湿度场、岸距和可站立高度共同决定分布，不能只提高森林密度。
- **资产组**：根木—湿岸—菌簇；芦苇—泥脚—小水渍；倒木明确跨水两端。发光菌单列 S8，主根木不得遍布亮点。
- **路线**：R1/R5 或局部栈道 R7；岔路可围绕水潭形成湿地岛，水面在节点保持真实归属。禁用铺满草的干广场。
- **镜头/顶部**：局部低枝压顶，水域上方可开；不把倒影或水面当作天空补洞材料。
- **地面/光雾**：水面近水平，泥岸过渡有支撑，雾沿湿域分布。液面与坡地接缝、透明水/雾排序单独测试。
- **拒绝**：草根浮于水上、岩片切断水面、远雾遮住入口后声称紧凑。

### O3 人工庭园：秩序可辨，但不机械复制

- **趋势**：行列、修剪边界、园圃和人行目的地；少量失控蔓生破坏秩序。按园圃组采样，不是逐棵随机。
- **资产组**：树/花/篱簇属于同一园圃；花盆和工具表达维护行为；焦点如巨型玫瑰或病果树承担记忆。低篱组可分隔路线，但不能遮死出口。
- **路线**：R3 与有主题装置的 R5；节点围绕园圃、桌或旧车分流；三岔是几条园路，不必都做成三个洞口。
- **镜头/顶部**：天空合法，树冠、藤架作为局部遮顶；花架需支撑与过道净空。角色前方保留可读区。
- **地面/光雾**：铺装/泥路与园圃边界连续；颜色强调集中于花果，不把整地染红。雾可低薄，不能吞掉人工秩序。
- **拒绝**：把果园做成矿洞、把茶会桌椅作为无关系的小物均匀撒布。

### O4 街巷：建筑节奏，不额外造连续侧墙

- **趋势**：门前使用区、招牌、屋檐轮廓、摊点/柴堆成段。宽厚建筑切片/檐柱组承担近侧体量，但仅用声明的独立模块，不擅自加左右连续墙。
- **资产组**：店面入口/檐下组与附属物绑定；路灯、井、招牌低频；建筑重复应改变轮廓和功能，不仅换色。
- **路线**：街道小转折 R1，巷口 R2，绕井/摊台 R3。分岔读作建筑之间的路径，非空旷十字广场。
- **镜头/顶部**：巷宽与屋檐投影共同决定可见天空带；窄巷的高处开空是合理城市天际线，不用洞顶封。
- **地面/光雾**：街面沿局部轴铺排，坡度与门槛/摊台底座协调；水沟独立。雾只处理远端层次，不改变近处建筑存在性。
- **拒绝**：房屋薄片边缘迎面暴露、转入侧巷后地砖长期斜切路线。

### O5 露天装置场：大装置分组，防止变空地

- **趋势**：游乐装置、站台、围带和遗留物组成岛；岛之间才是路。近侧框景可用木马群、棚架、售票箱组。
- **资产组**：每个可辨装置由基座、主体、附属物组成，检查组级比例；花哨小物不能代替装置主体。
- **路线**：R3/R5/R6；选择路径绕装置进入下一条稳定路线，不需要无限大中心场。
- **镜头/顶部**：局部棚布/灯串，上方天空开放；棚布受支持视角限制。大设施允许越过画面上缘，但脚点和远端目标仍清楚。
- **光雾地面**：旧漆/木材低饱和背景，独立稀少灯光；地面按装置基础和普通路面分区。
- **拒绝**：用大片平空地衬托一个小木马；每个装置都带不停闪烁的灯。

## 3. C：洞穴不是统一的大拱通道

### C1 紧凑岩洞：优先建立的新标杆

- **组织**：中等侧岩团、顶岩、岩肩、少量大地标构成不规则洞腔。层理/侵蚀方向在局部连续。近侧填充是宽厚竖岩组，不是两根孤立柱。
- **组合**：侧岩支撑组与顶组接口明确；左右错层、轮廓不镜像；中间顶岩可接两侧，但不把单个倒 L 图左右拼出 M 顶。碎石补脚与坡脚，不能负责整个洞形。
- **路线**：R1→R2→R4/R5。岔前仍窄，远处两个/三个小孔提前可读；分隔岩体保留；过小孔后再扩大截面进入战斗袋。整个节点尺寸由这些孔和可走扫掠共同推导，不取远端支路外缘做大并集。
- **镜头/顶部**：选择时保留原前向框景，近口才逐步转入。顶角覆盖由允许机位与岩组共同计算。默认 hybrid，深处可 atmospheric；不能为了盖角缝把近顶升成大教堂。
- **地面/光雾**：近脚岩碎、中央被行走磨平；方向性石层自然接续。少量渗水/晶体为节点，非每层一盏蓝灯。正式暗色背景可参与远接缝。
- **必须拒绝**：玩家认为像宫殿/下水道；门前空场；镜像 M 顶；薄片横向拉伸；转弯露出壳体外部；只解决上方而未解决左右角。

### C2 高大洞穴：高度可以大，玩家附近不能空

- **组织**：近脚侧岩/石笋提供尺度，上层大岩片/桥岩/远顶表现高度，中景有第二层体量。可行走廊并不随顶高同比放宽。
- **组合**：高低层使用不同观察尺度的轮廓，避免把普通小洞资产直接整体放大；巨大岩柱可只露出部分，但必须存在可信底座或远处遮蔽。
- **路线**：窄边道、内部小战斗袋、分层视觉空腔。岔路仍可小口进入大腔；R7 裂隙桥必须有独立步行面安全要求。
- **镜头/顶部**：以局部框景/垂吊岩和远顶渐暗表现高，不靠无上限抬头。允许远顶黑空，但近上角必须像空间延续而非缺贴图。
- **光雾地面**：少量高处漫射/远光传达高度；竖向雾层区别深度，避免亮光淹没角色；地面台地、跌落区有明确边界。
- **拒绝**：所有层同一岩片缩放，石笋/晶体同样重复；没有近景尺度参照而只剩黑色大空房。

### C3 根穴/侵蚀洞：方向来自生长或流动

- **组织**：曲根或溶蚀走势围合；主根/主脊引导视线，细根附着，地面碎屑沿凹处汇集。适合山中神秘入口、腐树内部等。
- **组合**：独立承载根肩/侵蚀岩与细附着物，不能用一张复杂满画面根网反复铺；组的轮廓密度须给角色留背景。
- **路线**：R2/R4；小入口可以被根包住，进入后展开成低腔或 C2。根系顺入口方向生长，不跨所有出口拉一片网。
- **镜头/顶部**：层层根肩自然封顶/混合背景，接合处允许不规则小孔；高亮孔洞必须作为明确主题窗而非偶然遗漏。
- **光雾地面**：泥根地面、低处湿润；侵蚀纹理与水流一致；发光物极少。细根动幅小，主根静止。
- **拒绝**：把该类当森林照搬树冠；无支点的根网；视线被高频尖刺全面覆盖。

## 4. I：室内首先表达“有人如何使用这里”

### I1 居所：低资产、顶层、吊饰共同成立

- **组织**：床/柜、炉灶/椅、缝纫/篮筐等生活角形成周边；相邻组合之间有安静过道。近侧柜/床尾可以有明显矩形体量，轮廓与中景家具一致。
- **资产组**：主家具、附属表面物、地面物分别绑定插槽。窗帘、门帘、吊灯、晾布属于上层组；悬吊人形仅作为明确的恐怖事件版本，不自动填空。
- **路线**：R4 小门串房；R2 是紧凑门厅，不是客厅每遇岔路就扩成大厅。战斗房间独立展开。
- **镜头/顶部**：较亮室内优先 geometric 顶材质加梁/局部挂物；暗阁楼可 hybrid。顶高由角色净空、吊物最低点和允许机位共同推得，不凭“房子一般几米”写死。
- **地面/光雾**：刚性平整支撑区，木板沿房间轴；炉光/灯光有来源，少量室尘，不默认贴地森林浓雾。
- **拒绝**：大部分家具退到远边；空旷地板；柜子/壁炉为挡缝异常放大；自动新增连续侧墙。

### I2 工坊：工序是一条可辨的资产关系链

- **组织**：材料存放→加工台→半成品→挂架/工具。路线穿插功能组边缘，避免每个工作台像独立小岛。
- **资产组**：台面插槽、原料容器、地面落料；挂钩/滑轮/皮张/木偶可在上层，与梁挂点对应。不要把工具各自随机扔地上。
- **路线**：R4/R3，工作台/支架可分流，战斗袋是腾出的作业区；选择口始终可见但不要求同宽三门。
- **镜头/顶部**：木梁序列加部分天花板；吊物沿作业轴分布，不能下垂到镜头/角色扫掠域。透视不合适的台面须换视角图或浅模型。
- **光雾地面**：木屑、皮屑、金属屑分别归属对应工序；局部任务灯，低强度尘埃；刚性工作台不可随噪声地形倾斜。
- **拒绝**：工坊变“房间加四张道具”；所有吊物同高度同间距，走近露出平面背面。

### I3 厨房/服务空间：长设备边界与使用通道

- **组织**：炉、案、储架与锅架形成工作边；有限突出物打破整齐，而非让厨房等价住宅。
- **资产组**：锅具挂在杆/钩上，餐盘接触台面，灰烬在炉旁；蒸气有锅/热源。可烘焙细小静态器具组。
- **路线**：R1/R4，服务通道转门；战斗袋选开放作业区，不能让兵线穿炉台。
- **镜头/顶部**：低中顶、梁/管/吊架；亮热源场景通常需要连续近顶，远端可减细节。
- **光雾地面**：地砖/木地面由主题选择，污渍响应工序；蒸气局部上升，不铺通用地雾；温暖热光与灰冷背景分离。
- **拒绝**：锅架没有挂点，炉火照亮顶缝，蒸气把角色轮廓长期抹掉。

## 5. A：人工拱道也有两套完全不同的逻辑

### A1 工程拱道：下水道、渠廊、维护通道

- **组织**：砌体肋拱、侧台、排水口/管件体现工程重复。重复本身合理，变化来自损坏、维修段、湿痕与岔口结构，不靠随机倾斜拱券。
- **资产组**：支撑—拱肩—顶段，渠道—侧台—出水口；装饰附着在工程构件而不是浮空。管道方向与接点连续。
- **路线**：通道 R1 与紧凑分配井 R2；井的尺寸由流路和步行桥/侧台决定。三岔不能简单叠三个完整拱。
- **镜头/顶部**：拱断面清晰，近处 hybrid/geometric；转向使用角拱/短接合段。完整拱只在允许的近正视直段重复。
- **地面/光雾**：渠底沿程有设计坡向，液面/侧台分开；湿雾比洞穴更低更局部；灯装在指定维护位。
- **拒绝**：用森林高度噪声产生逆坡水流；岔口水纹方向突变；把拱道工程秩序拿去套天然洞穴。

### A2 礼仪高廊：宫殿、礼拜堂、墓廊

- **组织**：成对/节奏性柱列、拱冠、轴线终点；允许有秩序重复，关键变体是柱间内容、破损段、仪式焦点和高度层次。
- **资产组**：柱脚/柱身/柱冠统一尺度关系，顶肋与吊饰接合；祭台/雕塑/帷幕成组。宫殿不能靠下水道道具改色完成独立主题。
- **路线**：R1 接门厅 R2 或仪式节点 R6；厅可以比普通洞穴宽，但仍须近侧柱组与中景层次，不无限空场。
- **镜头/顶部**：以柱高、顶肋和垂挂物暗示高度；亮穹顶需近处真实覆盖，暗远穹顶可背景衔接。左右转向检查柱冠背侧。
- **地面/光雾**：大图案铺装与仪式轴对齐；雾薄而可控，局部光束需上部开口或灯源解释。
- **拒绝**：柱冠缩放错配，空旷石坪，所有景深使用同一完整牌楼。

## 6. V：剧院与钟楼不能伪装成普通长走廊

### V1 剧院：台口、侧翼、上部机械

- **组织**：台框是视觉终点，帷幕/侧翼提供近侧体量，上部绳轮/灯架提供高度；观众侧与后台侧的资产用途不同。
- **资产组**：侧幕和上幕共用台口尺寸；面具箱/道具组属于后台；木偶悬挂有吊点与绳长，避免将悬挂木偶误当可索敌敌人。
- **路线**：R6 或后台 R4；岔路在侧翼/后台门，不能在中央舞台上刻三条森林路。战斗可以发生在台上，但进出台口要连续。
- **镜头/顶部**：高处可以暗空，边界由幕、台框与吊装分层解释。镜头不进入仅正面绘制的侧幕背后。
- **地面/光雾**：舞台木板/阶沿用局部轴；灯色服务焦点，角色补光与舞台灯分别有亮度上界；舞台雾限定区域。
- **拒绝**：舞台只是远景一张图，脚下没有台面逻辑；吊装变为巨量全屏透明卡片。

### V2 竖井塔楼：垂直感不等于让角色上下失控

- **组织**：环平台、梁、巨钟/齿轮/链构成上中下参照，开放井口有明确边缘；玩家附近平台可较窄，中央体积负责高度。
- **资产组**：设备轴心和支撑、链端与钟锤关系真实；大型运动设备用刚体变换/简化模型，不能靠一张持续转向镜头的正面图。
- **路线**：R7 与分层平台节点；只选择本期支持的坡道/短阶，未实现的自由垂直导航不伪称支持。上下层是明确连接图。
- **镜头/顶部**：展示有限上部与下方深度，不为“宏大”抬镜头破坏战斗占比；上下露空可能是井筒本身，必须标为允许区域。
- **地面/光雾**：平台与空域独立，掉落和阻挡有规则；竖井远雾渐变，设备局部高光稀少。
- **拒绝**：铺满一层地板却贴钟楼图冒充竖向空间；脚下空域与通行域没有区分。

## 7. X：异常必须建立在稳定的普通规则之上

### X1 活体腔室：鲸腹

- **组织**：肋架承载软膜，腔体宽高沿程变化，附着物与液迹回应重力/脉动。可有吞入的木船/生活遗物成为局部叙事组。
- **资产组**：硬肋与膜面分开；肋间接合明确；软膜小幅形变不能带动角色支撑面；发光腺体、滴液、纤丝独立。
- **路线**：R1/R4，小膜孔进入大腔，岔前不是对称三肋广场；入口组织有器官方向性。
- **镜头/顶部**：肋膜上层与暗背景组成 hybrid；近膜必须在实际灯效下成立。镜头滞后通过狭口，避免看膜片边。
- **地面/光雾**：湿润材料但不让全地面镜面反射；有限局部流体；暖冷对比保护角色肤色，不能整屏红光糊住层次。
- **拒绝**：石洞换肉色、悬膜无附着、脉动导致脚底滑动、每根肋上重复同一亮结节。

### X2 镜像廊：反射是受控效果与叙事规则

- **组织**：镜框/柱间节奏、遮布、破镜与少量异常反射；不是无限真实镜面递归。结构基底可以继承 A2，但反射与机位必须另验。
- **资产组**：框与镜面有独立材质/区域，裂纹可复用，显著异常图案唯一；侧面框架使用浅体积避免近侧穿帮。
- **路线**：R1/R2/R4；真实出口有稳定的物理/交互标识。假出口可以是设计内容，但不能因为程序缺陷与真出口混淆。
- **镜头/顶部**：优先限制可见镜面角度，远镜可用设计反射/模糊环境；若近镜必须反射角色，则纳入独立技术及预算范围，不能偷偷用静图宣称真实反射。
- **地面/光雾**：较冷克制背景、少量烛光；反射亮度封顶，地面图案对齐；不靠厚雾消除镜面需求。
- **拒绝**：角色走过近镜无倒影且无叙事解释；多次反射把帧预算击穿；镜面误读为天空漏空。

### X3 错尺门厅：不可能空间的可控版本

- **组织**：大小不同的门、过大日常物与正常尺度参照共存；异常集中在有含义的模块，不让全场所有尺寸随机。
- **资产组**：门组与门后过渡配对；桌上的瓶和钥匙仍有支撑；高门/小门各有可通行或纯装饰标签。
- **路线**：R8 与 R4；尺度变化只在明确转换点发生。如果角色不变尺寸，小门不得作为可穿行出口；可用开启后扩大、过门切换等明确设计。
- **镜头/顶部**：不通过任意 FOV 变化假冒角色缩放。空间重映射发生时完全遮蔽，保持进入/离开方向与故事联系。
- **地面/光雾**：参照地砖尺寸稳定或以明确边界变化；局部色调转变；不存在无缘由的地面相位跳变。
- **拒绝**：为修岔路无声瞬移；战斗中改变几何导致投射物丢失；不可能空间成为掩饰 bug 的借口。

## 9. 主动扩展的场景方向

以下是本作风格下的内容提案，不是本轮追加生产任务；尽量通过已定义能力组合，只有真正新增约束才扩展算法。

| 新场景方向 | 结构组合 | 独特体验/资产 | 新增技术边界 |
|---|---|---|---|
| 借走名字的档案馆 | I2/A2 + X3 | 书架/梯/吊签，找不到自己的抽屉 | 高书架侧视、假重复与真实出口区分 |
| 空壳祷告堂 | A2 + V1 | 柱间软布、无声钟、仪式焦点 | 高处柔性挂物与灯束预算 |
| 巨树内部的寄生村 | C3 + I1 | 树根房角、菌棚、寄生生活组 | 同一截面的木根与家具挂接 |
| 蛛丝织布间 | I2/C3 | 织机、丝束、吊茧、绷紧线方向 | 丝线透明过绘；少量前景丝线可读性 |
| 冻湖下的温室 | O3/X3 | 玻璃残片、冰顶、反季植物 | 折射只限定局部；不承诺全景实时玻璃 |
| 巨人遗物堆里的小径 | O5/X3 | 针、椅腿、钟壳成为地形参照 | 尺度变化必须保留角色正常物理规则 |
| 漂流的船舱旅馆 | I1/I2 | 梁舱、行李、吊灯、舷窗远景 | 摇摆以视觉层为主，避免所有脚点不停失稳 |
| 地下盐矿的送葬站台 | C2/A1 | 高腔、短轨/站台、盐柱、停钟 | 平台边界、方向性轨材质与路线同步 |
| 雨停不下来的回廊 | A2/O3 | 屋檐与露天庭院交替 | 室内外降雨遮挡、滴水与干湿分区 |
| 巨鲸胃中的沉船街 | X1/O4 | 肋膜包裹残船门前组 | 有机支撑与刚性船体接触、材质边界 |
| 被缝合的天空花园 | O3/R7 | 浮台、藤桥、垂挂根、远天 | 合法开空，不按洞穴封边；桥平台安全 |
| 一直在关门的旅店 | I1/X3 | 紧凑多门、门牌与灯变化 | 只有已遮蔽/未进入区域能重组，保持玩家因果 |

这些方向体现“童话结构 + 日常用途 + 单一明确异常”。不是将 SCP 名词随机贴在道具上，也不是靠全部变黑构成微恐怖。

## 10. 资产需求表如何按子类型形成

每景必须交付下表，未核实的格子写 `unmeasured`，不得用 0 或凭空整数代替。

| 需求项 | 推导依据 | 产出 |
|---|---|---|
| 普通结构轮廓 | 允许机位内同时可辨的结构组，合法左右/侧视组合 | 各角色最少独立轮廓及视角能力 |
| 结构接合件 | 路线模板实际出现的直段、内转、外转、门侧、顶角接口 | 接口能力清单，不是所有组合全生成 |
| 近侧填充 | 机位扫掠域、投影角落缺口、允许观察角 | 最少兼容体块/组，不许无限扩大 |
| 顶部与挂物 | 各阶段顶高/轮廓、挂点、照明闭合策略 | 顶组与稀疏挂组，分别核算 |
| 功能与叙事 | 一次旅程包含哪些有区别的活动/事件节点 | 主题主物、组合配物、唯一物件 |
| 低层过渡 | 主结构支撑、材料交界、湿/干生境 | 可共享的低显著簇与专用根脚 |
| 材料 | 地面、顶面、局部基础、湿/破损区域的周期需求 | 可平铺材料数及非平铺接合片 |
| 物效/灯 | 允许出现的来源、同屏上界、重要性 | 共享效果模板、主题参数、降级方案 |

不得因数量未定而无限研究。先完成一个**含全部困难节点的模板需求矩阵**，它就给出可计算的首批清单；随后只生成缺失能力。若普通结构已足、氛围仍不足，优先检查空间节奏/功能组/光层次，不能默认继续补图。
