# 矿洞紧凑岔路：可运行试验，不是已批准标杆

> **2026-09-22 用户裁决：当前试验的算法和视觉不达标，不能作为生产模板。** 包括空间过宽/过高、岔口与后续方向、镜头/顶角关系及重复轮廓等问题。以下保留试验过程，不代表问题已解决；后续按 [新系统设计](../../design-v2/README.md) 重新建立共同约束，不继续以扩大覆盖顶面作为通用修复。

## 本次解决的具体问题

旧矿洞在多条路线尚未充分分离时，只沿公共区域最外侧布置落地岩块，没有上部延伸，形成空旷广场和大片顶空。其他类型还存在单独拉宽整拱的路径；本试验不修改那些类型，也不修改森林、镜头、角色占比或实际路线。

参考学习：[用户提供的11张图册](../../references/mushroom-corridor/README.md)。借鉴层次、包围和紧凑选择，不照搬原作狭窄第一人称尺度或颜色。

## 资产分析与制作

- 复用：现有地面、岩脚、结晶簇、灯与碎屑；完整拱保留在旧方案，不拉宽使用。
- 补充：`shoulder-left-matte-v2.png`，独立落地岩肩，上部向内伸出；允许镜像用于另一侧，但镜像不计新的形态变体。
- 补充：`roof-cluster-matte-v2.png`，独立悬挂顶岩，填补岩肩之间的上部层次，不带落地支撑。
- 两图由内置image_gen生成，提示词见prompts.json，原始透明图直接入库，没有拿参考游戏截图裁切当资产。
- asset-check.json记录实际尺寸、alpha域和hash。透明域不等于语义支点；岩肩经图像观察选基准(.25,.94)，悬空顶块以底部为挂高基准，不伪造地面占地。
- 当前只有各1种轮廓，用于证明结构组合。正式量产需要不同岩肩与顶块变体；重复和翻转不能当成已经满足变体配额。

## 算法与参数

入口为`compact_cave.gd`，数值来自`godot/data/compact_cave.json`；仅开启`--compact-cave-workflow`时替换矿洞主结构。原模式可直接对照。

1. 沿路径采样横截面，以每条路线中心左右65U（3.25m）作为试验通行带，转弯用cos修正投影宽度。
2. 只合并实际重叠的带，不用所有出口的凸包清空整片场地。带分离后自然产生中间可放结构的区域。
3. 每组带由一个分支负责，避免在同一公共空间叠加三套完整洞口。世界坐标由局部坐标和段起始旋转统一计算。
4. 岩肩根点离带边38U，且到所有路线距离至少88U；这些是保守试验值，不等于整个岩脚轮廓碰撞已证明。
5. 岩肩画布高155U（7.75m），保持生成图比例。上下层岩块尺寸分别控制，不缩放路线去容纳图片。
6. 截面基准间距65U（3.25m），确定性波动±12%；左右纵深错开23U。顶块在截面中间错层，按105U上限间距等比例补块，不拉宽一整张图。
7. 顶块底部112U附近，高75U；起伏±7U。该参数用于当前镜头，不是所有洞穴的通用高度。
8. 公共段固定段朝向；路线完全分离后结构朝向对应路径。位置生成后固定，不跟随镜头重新撒布。

## 工作流及检查

1. 读取参考图册和本项目矿洞原图；列明每张图负责的结构角色。
2. 缺角色则生成独立构件；先检查透明、比例、支撑/悬挂、伸出方向。
3. 编辑配置，运行`godot/tests/test_compact_cave.gd`验证带合并、分离和路线覆盖。
4. 运行`python scripts/capture_compact_cave.py art/compact-cave-review/<新版本>`。输出目录不可覆盖。
5. 默认采集入口、两岔、三岔、左右中出口、战斗和战后，成对保留正式与诊断图；不重拍其他六类。
6. 先对照旧图判断包围与空旷是否改善，再查看诊断图找结构重复/露空/支点问题。诊断露空不自动要求补连续墙或顶面。
7. 按具体失败调整一次，再记录结果。图能生成和结构测试通过均不等于用户视觉通过。
8. 同机运行`benchmark_scene_workflow.gd`加候选开关，报告p50/p95/峰值；不将普通行进样本当成怪物技能压力测试。

## 边界与未完成

- 当前截面合并适配本项目既有左右圆弧分叉，不是任意PCG路径的通用布尔几何算法。
- 尚未实现五种组织方式的完整独立实例；本轮验证现有直行、两岔、三岔与分支进入。
- 第一轮已改善岔路上方空白，但明亮图有侧向露空和重复结构；第二轮增加间距/高度错落和独立分支朝向，仍待用户审查。
- 不新增左右连续墙，不把一张完整拱切半代替独立资产，不因暗场遮住问题就填accepted。
- 原7类截图是历史对照：代码改变后其源hash不能再当作当前版本证据。

## 用户反馈后的约束修订

当前v4候选将通行带宽从8.2m收为6.5m，岩肩画布高由10.5m降至7.75m；这些数值不是角色头顶净空，实际净空须按图中伸出部轮廓计算。通路镜头与角色比例保持原值。根点净空失败时只向外试探0/8/16/24U，仍失败就拒放；不直接跳过所有近侧结构，也不无限退到远处。

高频结构不得带醒目的重复发光点：原v1内嵌结晶已被用户指出为重复感来源，停用于候选运行，保留文件用于追溯。v2灰岩用image_gen修改，保留轮廓与透明底，去掉结晶。独立结晶沿用prop-0.png；现有生成候选经过30%保留抽样、同区域340U最小间距、600U邻域最多2个已有点缀的检查。它是生成时的世界空间密度约束，不是严格屏幕可见数量证明；不会根据相机移动突然删掉点缀。

在资产检查时主动逐项判定：轮廓重复、高反差斑点、烘焙光斑、识别性破损、变体数量、画布与有效轮廓尺寸、底部支撑、顶部附着、前中远层数量和镜头转入时的遮挡。结构、识别性装饰、光效分开管理；不再把主题颜色或发光点烘焙到每一张高频基础结构。
