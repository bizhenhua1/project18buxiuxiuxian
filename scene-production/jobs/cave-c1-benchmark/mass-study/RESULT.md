# 山洞短段实作结果 · 2026-09-22

**结论：候选可运行，尚不合格，不能升级为标杆或交给 Luna 批量生产。** 没有修改森林或正式山洞入口。本次不制作网页。

## 实际做了什么

- 用内置生图制作一张四块岩体的候选图集，以及一张凹底顶石；拆分后共五张运行图。源图、原始提示词、拆分说明保存在 `godot/assets/biomes/crystal/mass-study/`。五张只是结构试验用量，不是洞穴丰富度标准。
- 以真实角色、正式透视、实际起伏地面、真实 choose 状态流，运行直行 → 两岔选左/右 → 恢复原轴向 → 事件前停止。另跑三岔选右，主动暴露方案边界。
- 侧岩、斜肩、顶石分别排布；外侧大岩体承接小岩体外缘；不新增连续侧墙、不拉伸图片、不让资产跟镜头旋转。
- 试验中发现近乎不透明的岩图沿用草木透明混合会出现斑驳重叠。试验专用材质改为真正的不透明裁切，仍使用正式光照计算。这项修正尚未推广到正式渲染器。
- 内部分隔岩体按两个通行区域之间的实际剩余宽度限制等比尺寸，禁止用大岩块跨越相邻通道。落地岩体以原图不透明脚沿和真实三角地面求一次性刚性位置。

## 验证及明确边界

| 检查 | 结果 |
|---|---|
| 两岔左、右状态流程 | 两者走到事件前，末端镜头 yaw=0；仍使用同一有限曲线，地面没有转成永久斜向 |
| 图片比例 | 宽高始终由源图比例和统一缩放计算；无非等比缩放 |
| 岩体斑驳重叠 | 改为不透明裁切后，复核画面中的大面积斑驳消失 |
| 顶部和侧角 | 相比 pass-c 的大片露空改善明显；采样结果见 sample-check.json，不能视为连续全域覆盖证明 |
| 两岔局部性能 | 1440×900 窗口，RTX 3060；左/右帧等待加模拟 p95 约 17.00/17.11 ms，模拟 CPU p95 约 6.51/7.94 ms；加载和截图调用不计入，未测战斗/技能负载 |
| 三岔局部性能 | 同条件 p95 约 17.14 ms；1198 个候选图片实例，相比两岔 621 个明显膨胀，不是认可的预算 |
| 交互入口 | 实际输入事件验证右键选路和 F1 明暗切换；独立存档，终点停止，不进入战斗 |

## 未解决，禁止以“结构遮住了”关闭

1. **顶部重复仍明显。** 新顶石内缘优于平底地石悬挂，但同一凹底顶石多次出现，依然形成可辨识的横向节拍。侧岩尺寸和顶石的岩纹尺度也不完全统一。需要按同屏显著轮廓的差异补充经过审查的构件，不能仅增加随机间距。
2. **未选通道的可见范围与卸载尚未实现。** 为防止短预览后直接出现灰背景，本轮预建了多条长内部；三岔转入后仍能看到邻道。这是候选缺陷，不是认可的正式方案。应回到有限预览和遮挡接管的设计，不能继续把所有内部铺满。
3. **远端仍能看到试验范围的终止开口。** `sample-check.json` 原样保留这些灰背景连通区域；没有通过刷黑或删掉指标宣称零漏洞。
4. **尚无完整艺术库与事件展开证明。** 缺少经过验证的中景群落、稀疏独特点缀和完整战斗空间；目前五张图只用于发现结构耦合问题。

两岔尺寸在此进程里设为横移 3.4 m、前向转接 12 m；三岔横移 5 m。它们是本次候选值，不回写通用 C1 配置，也不是新规范默认值。选口之后从约 2.5 m 的喉口逐渐回到约 4.2 m 通道。不能将三岔候选的失败强行解释为用户需求不合理。

## 如何体验

双击工程根目录 `启动山洞短段新样例.cmd`；三岔用 `启动山洞短段三岔样例.cmd`。两者调用 `godot/cave-mass-study.ps1`，后者传入 `-Three`。角色先前进，到路口后用左右方向键或按钮选路；F1 切换正式光照和明亮检查。到事件前停止，关闭窗口退出。

旧的 `启动C1山洞接地测试.cmd` 调用的是 `godot/c1-review.ps1`，不会进入本轮新样例。新样例窗口显示“山洞短段候选”，使用新生成的圆钝岩体；旧入口仍是被否决的板状顶和直立侧岩布局。

这是单段候选，**不要从中进入正式战斗或把它作为无限跑图入口**。正式 C1 启动脚本未被替换。每次体验使用单独的带时间戳输出目录与存档。

- `final-left/`：最后布局的两岔左路，16 对明暗截图及位置/性能记录。
- `final-right/`：同布局两岔右路，16 对明暗截图及位置/性能记录。

- `interaction-smoke-v2/`：实际输入选路与明暗切换检查。
- `pass-a` 至 `pass-e-left`：中间候选，不作为最终代码验收证据。
- `sample-check.json`：原样列出采样画面的灰背景连通区；只用于定位，不给艺术质量打分。

本轮有效的技术发现可以复用；这套铺排方案的整体艺术质量和有限分支接管不能宣称完成。
